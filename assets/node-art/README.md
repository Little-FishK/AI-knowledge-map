# Approved node artwork

Six 276×276 PNG textures rendered from the maintainer's 2026-09-10 circular node and segmented-ring artwork, using the approved closely fitted, slightly thicker ring. Names remain real Cytoscape labels. No autonomous node motion is introduced.

Color mapping: foundations blue; coding orange; building green; generation purple; frontier silver; safety red. Canonical graph records are unchanged. Learning-order mode retains its existing numeric markers, and evolving concepts retain the dashed maturity indicator.

Original images and previous UI prototypes are preserved outside the repository in the task's ui-lab directory. Textures together are approximately 504 KiB rather than loading the twelve full-size originals (about 11.6 MiB) on every visit. This README is excluded by the public asset extension allowlist.
