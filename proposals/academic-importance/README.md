# 学术论文评价机制启动白名单

这些是已核实的具体机制，不代表完整覆盖所有领域、年份或重要论文。单篇仍需核对最终获奖和原件身份。规则见 [重要性审核机制](../../docs/ACADEMIC_IMPORTANCE_POLICY.md)。

当前收集要求采用[三路结果合并](../../docs/ARXIV_COLLECTION_POLICY.md)：相关分类、专业关键词、成熟评价与文献线索取并集并去重。本文的31项机制及 discoveryMode 仅管理奖项渠道和重要性证据，不构成全部送审文章的范围。v1.2 调整收集入口，保持重要性标准不变；尚未完成三路全量收集，总数未知。

本轮三路收集统一限于 2024-01-01 起首次提交到 arXiv 的论文（包含2024年），不以旧论文后续更新或获奖日期入池。历史试审与机制证据仍保留。

v1.1 最初登记20项评价记录。2026-09-23的100篇试审针对经典候选补核6项，当时共26项。随后2026年全量试验补核ACL两项与RSS三项，现共31项：14项为AI筛查候选机制、17项为定向补证机制。所有记录都必须另过“对AI发展有重大贡献”门槛，均无直接收录权限。原8组待核入口不再是领域覆盖任务。

本轮结果见[100篇试审报告](../../docs/ARXIV_100_IMPORTANCE_REVIEW_20260923.md)。新增机制仅补齐具体年份的外部评价，不改变重要性标准。
