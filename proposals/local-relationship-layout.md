# 相关节点图布局参考

2026-09-10：记录用户手动调整的监督学习和神经网络布局，作为后续局部布局的设计依据。本文件仅记录展示设计，不修改知识关系或理解页内容。

- 整体从左向右展开，选中节点位于偏左位置；不用圆心构图。
- 支撑节点在左侧上下分布，使用碧绿色小球和直线。
- 同级对比节点在右上方错落排列，尺寸与中心相同，使用白色连线；同级节点可以互连。
- 输出节点向右展开，按上下空间错落安排距离，不能只往右下方堆积。除同级关系外，连线只能与选中节点相接。
- 风险节点用红色箭头指向中心，集中在中心下方较近处，不延伸到最远的输出区域。
- 统一规则：最左侧风险节点固定到选中节点正下方，用短竖直红线向上连接。当前布局间距为 210，随画布等比缩放；只有一个风险节点时也遵循此规则。其余风险节点仍向右错开。此规则在局部布局目标位置计算时统一应用。
- 检查整体视觉重心与上下留白，避免下半部节点过多、分支过长。不能仅按角色机械排队；通过位置、角度、疏密共同平衡构图。
- 保留现有节点与连线样式、标签、页面排版和从大图过渡到局部布局的动画。

## 注意力机制的后续修正：箭头轮廓

用户指出：仅将节点排成扇形，仍会让每条右侧连线无意义地过长；下方风险的长红线也会拉低重心。

- 右侧输出轮廓应类似向右的箭头：中间节点最远，上下相邻节点退回一层，最上和最下的节点再退回一层。不能只调整角度而保持所有分支都很长。
- 本例由提示缓存形成箭头尖端；重排、可解释性为中间层；Transformer、梯度消失在内层。保持节点之间足够的标签空间。
- 下方风险节点单独收拢：上下文窗口接近中心正下方，中间迷失在其右上方，缩短红线，不与最远输出节点对齐。
- 后续布局同时检查分支长度和外围轮廓，不能仅以节点数量的上下均衡判断视觉平衡。
- 2026-09-10 实现按用户注意力机制截图的球心相对位置统一缩放，知识关系、箭头含义与内容保持原样。

## LLM 后续修正：紧凑左侧、向下风险、更尖的右侧

- 即使支撑节点多，左侧也保持贴近中心的紧凑半弧，不使用横跨大片画布的长线。本例九个小球与中心距离约为 200 个布局单位。
- 风险分支尽量朝下，而不是向右下摊开挤占输出空间。上下文窗口在中心近乎正下方，提示注入与越狱依次向右上方错开。按用户参考图保留必要的标签间距。
- 右侧箭头需要显著的尖端：AI Agent 最远，代码生成次之，其余两翼明显收回；不能把各节点放在接近同一条竖线上形成钝箭头。
- 评估重心时暂时忽略最远两条输出长线，单独看其余分支的上下分布，以及风险线长度和方向。
- 本次坐标按用户 LLM 截图的中心 (354, 408) 和各节点球心相对位置统一缩放。
