# arXiv 待审文章收集要求

版本：1.1｜生效：2026-09-23｜状态：收集规则已确定，尚未完成全量清单。

本要求定义哪些文章进入审核工作范围，不预判文章重要性或收录结果。最终收录仍执行[学术投稿内容重要性审核机制](ACADEMIC_IMPORTANCE_POLICY.md)。

## 1. 三路取并集

待审收集池 = 相关分类结果 ∪ 专业关键词结果 ∪ 成熟评价与文献线索反查结果，再按论文身份去重。任一路命中即可进入，不要求同时命中，不以获奖作为入池条件。

1. **相关分类。**以 `cs.AI`、`cs.LG`、`stat.ML`、`cs.CL`、`cs.CV`、`cs.NE`、`cs.MA`、`cs.RO` 为首版分类入口，同时检查主分类与交叉分类。分类命中不是 AI 贡献或重要性的证明。分类清单可有版本地扩充，不声称它覆盖所有 AI 研究。
2. **专业关键词。**在全站元数据中补搜具体研究术语，覆盖学习方法、模型架构、训练与推理、优化、数据与评测、可靠性，以及相关系统和硬件。使用版本化词表，记录实际字段和布尔检索式，不能只搜 `AI` 或 `artificial intelligence`。不局限于第一路分类，也不整类纳入所有数学、系统或硬件论文。
3. **成熟评价与文献线索。**从官方论文奖项、经典论文评选、专业综述中明确讨论贡献的关键文献反查 arXiv。保存原始名单或综述、具体定位及身份对应依据。引用关系或获奖只是发现和审核排序线索，不直接通过重要性审核；不无条件递归收集全部参考文献。

三路是互补入口，不是三个需同时满足的门槛。机制白名单约束重要性证据的采信，不限制前两路的收集资格；没有已启用奖项的文章仍可入池。

## 2. 初筛与完整审核

合并去重后的所有文章均计入待审收集池，首先做标题、摘要层面的 AI 相关性初筛：

- **相关：**可能贡献于 AI 的理论、方法、架构、能力、数据、评测、可靠性或训练/推理基础设施，进入完整六步审核。
- **待判断：**摘要不足、跨领域关系不清或材料缺失，保留并进入补查队列，不能静默排除。
- **范围外：**有明确依据表明仅将既有 AI 用于其他学科任务，未体现对 AI 本身的研究贡献，或明显无关；保留排除理由和原始记录。

初筛不要求已经证明“重大贡献”，也不使用获奖与否、引用量或 AI 自评分作排除门槛。完整审核的重大贡献与正式评价要求保持不变。入池、初筛相关、重要性通过、最终收录是不同状态。

## 3. 去重与留痕

- 同一 arXiv ID 的不同版本计一篇，保留版本记录；主分类、交叉分类及多路重复命中不重复计数。
- 保留每篇所有命中渠道、检索式或外部线索 URL、检索日期与证据定位，不能去重后丢失补漏来源。
- 不同 ID、改题名、会议版与预印本仅在身份核实后合并，保留别名与对应依据。相近主题或相似贡献不在收集阶段当作同一篇删除；贡献重复由内容审核处理。
- 外部线索尚未找到 arXiv 对应记录时，单列“待匹配”，不计入已确认 arXiv 文章总数，也不直接认定 arXiv 未收录。

## 4. 总量和完成口径

三路收集统一限定为 **2024 年 1 月 1 日（含）起首次提交到 arXiv 的论文**，以元数据 `published` 为准，不以版本更新时间 `updated`、获奖年份或会议发表年份替代。2024 年以前首次提交、此后仅更新版本的论文不进入本轮收集范围。每轮固定截止日期，并保存分类、关键词、外部线索清单及其版本。未来新增文章另计增量；首次提交日期缺失的记录待核，不猜测年份。

当前统计快照的截止日为 2026-09-23（UTC）；按首次提交日期使用区间 `[2024-01-01T00:00:00Z, 2026-09-24T00:00:00Z)`。此时间限制只调整本轮待审收集范围，不自动删除既有收录或改写历史审核记录。

每轮报告必须分别列出：三路各自命中量、多路合并去重后的待审总量、初筛相关量、待判断量、范围外量、完整审核完成量和未完成量、最终收录量。外部线索待匹配数量另列。

初筛守恒关系：待审总量 = 未初筛 + 初筛相关 + 初筛待判断 + 初筛范围外。已初筛相关论文进入完整审核后仍保留其初筛状态，避免重复计数。

只有本轮所有登记检索式与外部名单均已处理、分页完整且去重完成，才能报告“本轮规则下的待审总量”；运行中只能报“已收集数量”。失败、截断、未覆盖年份和未处理线索必须披露。不能将搜索平台估计命中数、旧关键词索引或试审样本数量直接当作最终待审总量。

完整清单是指定规则与截止日期下的结果，不等于证明穷尽全部重要论文。用已知重要论文检查检索是否命中，记录漏检原因并修订分类/词表或增加文献线索；检查集命中不构成零遗漏保证。

## 5. 依据

- [arXiv 分类说明](https://arxiv.org/category_taxonomy)：AI 研究分布于多个分类。
- [arXiv API 检索说明](https://info.arxiv.org/help/api/user-manual.html)：检索字段、组合条件、分页与版本规则。

本次确定收集要求，不代表已执行三路全量收集或已得到待审总数。
