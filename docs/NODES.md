## 一、判断标准：什么该成为节点

### 1.1 一句话原则

> **一个节点 = 一个可命名、有独立身份、值得单独一张卡片、能与其他概念连线的概念。**

再加一条方向性原则（用户 2026-07-19 定）：

> **合规的节点越多越好。** 边界情况向"单独建节点"偏，而不是折进别的节点当一段。
> 但"合规"是硬边界——宁可拆细，不可掺假。

两句合起来：**判据从严，取舍从宽**。够格的尽量都收，不够格的一个不掺。

### 1.2 够格成为节点的正面特征（满足即倾向建）

一个概念越符合下面几条，越该建节点：

1. **有独立身份**：能被单独命名，不依附于另一个概念才成立。
2. **有自己的"机制"和"对策"**：能写出"为什么会这样 / 怎么应对"，而不只是一句定义。
   —— 这是最强信号。**写正文时若发现自己在解释一个有成因和对策的东西，它就该是个节点。**
3. **能与别的概念连线**：至少能连出几条有意义的边（is-a / part-of / uses / mitigates / …）。跨大区的联系尤其加分。
4. **对"怎么用 AI"有实际意义**：读者会因为理解它而做得更好，而不只是多知道一个词。
5. **粒度适中**：比"整个深度学习"细（那是大区），比"softmax 的温度参数"粗（那并入采样参数）。

### 1.3 不该建节点的（无论频率多高，一律排除）

这些即使在语料里高频出现，也**不建节点**：

| 类别 | 例子 | 处理方式 |
|---|---|---|
| **产品 / 厂商 / 模型名** | GPT-4o、Claude、Pinecone、LangChain、text-embedding-3 | 进相关概念详情页的"代表实现"，或作 `model-families` 的例子；快变的可作 `activity` 条目 |
| **API 对象 / 代码 / 配置** | `client.chat.completions.create`、`BATCH_SIZE`、方法调用 | 不收，是实现细节 |
| **评价指标** | Accuracy、F1、BLEU、Perplexity、AUC | 收进相关概念详情页的"评价方式"，不单独建 |
| **参数细项** | temperature、top-k、top-p、max_tokens、各种 penalty | 合并进一个聚合节点（如"采样与解码参数"） |
| **通用软件/网络安全常识** | 泛化的认证、授权、RCE、反序列化、CIA 三性 | 不单独收；只有形成 AI 特有机制与决策的主题（如 Agent 委托权限）才建节点 |
| **职业 / 流程 / 学习资源** | "什么是 AI 工程师"、会议、证书、CTF、教程 | 不收；资源可作 `sources` |
| **与已有节点重复** | "向量检索"之于"检索与语义搜索" | 合并，加进 `aliases` |
| **散文词 / 章节标题** | Setup、Conclusion、Introduction、Overview | 不收，是文档结构不是概念 |
| **过于宽泛或过于细碎** | "深度学习"（是大区）、"softmax 温度"（并入父节点） | 拆成大区，或并入父节点 |

### 1.4 合并规则（把多个细项收成一个节点）

当一堆条目是"同一概念的不同侧面/参数"时，合并成一个节点，细项写进详情页：

- 采样参数（temperature/top-k/top-p/penalties/stop/max）→ **采样与解码参数**（1 个节点）
- MCP 的 Host/Client/Server/传输层（12 个条目）→ **MCP 架构**（1 个节点）
- 各类评价指标 → 进"评测"或相关概念的详情页

### 1.5 成熟度（`maturity`），不是分层

节点不分"基础层/活跃层"，只带一个轻量标签：

- **`stable`（缺省）**：教科书级、已成共识、以"年"为尺度才变。不特殊标记。
- **`evolving`**：较新、仍在演进的概念。图上虚线琥珀描边、详情页标"演进中"。

**按真实成熟度诚实标**，不为整齐硬凑：MoE/蒸馏是 stable，只有视频生成/合成数据/可解释性/世界模型/AIGC检测/计算机操作/模型家族/推理模型/AI编程工具/AI治理这类真·在变的才 evolving。

时效性的具体新闻/版本发布**不建节点**，作为概念详情页里的 `activity` 条目。

### 1.6 正文写作规约（够格建了，怎么写）

每个节点的 `body` 按固定四段：**是什么 → 为什么会这样（机制）→ 约束/影响了什么 → 怎么应对**。
只写"是什么"的词条没价值；第二段（机制）最容易被跳过，也最有价值。
正文提到别的概念用 `[[node-id]]` 内联链接，不重复解释、链过去。

### 1.7 版权

外部资料只作**选题依据和事实核对**，正文一律自己写。来源记进 `sources`，许可证记进 `CREDITS.md`。
明确禁止转载的来源（如 roadmap.sh）原文一个字不进仓库。

### 1.8 一条经验：为什么"扒源"加不出多少节点

2026-07-19 对 OpenAI 全套 Cookbook 的 30165 个抽取词做过全量分析，结论值得记住：
**实现/产品导向的语料，高频词几乎全是模型ID、产品功能、代码、指标、或已有概念，真正新的够格概念极少。**
—— 好的知识地图应**从领域本身建**，扒源只用来查漏，不用来充数。一个独立大语料反过来验证覆盖是否有缺口。

## 二、当前全部节点（129 个，★ = 核心视图默认显示的骨干）

> 六大区按"我怎么用 AI"分（用途分区 + 共享基础区）。`〔演进中〕` = maturity: evolving。

### 🧱 基础 / 共享（48）
★ **注意力机制** — 处理每个词时动态决定该"看"输入里的哪些其他词、看多重。
★ **Transformer** — 以注意力为核心、可反复堆叠的架构，当今几乎所有大模型的骨架。
　 **残差连接** — 让输入绕过一层与输出相加，深层网络能训起来的结构性前提。
　 **梯度消失** — 梯度层层回传中连乘、指数级衰减到近零，导致浅层学不动。
　 **缩放定律** — 规模/数据/算力同步放大时，损失以可预测的幂律下降。
★ **大语言模型 LLM** — 海量文本训出的超大 Transformer，本质在预测下一个 token。
　 **Token 与分词** — 模型看不见字符，只看见 token（文本被切成的小片段）。
★ **嵌入 Embedding** — 把文本变成向量，语义相近的内容在向量空间里也靠得近。
★ **上下文窗口** — 模型单次能"看见"的 token 总量上限。
　 **中间迷失** — 放在上下文中段的信息，利用率明显低于放在开头结尾。
　 **采样与解码参数** — 控制从"下一个词概率分布"里怎么挑的一组旋钮（temperature/top-p/…）。
★ **微调 Fine-tuning** — 在预训练模型上用特定数据继续训练，改变权重。
★ **神经网络** — 多层可调单元堆叠、通过数据自动学映射关系的模型。
　 **梯度下降** — 沿"误差下降最快方向"一小步步调参，训练的基本方法。
　 **反向传播** — 高效算"每个参数该往哪调"的算法，深层网络训练的前提。
　 **过拟合** — 模型把训练数据连噪声一起背下来，遇到新数据就失灵。
　 **卷积神经网络 CNN** — 滑动小窗口提取图像局部特征，长期是视觉主力。
　 **循环神经网络 RNN** — 按顺序逐个处理序列、传递"记忆"，Transformer 之前的序列主力。
　 **监督学习** — 用带标准答案的数据训练，学从输入预测输出。
　 **无监督学习** — 从无标注数据里自己找结构与规律。
　 **强化学习** — 智能体在环境中试错，用奖励信号学策略。
　 **自监督学习** — 从数据本身构造训练目标、不需人工标注，大模型时代的前提。
　 **正则化** — 一整套限制模型"死记硬背"的手段，对付过拟合。
　 **决策树与集成方法** — 一连串"是/否"判断做预测，及把多棵树组合起来的增强法。
　 **聚类** — 无标签下把相似样本自动分组。
　 **降维** — 把高维数据压到低维、尽量保留结构（PCA/t-SNE/UMAP）。
　 **维度灾难** — 维度越高空间越空旷、距离越失去区分度。
★ **预训练** — 海量无标注文本上做自监督训练，大模型能力的主要来源。
★ **多模态** — 一个模型同时处理文本、图像、音频等不同模态。
　 **量化 Quantization** — 用更低精度存权重，大幅减体积显存、换轻微质量损失。
　 **混合专家 MoE** — 拆成很多"专家"、每个 token 只激活一小部分，参数量大但计算省。
　 **模型蒸馏** — 用大模型当老师训小模型，把能力搬过去。
　 **合成数据** 〔演进中〕 — 用模型生成训练数据，应对真实高质量数据见底。
　 **上下文学习** — 只靠提示里几个例子就学会新任务，不改一个权重。
　 **Logprobs 与置信度** — 模型每步的 token 概率，可估计它对回答有多确定。
　 **CLIP 图文对比学习** — 海量图文配对训练，让图和文在向量空间里对齐；文生图的地基。
　 **批归一化 Batch Norm** — 按小批量统计把每层输入归一化到稳定分布，深层网络训得更快更稳；Transformer 改用层归一化。
　 **损失函数** — 把「预测离目标有多远」压成一个数，训练就是把它调小；优化的和真正在乎的之间永远有缝。
　 **信息论与熵** — 用熵量化不确定性，交叉熵/KL 散度是训练和评估语言模型的基本度量。
　 **核方法与 SVM** — 用核技巧在高维找最大间隔分界面，深度学习兴起前最强的分类器之一。
★ **后训练 Post-training** 〔演进中〕 — 在预训练之后，用指令、偏好与可验证反馈把基座模型塑造成可用助手。
　 **位置编码与 RoPE** — 把顺序和相对距离注入注意力，否则 Transformer 无法区分 token 的先后。
　 **层归一化与 RMSNorm** — 按单个样本的特征维稳定激活尺度，是深层 Transformer 能稳定训练的关键组件。
　 **优化器与学习率调度** — 决定拿到梯度后怎样更新参数、每一步走多远，直接影响训练速度与稳定性。
　 **参数高效微调 PEFT / LoRA** — 冻结大部分基础权重，只训练少量适配参数，以更低显存和存储成本定制模型。
　 **分布式训练与并行策略** — 把模型、数据和计算拆到多张加速卡上，突破单卡显存与训练时间限制。
　 **对比学习** — 把相关样本表示拉近、不相关样本推远，学出可检索、可迁移的表示空间。
　 **模型合并与适配器组合** 〔演进中〕 — 在不重新完整训练的情况下组合多个模型或适配器的能力，但容易产生参数干扰。

### 🔧 应用搭建（28）
★ **RAG 检索增强生成** — 回答前先检索相关资料，连同问题交给模型基于材料作答。
　 **向量数据库** — 专存向量并支持"找最相似的 K 个"查询的数据库。
★ **提示工程** — 设计输入的措辞与结构，让模型稳定产出想要的结果。
　 **文档切分 Chunking** — 把长文档切成小块，让检索能定位到片段。
★ **检索与语义搜索** — 从知识库找最相关内容，RAG 效果的真正瓶颈。
　 **重排 Reranking** — 对召回候选逐条精算重排，"先粗筛后精排"的第二步。
　 **约束解码** — 生成每步屏蔽会破坏格式的 token，从机制上保证输出合法。
　 **提示缓存** — 缓存重复提示前缀的中间结果，省重复计算。
　 **结构化输出** — 让模型稳定吐出程序能解析的格式。
★ **思维链 CoT** — 让模型写出推理过程再给答案，复杂任务上更准。
　 **LLM 应用评测** — 系统衡量应用好坏，没有它一切优化都是盲调。
　 **高级 RAG** — 基础 RAG 之上加处理，解决"检索不到/不够"。
　 **推理优化** — 让模型更快更省的一组技术（KV 缓存/Flash Attention/投机解码）。
　 **部署形态** — 模型对外服务的几种方式，各有隐私/成本/可控性取舍。
　 **模型选型与成本** — 不是都用最强的，先用最强建基线再往下换。
　 **上下文工程** — 决定每次调用窗口里放什么，比雕琢单条提示更上层。
　 **响应预填充** — 预先放入助手回复的开头，用输出前缀约束后续格式与方向。
　 **引用与溯源** — 让生成内容明确标出证据出处，使读者能核查结论。
　 **上下文压缩** — 在窗口接近上限时压缩历史信息，让长任务继续而不丢关键状态。
　 **流式输出** — 一边生成一边逐字吐出，而非等全部完成。
　 **系统提示与角色提示** — 对话最前面设定身份/规则/边界，贯穿整场。
　 **自洽性** — 同一问题独立解多次取多数，比单次思维链可靠。
　 **思维树 ToT** — 像搜索一样展开多条分支、评估、回溯，而非一条道走到黑。
　 **可观测性与追踪** — 记录每次调用全过程，让你能看清/调试/算账。
　 **知识图谱与 GraphRAG** — 把知识组织成实体+关系网络，检索能沿关系走、做全局归纳。
★ **模型评测与基准** 〔演进中〕 — 用可复现任务衡量模型能力、鲁棒性与安全性，并识别污染和指标错配。
　 **模型路由与级联系统** 〔演进中〕 — 按请求难度、成本与风险选择不同模型，让系统不必所有任务都调用最贵模型。
　 **数据漂移与持续监控** — 上线后的输入、用户与目标会变化，持续监控负责发现模型质量随环境悄悄退化。

### 💻 编程与 Agent（19）
★ **AI Agent** — 能自主循环"思考→调工具→看结果→再思考"直到完成任务的 LLM 系统。
★ **工具调用 / 函数调用** — 让模型输出结构化调用意图，由外部程序执行并回传。
★ **MCP 模型上下文协议** — 把"模型如何连接外部工具与数据"标准化的开放协议。
　 **MCP 架构** — MCP 的三角色（Host/Client/Server）与两种传输方式。
　 **Agent 循环** — Agent 反复的四步：接收→推理规划→调工具→观察。
　 **Agent 记忆** — 让 Agent 跨轮次/会话保留信息，上下文窗口装不下的部分。
　 **智能体技能** — 把可复用的专业流程、说明与资源封装成 Agent 可按需加载的能力包。
　 **Agent 框架** 〔演进中〕 — 帮你搭 Agent 循环、状态管理、多 Agent 编排的工具库。
　 **多 Agent 编排** — 把工作拆给多个 Agent 协作，两种模式：中心调度与对等交接。
　 **ReAct 推理+行动** — 让模型交替"推理"和"调工具"，Agent 循环的经典范式。
　 **代码执行与沙箱** — 让模型写代码并真正跑起来，用执行结果解决它算不准的问题。
　 **计算机操作** 〔演进中〕 — 让 Agent 像人一样看屏幕、点鼠标键盘，操作没 API 的软件。
　 **自我反思** — 让模型检查批判自己的输出再改进，用一轮自审换质量。
★ **代码生成 / AI 编程** — 让模型写代码，从补全一行到实现整个功能，AI 最成功的应用之一。
　 **规划与任务分解** — 把大目标拆成可执行小步，Agent 能否办成复杂任务的关键。
　 **人在回路** — 关键/不可逆步骤让人介入确认，Agent 安全落地的现实底线。
　 **AI 编程工具** 〔演进中〕 — 把代码生成/执行/仓库理解整合进开发流的工具，变化极快。
　 **工作流编排** — 用预定义固定流程串起多次调用，和自主 Agent 是两条路。
★ **Agent 身份、权限与密钥管理** 〔演进中〕 — 明确 Agent 代表谁、能访问什么、凭什么执行，并隔离密钥与高风险权限。

### 🎨 内容生成（13）
★ **扩散模型** — 学习"从噪声一步步去噪"来生成，当今图像生成的主流。
★ **图像生成** — 根据文本生成图像，主要由扩散模型驱动。
　 **生成对抗网络 GAN** — 生成器与判别器对抗训练，扩散之前的图像生成主力。
　 **语音识别与合成** — 语音转文字（STT）与文字转语音（TTS），两个反向任务。
　 **视频生成** 〔演进中〕 — 根据文本/图像生成连续视频，难点在时间一致性。
　 **可控生成** — 在纯文本提示外用额外条件精确控制生成结果（ControlNet/局部重绘）。
　 **变分自编码器 VAE** — 把数据压进连续潜在空间再重建，生成模型三巨头之一，藏在潜在扩散里。
　 **音频与音乐生成** 〔演进中〕 — 生成音乐/音效/环境声，和语音合成是不同任务。
　 **图像编辑** — 在已有图上按指令改，而非从零生成，实用场景主力。
　 **超分辨率与修复** — 放大低清、修复破损，用生成能力补细节（补的可能是错的）。
　 **世界模型与 3D 生成** 〔演进中〕 — 生成可交互、有物理规律的三维世界，而非一张图/一段视频。
　 **AIGC 检测与水印** 〔演进中〕 — 判断内容是否 AI 生成，检测器与生成器的军备竞赛。
　 **Flow Matching / Rectified Flow** 〔演进中〕 — 直接学习把噪声连续运输到数据的速度场，是与扩散紧密相关的现代生成路径。

### ⚖️ 安全与对齐（17）
　 **RLHF 与偏好对齐** — 用人类偏好训练模型倾向"人更想要的"回答，基座变助手的关键。
　 **红队测试** — 主动扮演攻击者攻破自己的模型，上线前找漏洞。
　 **可解释性** 〔演进中〕 — 试图搞清模型内部在做什么，仍是开放前沿。
★ **幻觉 Hallucination** — 模型生成流畅自信、但事实错误或虚构的内容。
★ **提示注入** — 把恶意指令藏在模型会读到的内容里，劫持它的行为。
　 **越狱 Jailbreak** — 用特定措辞诱导模型绕过自身安全限制。
　 **奖励黑客** — 系统找到让奖励变高却违背本意的捷径，是目标没写对。
★ **对齐 Alignment** — 让模型行为符合人类意图与价值观的一整套技术与目标。
　 **护栏 Guardrails** — 在模型前后加多道独立检查，分层防御把风险挡在外面。
　 **宪法 AI** — 用一组明确原则让模型自我批评和修订回答，并据此训练更安全的行为。
　 **数据投毒** — 在训练数据里掺恶意样本，让模型学到攻击者想要的行为。
　 **对抗样本与鲁棒性** — 对输入做人眼难察的微扰，就能让模型给出完全错误的结果。
　 **偏见与公平性** — 模型继承并放大数据里的社会偏见，在关键决策造成不公。
　 **隐私与数据合规** — 模型可能记住并泄露训练数据，加上数据出境等合规硬门槛。
　 **AI 治理与法规** 〔演进中〕 — 管理 AI 风险的制度/标准/法律，技术之外决定 AI 怎么被允许使用。
★ **训练数据治理** 〔演进中〕 — 管理训练数据的来源、许可、质量、去重、配比与可追溯性，决定能力也决定风险。
　 **不确定性校准与选择性预测** — 让置信度与真实正确率匹配，并在风险过高时拒答、检索或转人工。

### 📰 追前沿（4）
　 **主流模型家族** 〔演进中〕 — 当前主要大模型家族及其定位，变化最快的一层。
★ **推理模型** 〔演进中〕 — 回答前先生成一段长思考，用推理时算力换准确率。
★ **推理时计算与验证器** 〔演进中〕 — 在回答阶段投入更多候选、搜索、验证和工具计算，以成本与延迟换取成功率。
　 **状态空间模型与 Mamba** 〔演进中〕 — 用压缩状态线性处理长序列，并通过选择机制决定哪些信息保留或遗忘。
