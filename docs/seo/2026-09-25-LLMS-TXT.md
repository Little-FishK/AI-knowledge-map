# 2026-09-25 发布 llms.txt / llms-full.txt：决策记录

## 背景：本轮要处理的矛盾

`docs/seo/2026-09-19-SEO-GEO.md` 末尾记录了一条立场：

> 保留现有搜索抓取允许策略；……没有添加对模型发号施令的隐藏提示或宣称 llms.txt 能提升排名。

这条立场是对的，本轮不作修改。**llms.txt 不是排名因素**，Google 的生成式 AI 搜索指引也明确没有为其设置任何特殊抓取或 schema 要求。任何"发布 llms.txt 会提升排名"的说法都不成立。

但"不是排名因素"不等于"没有用途"。2026-09-25 的 GEO 评估（`docs/geo-assessment-20260925.md`）发现了下面这个不对称。

## 决定

**发布 `/llms.txt`（短索引）与 `/llms-full.txt`（全量条目索引）。**

## 理由：不对称的采集与供给

这个项目在**采集端**大量依赖上游的 llms.txt，这不是猜测，是仓库里的既有实现：

| 上游 | 用途 |
| --- | --- |
| `platform.claude.com/llms.txt` | 构建 Anthropic 官方资料清单（637 条） |
| `code.claude.com/docs/llms.txt` | 同上（208 条） |
| Google DeepMind、Hugging Face 等 | 同法构建各来源清单 |

也就是说：**项目自己证明了 llms.txt 对"机器读清单"这件事有用**，并且正是靠它把 1300 多条官方资料组织起来。而本站坐拥 1800+ 条经来源治理、带审核状态与使用边界的结构化资料，却不对外提供同等形式的索引——下游只能靠抓 HTML 逐个猜。**消费端证明了格式有用，生产端却不供给，这是不对称，不是克制。**

## 这与 09-19 的立场不冲突

| 09-19 已拒绝的 | 本轮做的 |
| --- | --- |
| 宣称 llms.txt 提升排名 | **不宣称任何排名收益**；文件内文只描述站点结构与记录，不含面向模型的指令 |
| 隐藏提示注入、"喂给模型的指令" | 不做。llms.txt 里没有 imperative 内容，只有链接与客观描述 |
| 为凑长度写模板话术 | 不做。每条索引行由 `title` / `summary` / `evidenceUse` 等既有字段生成，不新增描述文本 |
| 反复提交未变化的 sitemap | 不涉及。llms.txt 是文件，不是提交动作 |

定位说清楚：**llms.txt 是结构化索引，不是排名手段。**

## 实现

- 生成器：`tools/readiness/llms-txt.js`。
- 接入点：`tools/readiness/site-artifact.js`（完整构建时生成）、`tools/seo-crawlable-release.js`（在已验签产物上补生成）。
- 格式：遵循 llmstxt.org 约定 —— H1 站点名、blockquote 一句话定位、H2 分组、组内 `- [标题](URL) — 说明`。
- 内容边界：
  - `llms.txt` 是**短索引**（分组 + 计数 + 指向分类目录页），体积控制在 10 KB 以内（有测试断言）。
  - `llms-full.txt` 是**全量索引**，逐条给出原始 URL、摘要与证据用途；资料库部分按一级来源分节。
- 不写入任何正文以外的新文本；`summary`、`evidenceUse`、`authorityTier`、`discoveryOnly` 全部取自现有数据字段。

## 验收

- `tests/tooling/crawlable-coverage.test.js` 断言：`llms.txt` 以站点 H1 开头、包含分类目录链接、字节数 < 10240；`llms-full.txt` 包含条目标题与原始 URL；前言中不出现排名声称。
- `tools/verify-website.js` 的文件集校验覆盖这两个文件（它们经 `put()` 登记进 `release-manifest.json`，因此所有改动都可验签）。
- 实测体积：见 `docs/seo/2026-09-25-GEO-P0.md` 的记录表。

## 回滚方式

删除 `site-artifact.js` / `seo-crawlable-release.js` 中生成这两个文件的两行，并重建产物即可；无数据或内容依赖。

## 尚未成立的部分（不要夸大）

- **没有**任何证据表明生成式引擎已经引用本站，也没有引用量、引用页数或排名的前后对比。Bing AI Performance 在 09-19 的记录中就是 0 引用、0 引用页。
- 引用是否增加，需要等真实字段数据；在拿到之前，本文不主张 llms.txt 带来了任何可见收益。**这份文件的作用是把"可被机器读取的索引"补齐，而不是证明 SEO 效果。**
