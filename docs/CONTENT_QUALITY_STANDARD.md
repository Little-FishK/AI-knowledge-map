# 原计划第三阶段：内容质量标准

本标准对应原计划第11–18项。不是Stage 2审核记录，不覆盖控制器结论。2026-09-08起使用。

执行机制已接入[统一审核 v4](UNIFIED_AUDIT_V4.md)：按核心概念保留六项教学检查，并核验整页事实、公式、图表、来源和一致性；证据可跨章，但每章必须有定位。下表的跨页语义一致性与真实读者效果仍须单独验收，单页 v4 通过不自动完成这些项目。

## 每页教学检查

| 检查项 | 可核验要求 |
|---|---|
| 核心解释 | 明确回答是什么、解决什么问题；定义不依赖尚未解释的关键术语 |
| 具体例子 | 输入、过程、输出完整；数值可复算；区分示例与普遍结论 |
| 机制 | 解释步骤之间的因果关系，避免只列组件；标明所需前置知识 |
| 边界 | 说明成立条件、常见失效情况与类比不适用之处 |
| 图表 | 轴、箭头方向、图注、单位、公式、数据点与正文一致；有可读文字解释 |
| 跨页一致性 | 相同术语、符号和关系方向一致；链接目标存在；同名概念无含义漂移 |
| 来源 | 关键事实可追溯到具体来源；动态信息有核验时间；引用没有超出证据范围 |
| 下一步 | 说明接下来读什么及原因；采用既有链接，不借本轮检查重新设计学习入口 |

准确性审查必须指向当前版本的具体片段。图表应按公式、坐标、箭头或数据检查，不能仅凭截图“看着正确”。全站字段校验通过只说明结构，不能替代语义一致性检查。

## 三份独立结论

1. **事实准确性**：待查／有阻断／当前范围通过。保存页面hash、范围、来源、核验时间和未解决问题。只检查一页不能外推全站。
2. **教学效果**：未测试／形成性测试发现问题／修订后有改善证据。独立机器教学审查另列为“教学设计检查”，不能替代目标读者复述与应用。当前用户暂缓真实用户测试，不写“效果优秀”。
3. **记录完整性**：待查／缺少记录／当前版本链完整。人工维护的旧页可以记录真实人工来源及确认，不能补造历史生成或机器审核。每次修改必须使审核hash与当前版本对应。

上述三项不得取平均分；任一未知保持未知。审核次数多不证明内容正确，机器通过也不证明读者学会。

## 批次与依赖

所有130页进入元数据清单。按已存在的官方顺序作检查顺序，称为“存量检查批次”，不称为已验证的初学者旅程。第二阶段必须先与用户讨论；第15项的基础旅程优先级最终确认因此保留依赖。

理解页正文、图表、发布、返修和审核通过Stage 2 MCP执行。一页一个全新独立审核者；修订者仅使用净化缺陷；不清零返修历史。涉及人工最终确认时提供完整可审阅候选。不能为清空队列把待审页标为通过，也不预设重写全部页面。

## 软件、教程和资料库

逐记录检查官方地址、用途与限制、时效性断言、版本和地区条件、推荐理由及初学者前置要求。HTTP 200仅证明当时可达；403/429或超时记为无法核验，不直接删除。模型、价格、产品能力、法规与教程界面说明须查当前原始来源。视频教程未实际复现时不得标为可复现通过。

## 第三阶段完成条件

- 第11–18项有交付物；130页和其他公开内容全部有明确本次检查范围及维护状态。
- 关键事实及图表阻断已解决或明确撤出推广范围，撤出仍须符合发布控制器规则。
- 受影响跨页一致性、正文与图表经过复验；确认记录绑定实际版本。
- 核心内容具备新读者复述、应用与修订后复测证据。该测试继续暂缓时，只能报告“机器检查已完成，教学效果验收待进行”，不能宣布第三阶段全部完成。
