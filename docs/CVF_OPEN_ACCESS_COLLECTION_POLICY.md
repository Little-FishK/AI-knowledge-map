# CVF Open Access 待审文章收集要求

版本：1.0｜生效：2026-09-24｜统计范围：CVF Open Access 官方索引中 2024、2025、2026 年的可访问终版论文记录

本要求只定义哪些 CVF Open Access 记录进入候选池，不把 CVF 收录、主会录用、Findings、Oral、Highlight 或 workshop 身份当作重要性结论。正式收录继续执行[学术投稿内容重要性审核机制](ACADEMIC_IMPORTANCE_POLICY.md)。

## 1. 来源特点

- CVF Open Access 是多个计算机视觉会议及其 workshop 的开放论文入口，不是单一会议或统一评价赛道。
- 主会、Findings 和 workshop 分页独立组织；论文必须保留会议、年份、轨道和 workshop 名称，奖项机制不能跨页、跨轨道、跨会议或跨年份继承。
- 官方页面提供题名、作者、论文页和 PDF。候选身份以单篇 HTML 论文页 URL 为准；同一 URL 只计一次。
- CVF 页面提示开放版本由作者提供；若页面注明 IEEE 出版版本为正式记录，网站只发布链接、书目信息和原创说明，不把开放副本误称为唯一权威版本。

## 2. 候选池范围

本轮范围为 CVF Open Access 首页正式列出的以下 2024–2026 分区：

1. 主会：WACV 2024、CVPR 2024、WACV 2025、CVPR 2025、ICCV 2025、WACV 2026、CVPR 2026；
2. Findings：CVPR 2026 Findings；
3. Workshop：上述会议在 CVF Open Access 上单独列出菜单并能访问的 workshop 论文页。

全部可解析的单篇终版论文记录进入候选池，不先用题名关键词裁剪。这样可以保留基础视觉方法、优化、几何、数据与评测等题名中未出现 `AI` 的潜在重要成果。

## 3. 轨道边界

- 主会普通录用、Oral、Highlight、Poster 都只是发现信息，不构成正式评价通过。
- Findings 是正式论文通道，但其身份本身不构成重要性证据。
- Workshop 可进入候选池，但 workshop 论文不能继承同年主会 Best Paper 等机制；挑战报告、竞赛总结或应用论文也不能仅凭所在页面通过。
- Best Student Paper、Honorable Mention、Runner-up、Demo 奖或其他相邻奖项必须保持原名，不能冒充已启用的 Best Paper 正奖。
- Longuet-Higgins Prize 等历史机制按原论文年份另做历史补审，不计入 2024–2026 出版候选基数。

## 4. 与重要性审核衔接

候选池按会议、论文年份、轨道、完整奖项名与 winner 身份精确匹配机制登记表。未命中已启用正式机制的记录在第 2 步暂缓；不逐篇重复制造“没有获奖”的伪深度审核。

即使精确命中正式奖项，仍必须继续核验论文身份、当前状态、AI 重大贡献三问、材料与版权用途。奖项名单或作者摘要不能单独补足“外部专业说明具体改变了 AI 什么”的证据。

同一成果若已从 arXiv、OpenReview、PMLR 等入口进入网站，应合并 CVF 终版与奖项证据，不重复建卡。

## 6. 完成口径

快照保存每个已访问页面的 URL、抓取时间、HTML SHA-256、解析数量和失败路由。报告必须分别给出候选总数、分年／会议／轨道数量、去重数、正式机制精确匹配数、六步完成数、待补证数、暂缓数和最终可上线数；任何失败路由或未来新增页面都必须触发增量复查。
