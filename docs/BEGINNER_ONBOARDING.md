# 六站新手导览

任务6的独立入口，不属于正式图谱节点或理解原理页 Stage 2。任务7、局部关系图与正文阅读深度改造未包含在此次实现中。

## 内容与展示

1. 认识AI：AI能帮我做什么？
2. 理解生成：AI为什么能回答、写作和画画？
3. 说清需求：怎样让AI听明白我的意思？
4. 检查答案：我能相信AI的答案吗？
5. 负责使用：怎样用AI，才不会给自己和别人添麻烦？
6. 开始探索：工具这么多，我该从哪里开始？

正文为原创中文讲解，参考 Google AI Essentials 和 Elements of AI；各页附官方继续阅读链接。复用现有 dd-* 阅读样式，每站含核心结论、三节正文、原创SVG讲解图、可选思考题和回顾。新手内容尚无英文翻译，英文用户会看到中文内容说明及可跳过入口。

## 行为约定

- 首次进入时显示独立的新手地图，桌面端一排六节点、窄屏一列六节点，无侧边栏或正文。只有第一站可点击，其余逐站解锁。
- 点击已解锁节点进入独立阅读页。阅读页不显示节点路线图、已读数量或进度条，可返回新手地图，或使用页尾按钮逐站阅读。
- 刷新或重新打开导览时先显示新手地图，保留已读与解锁进度；完成或跳过后刷新仍直接进入完整地图。
- “读过，下一站”保存已读进度并打开下一站。重复阅读不会重复计数。
- 所有站点读过后进入完整地图；“我已熟悉AI基础用法”允许直接跳过，不伪造已读状态。
- 顶部“新手导览”可重新进入。已跳过的用户可从未完成的位置继续补读。
- 不改写原URL；首次进入概念或其他深链接时，完成或跳过导览后继续访问原目标。
- 导览是阅读引导，不是安全权限限制。独立静态文章仍可直接访问。
- 无需登录、注册外部服务或答对题目。没有计时、滚动或测验门槛。
- 本机进度存于 localStorage 的 `ai-knowledge-map.onboarding.v1`，与图谱学习进度和云账号分离。更换浏览器或清除站点数据会重置。
- 存储被禁用时提示无法保存，仍可在当前会话继续。损坏的数据可重建；跨标签页合并已读数量时不倒退。

## 文件

- `assets/onboarding-content.js`：六站正文、图示数据和参考链接。
- `assets/onboarding-model.js`：可独立测试的解锁、访问与状态合并规则。
- `assets/onboarding.js`：页面渲染、本机存储、键盘焦点与进入地图。
- `assets/onboarding.css`：导览布局与移动端样式。
- `index.html`：样式、脚本和复习入口。
- `assets/app.js`：地图初始化等待新手导览完成或跳过。

新资源全部位于网站构建已包含的 assets 目录；现有 site-release 是先前产物，不在本次前端修改中直接重写。上线需走现有受控构建与发布流程。

## 验证

运行 `npm run test:onboarding`，验证内容结构、解锁规则、刷新续读、跳过/复习、深链接、移动端、损坏和不可写存储，以及 file:// 离线入口。

浏览器测试使用合成的原理页导航夹具，不读取正式 Stage 2 正文；截图输出至 `.tmp/onboarding-qa/`。
