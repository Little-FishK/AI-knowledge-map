# 统一审核机制 v4

2026-09-08。用户授权以新版整页审核为主，补回旧版有价值的教学检查。本次不启动产品计划第二阶段，不修改内容生成固定提示词，不据此宣布第三阶段已完成。

## 合同与证据

新领取任务默认schemaVersion 4、policyId whole-page-teaching-v4，携带固定规则快照摘要。历史显式绑定v2/v3的任务仍可按原合同处理；原审核记录不改版本、不补造证据。升级入口保存旧正文、审核和状态快照，保留返修次数及已发布版本，再排入独立补审。

每个核心概念检查定义、问题、输入输出、机制与因果链、结果解释、边界。证据可跨章节，每条记录section与原文quote；只能定位到该概念列出的章节。定义、问题、边界必须回答；其余三项可在确实不适用时标not-applicable，必须提供定位和applicabilityReason，由独立审查者承担适用性判断。机器不以关键词、固定字数或每章六问模板代替语义判断。

整页另检查facts、formulas、figures、sources、consistency，reviewedSections须恰好覆盖全部章节。每章必须至少有一条 coreConcepts 或 pageChecks 的真实定位证据，不能只列章节号。合同同时给出 blocker 与 warning 字段说明。有图表时不能把图表审核标不适用；存在 dd-formula、MathML 或 data-formula-id 时拒绝公式“不适用”。无显式标记不代表没有数学内容，仍须语义检查。事实、公式、来源支持、实质图文矛盾和必要解释缺失保持阻断。轻微措辞与图注建议不自动升级为阻断。

新版人工整理流程继续只允许一次返修，之后仅复核首次问题。定向复验绑定首次问题摘要；结果标为targeted-review-only，不冒充新的一次全页通过，也不能用定向记录单独通过全页发布CLI。

## 三项结果与发布

- 准确性：事实、公式、数值、术语、来源、图文一致性的专家结论。
- 讲解效果：核心概念与整页讲解的专家结论；真实初学者验证始终单独记录，当前not-tested。
- 记录完整性：规则版本、正文摘要、审查日期、章节范围、逐字证据与结论的一致性。

记录完整不等于内容正确，专家通过不等于真实读者已经学会。新v4审查结果保存为摘要命名的不可变文件，并记录审查者、任务、正文摘要及规则版本。普通v4页面也先进入manual-review，不自动发布；人工终审仍检查当前版本的证据和门禁。新版整理页面的人工作用域保留原明确覆盖记录机制，但无效/过期的v4审核不能充当终审依据。

## 统一技术入口

权威规则：tools/deepdive/quality/audit-policy.js。共享检查：audit-evaluation.js与控制器audit-rules.js。候选门禁、正式发布验证及CI使用同一v4评价逻辑。新规则不依赖网站当前神经网络正文，规则快照变更会使旧v4记录失效，需要补审。

原神经网络基准文件及v1/v2章节审核保持历史原状，未机械更新摘要。旧工具通过quality:l3:legacy保留为历史诊断；quality:l3为当前全站审核检查。quality:deepdives检查正文变化的页面及所有已采用v4的页面，之后仍执行浏览器与既有L4流程；未升级的改动页明确返回audit-upgrade-required，未改变的历史页面不被冒充v4通过。

CI 使用 DEEPDIVE_BASE_REF / GITHUB_BASE_REF 对应的提交基线，包含已经提交的变化；本地无配置时比较 HEAD 与工作区。CI 无基线时检查全部页面，指定基线不存在时明确失败。v4 的模板化表达结论来自独立整页审查证据，提交与人工终审不再额外叠加旧句式计数门禁；原内容生成和候选准备的保护规则未变更。

所有生产访问经MCP。新增完整控制器接口：stage2_inspect_audit_upgrade只读检查；stage2_queue_audit_upgrade按候选摘要保存历史并排队。只允许hold启动，拒绝活动租约，不开放给审查或返修代理。

迁移期间设置 auditUpgradePublicationHold，禁止审查结果刷新网站草稿；已有人工批准的页面也不会仅因补审被重写成待审页。工作流状态与既有发布状态分别保留，显式人工终审成功后才解除迁移发布保持。

审查材料隔离同时覆盖临时预览、嵌套备份、旧生成回复与任务包；读取前规范化路径，链接解析后再次检查实际目标。搜索不进入这些目录或链接。神经网络一次试点因搜索暴露旧材料摘要而停止，未预检、未提交；修复及隔离测试通过后，已用全新无继承审查者重新开始，该中止轮不计为独立审核证据。

后续试点还发现页面 quality 字段自带旧式答案元数据。v4 审查任务包与分段合同现仅交付 pageContentHash 绑定的 title、subtitle、thesis、html；原始 data/deepdive 与 runtime 文件在 v4 审查读取和搜索中均屏蔽，避免重新带入旧答案。隔离夹具已验证初始包、续读合同、原始文件读取及搜索均不会泄漏这类元数据。发现该问题的神经网络轮次提出三项内容阻断，但已保存为历史线索；后续全新审查者实测确认材料净化，并完成独立全文验收，最终两项事实阻断、五项建议，未自动沿用旧结论。

## 验收进度

隔离测试覆盖证据错位、逐章覆盖缺口、缺少机制、伪造不适用、明确公式漏审、日期/正文/规则摘要漂移、旧版本误升级、定向冒充全页、人工发布边界、发布失败回滚、迁移历史保留及不存在/失配旧参照页时的新版CLI。还覆盖 CI 提交基线、本地变化、历史未改页面、无基线及无效基线。历史状态机和MCP权限测试保持通过。

真实机制试点已完成：信息论13章/7概念、监督学习11章/8概念均零阻断，进入人工终审；神经网络13章/12概念的最终独立审核发现两项事实阻断，记录完整但准确性和讲解专家审核均未通过，停在人工审查且保留原发布。具体回执见PHASE1_3_CURRENT_REVIEW.md。机制改造通过不等于130页完成补审，下一步仍属第三阶段的受控内容返修及其余页面核验。
