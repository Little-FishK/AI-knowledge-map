# 前沿来源准入审核机制

版本：2.0｜修订日期：2026-09-23

本机制只回答：**这个来源是否具备进入前沿来源池的资格？合格的全部可以进入，不设名额，不作择优淘汰。** 代表性成果只是来源资格的证明，不是本轮选出的展示内容。具体收录、展示、排序、逐条事实审核与授权另行处理。

## 1. 经典与前沿分开

- 前沿：目前仍产生原创贡献，并已进入独立主体的研究或实践链条，采用下述四道闸门。
- 经典：凭长期影响与历史价值审核，不套用近 12 个月首创要求；完整经典审核办法另定。本轮不批量认定经典来源。
- 同一来源可以兼具两种资格；前沿活跃度下降不抹除其历史贡献，也不自动获得经典资格。

## 2. 先明确审核对象

审核单位是“发布主体 + 原创栏目/项目集合 + 产物类型 + 专业范围”。例如审 Sakana AI 的原创研究与系统，而不是只审某篇论文，也不是给整个网站所有栏目授信。

| 角色 | 如何处理 |
|---|---|
| 原创发布者 | 研究团队、企业、个人、评测机构等；按四闸门审核来源资格 |
| 原件发布渠道 | arXiv 等作者投稿托管平台；登记渠道身份，原创资格归属实际作者或团队，平台不整体继承入驻者资格 |
| 发现入口 | 搜索、索引、新闻聚合等；可帮助发现来源，但转引他人产物不证明其自身原创资格 |

同一机构可以同时承担以上角色。检索服务不合格不代表其自研数据集、研究栏目也不合格；后者应另建明确范围的来源记录。不得仅凭“个人创作者”“咨询机构”“企业”等身份排除其原始研究、数据或测量。

## 3. 四道闸门

每项记为 pass（通过）、fail（明确不符）、unknown（证据不足）；短路后未审项目记 not-assessed，不能伪造为不通过。

| 闸门 | 来源层面的判断 | 最低可核查证据 |
|---|---|---|
| 一手 | 在所审范围内，是否确实创造并发布原始产物？ | 可追溯的原件及作者、机构或维护者归属；论文、模型、系统、原始数据、测量、方法或标准均可 |
| 首创 | 近 12 个月内是否至少发布过一项实质原创贡献？ | 原件链接、首次公开日期，以及一句具体贡献说明；包括新方法、新系统、新数据、新测量及实质性版本贡献 |
| 应答 | 该来源的产物是否已被独立主体实质引用、采用、复现、比较或批评？ | 至少一项可定位的外部证据，说明谁、针对什么、做了什么，并核查公开作者与机构关系 |
| 归属 | 该来源的专业范围是否对应网站已有节点或知识区？ | 至少一个现有节点 ID 或知识区及对应理由；只判断专业相关性，不要求现成展示位置 |

**四项可以用多项代表性成果共同证明。首创与应答不必对应同一成果，应答不受同一个 12 个月窗口限制。** 所有证据必须属于所审来源与专业范围；不能借母公司、兄弟团队或无关领域的成绩补齐。

### 首创如何避免误判

“首创”表示它贡献了自己的新产物，不要求证明全球第一、世界领先或不可替代。新测量和实质数据扩展可成立；搬运、换标题、重新包装或无实质变化的版本号不成立。

用首次可核查公开日期；论文早于博客发布时取论文日期。旧成果新版只有新增贡献本身可以计入新窗口。检索抓取时间、页面更新时间不能替代产物日期。审核日为 D，窗口从 D 往前 12 个日历月起算至 D，含端点。

### 应答如何避免误判

应答证明已进入外部工作链条，不证明结论正确或获得赞同。实质批评同样算应答；使用已发表结果作明确比较可以算比较，不能称为复现。

自引、同一团队账号、共同作者成果、新闻照抄、简单镜像、社交转发及无实际使用的链接不单独满足应答。受资助或合作产生的材料须说明关系，不能直接当独立证明；另找独立证据。独立性只按公开信息核实，关系不明记待核实。

没有找到某一项成果的应答，应继续检查该来源其他代表性产物。首次试审可先查 2—3 项代表作，仍不足则列待核实；这只是工作安排，不是成果数量门槛。

## 4. 判定与准入

| 结果 | 条件 | 动作 |
|---|---|---|
| 通过 | 四闸门全部通过 | 具备入池资格；不因已有同类来源、名气小或名额限制拒绝 |
| 待核实 | 未发现明确不符，但关键证据缺失或冲突 | 指明缺哪项证据，继续补证，不冒充淘汰或通过 |
| 不符合当前前沿资格 | 有可明确解释的不符项 | 写清所审范围与原因；发现入口、原件渠道等角色可另行登记 |

审核发现对象其实是平台渠道时，先修正角色，不强行把全平台当原创发布者评分。若要审核其自研项目，明确项目范围后再走四闸门。

取消将 S/A/B 等级作为来源准入门槛。旧等级不替代证据、不能抵消任何闸门；本文也不赋予通过来源的任意内容直接支撑正文断言的权力。

## 5. 审核记录模板

每份记录保存：来源名称、审核范围、角色、已有目录 ID（新候选留空）、审核日、窗口起点、四闸门分别的结果与理由、证据、总体决定、限制、下次复核日。

每条证据记录 URL、产物名称、作者/机构、首次公开日期（适用时）、查阅日期、页面内定位及它证明的具体闸门。应答证据另记与来源的公开关系、应答类型及对应产物。一个证据可证明多项，不要求凑链接数。

总体决定使用 admitted / pending / ineligible；仅登记渠道身份时使用 channel-only。已有目录条目也必须提供证据，不因以前入选自动通过。

## 6. 复核与维护

建议每 180 天复核一次来源资格；来源停止更新、归属变更、证据撤回或链接迁移时提前复核。这是人工流程建议，本次没有配置自动任务。

- 新窗口缺乏原创贡献时，标记前沿资格待复核；查证不再满足后退出活跃前沿池，保留历史审核记录。
- 页面短暂不可访问或拒绝自动抓取时，记待核实并寻找原件备份，不能据此认定来源已关闭。
- 一项应答证据失效时检查其他代表性证据，不把一篇成果的问题直接扩展为来源整体不合格。
- health、回访频率和链接存活是维护状态，不是可信度排名。
