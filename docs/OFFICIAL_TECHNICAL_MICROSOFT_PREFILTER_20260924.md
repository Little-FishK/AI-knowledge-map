## 口径修正

按 Microsoft Learn 官方站点地图和 Microsoft 官方仓库逐条枚举后，原先聚合估算的 4,167 份修正为 **4,158 份唯一候选**。差异来自官方仓库中“文档目录”与实际技术正文文件的精确边界；本次结果以 4,158 份逐条 URL 记录为准。
