# AI 知识地图 — 知识结构展示

> 目的：在做成品前，用一个**真实的知识切片**把我们定下来的结构具象化，让你直观看到"长什么样"。
> 配套：设计规格见 [SPEC.md](SPEC.md)。本文只负责"展示结构"，用的是一小块真实内容做样例。

---

## 0. 一图看懂：五个结构要素怎么叠在一起

```
        用途大区（横向分区）              叠层（纵向稳定度）
   ┌──────┬──────┬──────┬──────┐        ▲ 越上越新/易变
   │ 编程  │ 应用  │ 内容  │ 追前沿 │   L2  │ 新闻/项目/案例（天~周）——住在详情页
   │ Agent│ 搭建  │ 生成  │       │   L1  │ 新技术/新概念（月~季）——多为新节点
   └──────┴──────┴──────┴──────┘   ────┼──────────────────────
   ┌───────────────────────────┐  base │ 教科书级稳定知识（年）
   │      🧱 基础 / 共享区        │       └──────────────────────
   │  （所有用途共享的公共底座）    │
   └───────────────────────────┘

   节点之间：主干树（父子，负责"整理导航") + 跨边（有类型，负责"展现联系")
   点一个节点：先出【卡片】→ 再进【详情页】（详情页承载 L2 的新闻/项目/案例）
```

五个要素：**① 用途分区（横）· ② 叠层（纵）· ③ 主干树 · ④ 跨边 · ⑤ 卡片→详情页**。下面逐一用真实样例展开。

---

## 1. 主干树（负责"整理"和"导航"）—— 借鉴 aiknowledgemap 的长处

每个节点只有一个 `primary_parent`，形成一棵干净、可折叠、可导航的树。下面是一块**真实切片**（LLM 应用相关）：

```
🧱 基础 / 共享  (foundations)
├── 神经网络
│   └── Transformer
│       └── 注意力机制
├── 词嵌入 (embeddings)
├── 大语言模型 (LLM)
└── 训练
    ├── 梯度下降
    ├── 反向传播
    └── 强化学习
        └── PPO

🔧 应用搭建  (building)
├── RAG
│   └── 向量数据库
├── 微调 (fine-tuning)
└── 提示工程

💻 编程与 Agent  (coding)
└── Agent
    ├── 工具调用 (tool use)
    └── MCP
```

树的价值：**分门别类、一眼看到层级、可以折叠展开**。但它有个致命缺陷——一个节点只能挂一个父亲，表达不了"跨分支的联系"。这就要靠下一节的跨边。

---

## 2. 跨边（负责"展现联系"）—— 补上纯树缺的东西

跨边横跨主干树的不同分支，是**有类型、有方向、按颜色区分**的。同样用上面那块切片，把真实联系连起来：

| 跨边（起点 → 终点） | 类型 | 颜色 | 为什么树表达不了 |
|---|---|---|---|
| 注意力机制 → Transformer | `part-of` 🟦 | 蓝 | （这条其实是父子，树能表达）|
| Transformer → 神经网络 | `is-a` 🟩 | 绿 | 同上，树内 |
| Transformer → 大语言模型 | `enables` 🟪 | 紫 | **跨分支**：架构区 → LLM |
| 梯度下降 → 反向传播 | `prerequisite` 🟧 | 橙 | 学习路径，先懂 A 才懂 B |
| RAG → 词嵌入 | `uses` 🟨 | 黄 | **跨大区**：应用搭建 → 基础区 |
| RAG → 向量数据库 | `uses` 🟨 | 黄 | 依赖 |
| Agent → 大语言模型 | `uses` 🟨 | 黄 | **跨大区**：编程 → 基础区 |
| RAG ↔ 微调 | `contrast` ⬜ | 灰 | 常被拿来二选一 |
| GRPO → PPO | `variant-of` 🟥 | 红 | 前沿技术是老技术的改进 |
| Agent → 工具调用 | `related` ⬜ | 淡灰 | 弱相关兜底 |

**看图理解**（同一块切片，加上跨边后的样子，虚线=跨边）：

```
   基础/共享区                              应用搭建区            编程区
   ┌─────────────────────────┐          ┌───────────┐        ┌──────────┐
   │ 神经网络                  │          │ RAG        │        │ Agent    │
   │   ▲ is-a                 │          │  │ uses    │        │  │ uses  │
   │ Transformer ──enables──────紫────▶ 大语言模型 ◀──────黄──────┘         │
   │   ▲ part-of              │  紫      │  │         │  黄    │           │
   │ 注意力机制                │          │  ▼ uses   │        │ 工具调用   │
   │                          │          │ 向量数据库 │        └──────────┘
   │ 词嵌入 ◀──────uses(黄)──────────────┤  RAG      │
   │                          │          │  ⋯contrast(灰)⋯ 微调
   │ 训练 › 强化学习 › PPO ◀──variant-of(红)── GRPO(L1新)
   └─────────────────────────┘          └───────────┘
```

一句话：**树让你"找得到"，跨边让你"看得懂它和谁有关系"。** 这正是纯 aiknowledgemap 做不到、而我们要的。

## 3. 叠层（负责"分基础 / 活跃"）

同一个概念领域，纵向按"稳定度"叠三层。以 **Transformer 及其周边**为例：

```
  L2 news   ┆ 📰 2026-07 某实验室线性注意力新论文（详情页里的一条动态）
  （天~周）  ┆ 📰 新开源推理框架 vLLM x.x 发布
  ──────────┼───────────────────────────────────────────
  L1 emerging┆ 🌱 Mamba（新架构，alternative-to Transformer，正在观察是否站稳）
  （月~季）  ┆ 🌱 GRPO（新训练算法，variant-of PPO）
  ──────────┼───────────────────────────────────────────
  base      ┆ 🧱 Transformer / 注意力 / 词嵌入 / PPO …（教科书级，年尺度才变）
  （年）     ┆
```

- **base** 常驻主图骨架。
- **L1（emerging）** 多以**新节点**出现，挂在相关 base 节点上；亮度=热度。
- **L2（news）** 多为**详情页里的动态条目**，不一定成节点；带时间戳，会随时间变暗/下沉/归档。
- **会向下沉淀**：某个 L1 概念若被证明持久（反复出现、成公认基础），人工确认后可降为 base（如 RAG 就是从 2020 的前沿逐渐沉淀为近乎基础）。

## 4. 用途分区（负责"第一眼的组织方式"）

大区**按"我怎么用 AI"分**，不按学科。基础区是所有用途共享的底座：

```
  🧱 基础/共享   Transformer · 注意力 · 词嵌入 · LLM · 训练 · 强化学习 …
  💻 编程与Agent  Agent · 工具调用 · MCP · 代码生成 …
  🔧 应用搭建    RAG · 微调 · 提示工程 · 向量数据库 · 评测 · 部署 …
  🎨 内容生成    文生图 · 文生视频 · 语音合成 …
  📰 追前沿      新模型 · 新论文 · 新项目（活跃层重灾区）
  ⚖️ 安全与对齐   对齐 · 越狱 · 评测 · 可解释性（横切关注点）
```

> 用途大区里的节点，通过跨边（多是 `uses` / `enables`）连回 🧱 基础区。例如"RAG"住在应用搭建区，但 `uses` 词嵌入（基础区）——这条黄色跨边就是"用途"和"底座"的桥。

## 5. 卡片 → 详情页（负责"点开之后看什么"）

## 7. 小结：五个要素各司其职

| 要素 | 解决什么问题 | 灵感/出处 |
|---|---|---|
| 主干树 (`primary_parent`) | 整理、导航、折叠 | 借鉴 aiknowledgemap |
| 跨边（8 类，全展示） | **展现概念间联系**（需求#1） | 补 aiknowledgemap 的短板 |
| 叠层 (base/L1/L2) | 分基础/活跃，防资讯撑爆 | 你的 D4 |
| 用途分区 | 贴合"对我有用"的组织视角 | 你的 D3 |
| 卡片 → 详情页 | 点开看什么，活跃内容的落脚点 | 你的 D4 |
