## 1. 目标回顾（一句话）

一个可离线双击打开的**纯静态 AI 知识网**：概念之间用有类型、有方向的边连接，以用途大区、核心视图和聚焦模式降低复杂度；概念详情可继续进入“理解原理”深读页。新资料通过会话内的半自动入库流程变成可审核提案，确认后合并进 `data/graph.js`。

当前数据规模：**112 个概念、330 条边、23 个核心节点、25 个深读页、62 个软件条目**。23 个核心节点均已有深读页。

│  ├─ graph.js           # 概念、边、核心列表与固定坐标
│  ├─ software.js        # 软件目录
│  └─ deepdive/          # 每个概念一份“理解原理”页
├─ docs/
│  ├─ SPEC.md            # 设计规格
│  ├─ NODES.md           # 节点标准与全量清单
│  ├─ SOFTWARE.md        # 软件收录标准
│  ├─ DEEPDIVE.md        # 深读页标准与覆盖进度
│  ├─ INGEST.md          # 半自动入库规范
│  └─ plan.md            # 本文件
└─ tools/
   ├─ validate.js / validate-software.js
   └─ proposals/         # 人工审核过的入库提案

**关键约束**：`index.html` 双击能直接打开。数据使用 `data/graph.js` 注册到 `window.GRAPH`，不通过 `fetch` 读取本地 JSON，因此无需本地服务器。

## 4.5 写作规约（2026-07-19 补，源于一次真实的返工）

### 正文骨架
每个节点的 `body` 按固定四段写，缺任何一段都算没写完：

1. **是什么** —— 定义，一句话能说清就别写三句
2. **为什么会这样** —— 机制。**这一段最容易被跳过，也最有价值**
3. **它约束/影响了什么** —— 和别的概念的因果关系
4. **怎么应对 / 怎么用** —— 可操作的建议，最好带优先级

> 反面教材：早期版本在「上下文窗口」里写了一句「这被称为中间迷失」就结束了——
> 说了现象，没说成因，没说对策。读者拿到一个名词，然后无路可走。

### 内联引用
正文里提到其他概念时用 `[[node-id]]`，渲染成可点的链接。
**不要重复解释别的节点已经讲过的东西**——链过去就行。这既是给读者的路径，
也是防止正文无限膨胀的闸门。

### 节点粒度：写作时才能发现的那一半
**清单定骨架，写作发现器官。**

节点清单（`tools/concept-checklist.md`）是在动笔之前定的，且颗粒度继承自外部目录
（roadmap.sh / aiknowledgemap）。这导致一个系统性偏差：**外部目录里没有的概念，
清单里也不会有**——即使它对理解这个领域很关键。

而「需要哪些节点」这件事，只有在写正文、要向读者解释某个机制时才会暴露。

> **规矩：写正文时，如果发现自己在解释一个「有自己的成因和对策」的东西，停下来——它该是个节点。**

判据仍是 SPEC §3.1：有独立身份、值得单独一张卡片、能与其他概念连线。

补网工具：`node tools/audit-mentions.js` 扫出正文里被强调但不是节点的词。
**但它只是线索生成器**——实测误报率高（会抓到小标题和举例），漏报也不少
（没加粗的概念抓不到）。别指望它替你做判断。

## 5. 验证方式

当前采用“数据校验 + 实际驱动网页”两层验证：

- 每次改 `data/graph.js` 后运行 `node tools/validate.js`。
- 每次改 `data/software.js` 后运行 `node tools/validate-software.js`。
- 深读页至少检查脚本可加载、注册 id 与节点 id 对齐；核心节点覆盖率应保持 100%。
- 发布前用浏览器打开 `index.html`，检查控制台、搜索、筛选、聚焦、详情、软件模式、深读页和移动端布局，并留截图记录。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| **毛线球**：112 节点、330 条边全开时会糊 | 默认核心视图 + 聚焦模式 + 按边类型和大区过滤；全量图用于查找，不作为默认入口 |
| **内容长歪**：外部学术目录和用途分区打架 | 节点标准以 `NODES.md` 为准，外部资料只作选题与事实核对，不直接继承其树结构 |
| **入库长出重复节点** | aliases 字段从一开始就认真填；提案必须显式列出"疑似重复"供审核 |
| **`file://` 限制** | M0 直接用 `graph.js` 内嵌方案绕开 |
| **范围膨胀** | v1 明确非目标：无账号、无后端、无定时抓取（SPEC §1） |
