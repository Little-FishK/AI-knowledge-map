# 「理解原理」门禁真实缺陷目录

版本：1.0  
日期：2026-07-25  
样本范围：监督学习、信息论、损失函数、梯度下降、无监督学习、强化学习六页

## 1. 用途

本目录把真实阅读障碍转换成门禁回归样本。它不是修改日志，也不以“出现了某个组件”代替教学质量。每条正式规则必须能够追溯到这里的缺陷、说明自动检测边界，并配有应通过与应失败的夹具。

详细逐页证据位于：

- [监督学习](deepdive-reviews/supervised-learning.md)
- [信息论](deepdive-reviews/information-theory.md)
- [损失函数](deepdive-reviews/loss-function.md)
- [梯度下降](deepdive-reviews/gradient-descent.md)
- [无监督学习](deepdive-reviews/unsupervised-learning.md)

## 2. 已记录的 48 条错误

### 2.1 监督学习（7）

1. “常见误解”被跨章节正则污染，出现超长重复斜体正文。
2. 二分类手算中标签、概率和正确类别概率的叙述不连续。
3. 自测后三题难度突然跃升，答案没有满足题目中的显式约束。
4. 标签被反复写成绝对“正确答案”，掩盖标注噪声和任务约定。
5. 官方第 1 页把后续节点列成先修，形成循环依赖。
6. 自监督归类和评测结论表述过度绝对。
7. 分类工程判断只讲总体准确率，缺少类别不平衡、阈值、错误成本和部署分布。

### 2.2 信息论（10）

1. 交叉熵只有关系式，没有“在真实分布下使用模型编码的平均代价”这类核心定义。
2. KL 在没有由熵和交叉熵推导的情况下突然出现。
3. 用欧氏距离作反面对照，却没有定义欧氏距离。
4. 困惑度定义过短，“有效候选数”类比缺少适用边界。
5. `P` 与 `Q` 晚于依赖它们的公式和案例才获得解释。
6. 官方早期节点存在循环先修。
7. 总体交叉熵与有限训练集上的经验损失混淆。
8. 自测被通用工厂题污染，问题引入未教授的评测和工程词汇。
9. `log`、`log₂`、`ln` 与 bit、nat、指数还原口径不一致。
10. 使用普通 `√` 字符模拟根式，横线没有覆盖完整被开方表达式。

### 2.3 损失函数（10）

1. 经验风险公式一次引入大量符号，没有逐项绑定自然语言角色。
2. 交叉熵对照样本不完全满足题干声称的比较条件。
3. “成交率、满意度、可微代理”等产品术语没有铺垫。
4. 手算突然设定 `w=2`，没有说明它是初始参数及其单位。
5. MSE、MAE、Huber 没有兑现“解释误差假设”的学习目标。
6. “损失必须是标量”表述过度绝对。
7. 批量损失与梯度估计混为一谈。
8. 梯度与链式法则早于官方学习顺序，且未标成预告。
9. 对数底数与信息论页不一致。
10. 最终自测被通用题追加污染。

### 2.4 梯度下降（10）

1. 更新公式解释不足，`w=2` 再次无定义出现。
2. 核心章节几乎只有数学式，缺少直觉、数值锚点和结果解释。
3. “狭长谷地”没有映射到损失曲面、不同方向曲率和震荡现象。
4. “硬件效率代价高”没有落到时间、吞吐、显存或通信等可观察资源。
5. SGD、Momentum、Adam 未定义便直接比较。
6. warmup、decay、clipping、detach 等新概念密集出现并互相借词解释。
7. 把多变量微积分当作读者已经掌握的前置知识。
8. 诊断步骤列出术语，却没有形成“看到什么—意味着什么—下一步做什么”。
9. 小批量梯度的统计作用与硬件计算作用混在一起。
10. 最终自测被通用问题追加。

### 2.5 无监督学习（5）

1. 逐步演算章节从答案开始，没有在局部重新建立案例对象、特征、单位、目标和计算规则。
2. PCA 公式中的 `W` 等符号无定义，整节使用密集专业术语互相解释，缺少新手入口。
3. “轮廓系数”首次出现即参与结论，没有定义比较对象、公式、取值范围和解释。
4. 密度估计直接从最大似然公式开始，没有说明任务输入、输出、用途和“低密度”的实际含义。
5. 同页降维采用完整新手教学链，密度估计和内部指标却只列术语，核心任务之间没有沿用统一解释标准。

### 2.6 强化学习（8）

1. MDP 首次出现时只有状态—动作—奖励的一句压缩描述，没有说明对象职责、策略输入输出和最终学习产物。
2. 折扣回报公式没有逐项解释 `t`、`k`、`r`、`γ` 与 `G`，也没有局部数值锚点。
3. Bellman、DQN、优势、Actor–Critic 和 PPO 连续出现并互相借词解释，新手无法建立价值法与策略法的区别。
4. “奖励与环境是边界”只有结论，没有说明代理错位、状态遗漏、模拟器缺口和权限约束各自怎样失效。
5. 自测前五题答案只有一句定义，不能检验公式计算、机制解释、工程边界与风险切片设计。
6. 工厂曾用徽章文本推断章节角色，使核心“消歧”章节被排除、参考章节被纳入六问检查；章节角色必须依据显式角色或标题语义。
7. “必须探索”只给结论，没有解释动作价值来自有限样本、纯贪心会停止收集反证并把早期估计误差永久固定。
8. ε-greedy、熵奖励和置信上界被压缩在一句话中，没有分别说明选择规则、解除锁死的机制和适用边界；流程图底部结论与上方节点的视觉间距也不足。

## 4. 成熟规范的职责

### LORI：单页学习对象质量主体

采用内容质量、学习目标对齐、呈现设计、反馈、可用性和可访问性维度。LORI评分必须由审查者给出具体证据，不得转换为字数、公式数或关键词数量。

### Quality Matters：目标对齐与认证过程

采用目标—材料—活动—评测 Alignment，以及关键项必须通过、多人评审和认证失效机制。QM面向课程，因此本项目只抽取适合单页的对齐与审查过程。

### CAST UDL 3.0：认知可达性

采用词汇与符号澄清、数学记号解码、连接前置知识、突出关系、迁移和渐退支架。它为概念依赖和符号首次使用规则提供依据。

### WWC 循证教学指南：数学与科学教学链

采用完整例题与自主问题交替、图文结合、抽象与具体表示连接、主动提取和深层解释题。它不规定本项目的符号格式，领域细节由数学附件补充。

### ISO 24495、WCAG、Vale、SonarQube

- ISO 24495：简明、可理解、可使用的语言。
- WCAG：可感知、可操作、可理解和稳健的页面。
- Vale式规则：一致用词、缩写、绝对化措辞等可复现 lint。
- SonarQube式门禁：明确 issue、blocker 为零、新增问题阻断；不把代码门禁指标直接当作教学质量指标。

## 5. 当前门禁缺陷

1. 规范声称检查认知连续和目标映射，代码实际主要统计长度、章节、目标、引导语、图表、公式和关键词。
2. “高阶问题”由“为什么、如何、设计”等词命中，无法证明问题具有迁移价值。
3. “机制闭环”由输入、变换、输出、反馈和边界等词命中，无法证明它们属于同一因果链。
4. 通用补全脚本会生成门禁奖励的题目、诊断、案例和机制段落，形成自我刷分。
5. 维度最低分只能防止代理分跨维度补偿；真正的语义 blocker 没有进入问题模型。
6. L4具备证据映射和独立审查设计，但常规 CI 不要求当前有效认证。
7. 故障夹具没有覆盖符号未定义、案例条件错误、答案不满足约束、单位冲突和跨页先修倒置。
8. 历史基线只记录评分缺口，没有记录缺陷责任、失效日期和修复进度。
9. 术语复核只在同节累计多个词时触发，单个关键新概念可以漏检；旧记录也没有分别证明概念“是什么”和“有什么用”。

## 6. 规则准入合同

每条新增门禁规则必须包含：

1. 稳定规则 ID；
2. 对应的真实错误记录；
3. `blocker`、`review-required` 或 `advisory` 严重度；
4. 明确、可复现的检测证据；
5. 一个应通过夹具和一个应失败夹具；
6. 误报边界与有限豁免方式；
7. 适用页面类型；
8. 负责人、加入日期和复审日期。

没有失败夹具的自动规则不得成为合并阻断项。无法稳定自动判断的教学要求必须进入 L4，不得用关键词近似后宣称已经验证。

## 7. 全量迁移阶段新增记录（2026-07-27）

1. 多模态生成与安全治理的后期长页已经具备定义、机制、案例、失败边界和评测内容，但仍停留在旧合同，导致“页面内容较好、门禁却无法逐节追责”。现已为每个核心章节登记六问本地证据。
2. 扩散模型、图像生成和对齐仍采用较短的旧模板：章节能讲主线，却没有稳定交代输入输出、结果解释和不能推出什么。现已逐节补入这些信息，并新增或明确标记完整案例。
3. 多个运行示例只把“运行示例”写在标题外的徽章中，正文标题本身没有案例语义，导致案例合同无法可靠绑定。现要求案例类型进入标题或显式 `data-worked-example`，不能依赖装饰徽章。
4. 生成、安全与治理批次仍有 28 个公式使用整行电脑符号。现统一迁移为 MathML，并把变量、数值、运算符和上下标拆为数学节点；根号必须用 `<msqrt>` 覆盖完整被开方项。
5. `模型家族`页虽有独立误区表，但没有在首次混淆点设置局部消歧警告，造成同页教学密度不均。现补充“架构—模型—产品”三层消歧。
6. 自动合同生成可以验证“六类证据均在本节存在且互不复用”，但不能证明证据与问题在语义上完全等价。迁移器因此采用语义线索优先取证；自动结果仍只属于 L3，不能冒充 L4 独立教学审校。
