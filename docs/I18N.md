## 1. 语言合同

| 项目 | 决定 |
|---|---|
| 权威源语言 | `zh-Hans`（简体中文） |
| 首个目标语言 | `en`（通用英语） |
| 默认语言 | `zh-Hans` |
| 语言标识 | 使用 BCP 47；在确有地区差异前不拆分 `en-US` / `en-GB` |
| 用户入口 | 设置 → Language |
| 初次选择优先级 | URL → 用户已保存选择 → `navigator.languages` → `zh-Hans` |
| 用户偏好 | 计划保存到 `localStorage`，键名固定为 `ai-knowledge-map.locale.v1` |
| 页面语言 | 切换时同步设置 `<html lang>`；文字方向由语言配置给出 |
| 格式化 | 日期、数字、列表、复数和排序使用浏览器 `Intl` API |
| URL | 新路由计划支持 `#/zh-Hans/...` 与 `#/en/...`；现有无语言段路由保持兼容 |
| 正文回退 | 目标语言整页/整条缺失时明确提示并回退到中文，不静默拼接混合语言 |

运行期语言选择必须满足：用户手动选择永远覆盖浏览器自动判断；切换语言保留当前节点、软件、教程或资料 ID，不返回首页。

## 2. 稳定身份与禁止翻译项

以下内容是跨语言共享的结构或身份，不得翻译或复制出语言分支：

- 节点、软件、教程、资料和平台的 `id`；
- Hash 路由中的实体 slug；
- 边的 `from`、`to`、`type` 与图谱拓扑；
- 节点坐标、核心节点集合、推荐学习路径结构；
- `domain`、`cat`、`platform`、`maturity`、`activity`、审核状态等枚举值；
- URL、日期原值、哈希、版本号、来源 ID；
- 数学公式、代码、HTML 的 `id` / `class` / `data-*` 属性；
- `[[concept-id]]` 内部链接目标。

产品名、模型名、机构名、作者名和论文标题默认保留官方写法。只有存在可靠的官方本地化名称时才提供本地化显示名；外部资料标题不得用译文覆盖原题，可另设译名字段。

## 3. 翻译单元命名

界面消息使用稳定、语义化、英文小写点分键，不使用中文原文充当键：

```text
nav.graph
nav.software
settings.title
settings.language.label
controls.sidebar.collapse
search.results.empty
```

变量使用命名占位符，例如 `{count}`、`{title}`。同一个键的所有语言必须拥有完全相同的占位符集合。不得通过字符串片段拼接完整句子。

## 5. 回退与发布状态

### 5.1 界面消息

- 开发环境可以临时显示中文回退并记录缺失键；
- 英文正式发布前，英文界面键必须 100% 完整；
- 缺键、占位符不一致或重复键均属于发布阻断项。

### 5.2 结构化内容和长篇正文

翻译状态固定为：

```text
draft → reviewed → published
                    ↓
                  stale
```

- `draft`：不可作为正式英文内容；
- `reviewed`：完成内容与结构复核，等待发布；
- `published`：可展示；
- `stale`：中文源已变化，继续显示前必须带明显提示，或回退到中文。

回退以完整记录或完整页面为单位，不允许一个正式页面在没有提示的情况下逐字段混用中英文。

## 9. 阶段 3：设置接入与发布门控

本阶段完成以下用户链路：

本阶段新增与中文权威数据相互独立的内容语言层：
