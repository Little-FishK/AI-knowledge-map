# 理解页翻译阶段 9：重组、展示与受控发布

## 当前交付与边界

本阶段接入英文重组、前端按语言加载、整页中文回退、独立英文发布入口及隔离浏览器测试。没有翻译或发布真实页面，没有调用付费 API，没有改变中文正文或中文审核状态，也没有提交 Git 改动。

实现位置：

- `tools/deepdive-stage2/lib/translation-publication.js`：确定性重组、验收合同、受控发布。
- `assets/app/runtime-loader.js`：读取中文源及已批准的英文 JSON，校验内容摘要和版本。
- `assets/app/deepdive-view.js`：正文语言标记、回退提示，保留原有暂行发布警告。
- `tests/stage2/translation-publication.test.js`、`tests/app/deepdive-translation-browser.test.js`：隔离的发布门禁与浏览器测试。

## 数据流

冻结中文及资源 → 收齐 Batch 译文 → 独立整页审查/定点修复 → 确定性英文候选 → 真实候选资源与浏览器验收 → 人工批准精确摘要 → 控制器写入独立英文 JSON。

候选只从质量控制器的当前记录重组，不接受调用者传入任意页面 HTML。逐单元核对源位置、覆盖和注入风险，从后向前替换可译文本/属性。其他结构、链接、代码、公式保护块不改。标题、副标题、别名、元信息和核心命题也纳入译文；英文核心命题按普通文本安全渲染，不将模型输出当成可执行 HTML。含 HTML 的特殊页头必须在试点浏览器验收时检查，不能把裸露标签当成合格排版。

## 发布能力隔离

`translation-publication` MCP 配置绑定 `STAGE2_MCP_PAGE_ID`，只提供：

| 接口 | 作用 |
|---|---|
| `stage2_preview_translation` | 分页返回候选、artifactHash、质量门禁、资源编号和浏览器验收清单；不发布 |
| `stage2_publish_translation` | 对精确版本进行一次发布尝试；没有明确人工授权则拒绝 |

协调者 `full` 只能预览，不能发布英文。审查者和返修者均无发布权限。原中文控制器和角色权限不变。新工具需在下一次受控连接时加载，本轮不重启生产 MCP。

发布须由可信启动方在获得用户明确批准后，将 `STAGE2_TRANSLATION_PUBLISH_HASH` 设置为验收过的 artifactHash。不要由翻译或审查代理自行授权。工具还要求 acceptance：

- `artifactHash`、`approved:true`、`reviewer`；
- `browserChecks`：english、chinese、fallback、rapid-switch、navigation、resources、desktop、mobile、console，每项 `passed:true` 和具体 notes；
- `resources`：预览返回的每个 resource 编号各一条 `key`、`passed:true`、具体 notes；
- `resourceSummary`：图片、SVG、公式、依赖的完整检查结论，包括保护区中是否仍有需要解释或翻译的文字。

这些是绑定版本的**人工验收记录**，不是程序能够证明真实性的浏览器证据，更不代表模型自评就是通过。真实截图、测试报告和实际判断应先交给用户审阅，得到批准后才可启动发布配置。隔离测试中使用的合成证据绝不能用于真实发布。

规则 1、2、3、4、5、7、8 必须已通过。资源和浏览器待审项只能由上述完整验收补齐。中文批准缺失、被重置或撤销的页可以继续准备/审查英文，但此入口不会替它补出中文批准，正式发布仍被阻止。返修或原文、术语、资源、批准状态变化都会使当前候选/验收失效。

质量记录锁保护译文版本；实际写入还通过源控制器锁重新确认完整快照。只写 `data/content-locales/en/deepdive/<pageId>.json`，不改 `.stage2/state.json`、中文页、中文审计或 graph。采用临时文件后原子替换；拒绝目录链接；同版重复请求幂等。已有不同版本不覆盖，必须等明确的替换/回滚流程。

验收者身份和详细笔记保存在独立翻译私有数据目录 `publication-acceptance`，公开 JSON 仅携带验收摘要。私有验收记录表示获得批准，不单独证明文件已发布；必须结合发布结果。发布前中断不会凭一份验收记录自动标为已上线。

## 前端行为

| 情况 | 阅读页行为 |
|---|---|
| 简体中文 | 保持原中文加载方式 |
| 英文已批准且匹配已加载中文内容 | 整页显示英文，正文 `lang=en` |
| 未翻译、未批准、版本不匹配、摘要损坏、字段缺失 | 整页中文，正文 `lang=zh-Hans`，显示英文回退提示 |
| 请求失败、无效 JSON、超时 | 同上，不拼接半页英文 |
| 中文是暂行/编辑草稿 | 中文回退且保留红色质量警告 |
| 直接双击本地 HTML、浏览器无安全摘要能力 | 保持中文可读，英文 JSON 安全回退；英文体验需 HTTP localhost 或 HTTPS |

英文请求不长期缓存，每次打开读取；超时默认 8 秒。图谱/学习导航预加载只读取中文源，避免后台无用英文请求。快速切换/关闭沿用视图请求序号，旧响应不得覆盖新选择。

注意：前端核对的是**当前浏览器已加载的中文正文版本**，不直接读取私有控制器状态。静态网页无法实时知道服务器外部的批准撤销、资源变更或同一会话中未重新加载的中文更新。摘要是完整性校验，不是数字签名。阶段 12 仍须接入失效索引、发布部署联动与回滚；在此之前不能承诺实时撤销。生产部署必须同时包含匹配的中文运行时和英文发布产物。

嵌入图片中的中文不会被本流水线自动改图。无需翻译的图应说明理由；需要英文化的图必须先走独立受控资源处理，重做快照与验收，不能以文字译完为理由放行图片。SVG 可译文字在普通文本单元内时会替换，但必须检查长度和裁切；MathML/代码保护区仍原样保留。

## 测试与重现

`npm run test:stage2` 包含原流程回归、准备、Batch 模拟、质量检查、英文发布门禁。准备新增源锁回调测试；发布测试覆盖重组、越界/注入、精确授权、待审阻止发布、验收完整性、过期、幂等、拒绝覆盖、质量模块联动和 MCP 权限。

`npm run test:translation-browser` 使用 Playwright 与本机 Edge（可通过 `TRANSLATION_BROWSER_CHANNEL` 改用已安装浏览器通道）。运行时需要能解析 Playwright 包。本次使用桌面应用自带依赖，不安装或下载浏览器。

浏览器只服务内存中的合成页面以及现有视图/加载器/样式/UI 字典，不服务生产内容目录。实际点击切换语言、自测、锚点、返回/关闭/Escape；覆盖异常译文、超时、竞争响应、原文更新、暂行警告、桌面/390px 手机宽度和本地文件回退。截图保存在测试输出给出的临时目录。

这是**真实浏览器里的隔离组件集成测试**，不是整站生产点击验收，也不是正式页的语义或图片验收。阶段 10 必须对真实试点重复资源、长表格/长公式、导航和视觉检查。
