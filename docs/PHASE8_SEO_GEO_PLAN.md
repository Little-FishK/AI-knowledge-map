## 实施顺序与验收边界

1. 47/48/49/51 共用元数据及发布资格规则，先建立生成与回归测试。
2. 确认 50 的训练抓取政策与 55 的公开品牌事实，随后实现并发布。
3. 52 接入站长工具，以当前首页、文字目录、监督学习中文页完成首轮真实抓取检查。
4. 53 建立发布差异与通知流程；56 建立基线；54 随内容审核逐页推进。
5. 第二阶段完成后，新增学习入口、导航/面包屑、内容分层的语义与搜索元数据联合复验。

当前可验收的是“全站通用机制完成 + 当前正式发布范围通过”；全量内容覆盖是逐页发布验收；抓取、收录和 AI 引用效果是单独的运行观察，不能混为一个完成状态。

第二阶段结束前不验收：两条学习入口的最终标题/摘要、分层章节最终锚点和可独立引用性、最终可见导航对应结构化数据，以及这些新入口的真实搜索/学习效果。其他任务没有“必须等待所有页齐备”的前置条件。

## 官方依据

- [Google 语言版本](https://developers.google.com/search/docs/specialty/international/localized-versions)：每个版本含自身和真实对应版本，双向链接一致。
- [OpenAI 爬虫](https://developers.openai.com/api/docs/bots)：OAI-SearchBot 与 GPTBot 用途和配置独立。
- [IndexNow 文档](https://www.indexnow.org/documentation)：站点验证、变更 URL 提交；提交不等于收录。
- [Google URL 检查](https://support.google.com/webmasters/answer/9012289)：实时可访问性与已索引结果需要分别检查。
- [Bing URL 检查](https://www.bing.com/webmasters/help/url-inspection-55a30305)：检查索引、SEO 与标记信息。
