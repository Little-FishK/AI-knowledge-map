# 英文页自动排版修复

英文静态渲染器和浏览器验收共用 `translation-layout-repair.js`。字体就绪后，第一阶段按实际文字宽度和节点/列宽换行；第二阶段调整框内行距、扩展节点框和画布。保持全部文字、数字、运算符和字号，不靠隐藏或缩小文字通过检查。复杂变换、无法解决的碰撞继续阻断。

验收在修复后检查 1440、768、390、320 像素宽度，集中记录残留问题。成功回执包含排版修复记录；失败诊断保留缺陷数组和已尝试的修复，不把排版失败冒充语义缺陷。两阶段修复后仍失败，不做无变化重试；其他页照常处理。

MathML 中完整的自然语言 `mi`/`mtext` 标签采用小型确定性词表：教师 → teacher，学生 → student，硬标签 → hard labels。未知标签仍阻断，公式结构、数字、运算符、TeX 和代码不变。真正的公式内容错误继续经过既有语义返修及定向复审；本修复器没有新增允许模型改写受保护数学块的权限。

运行器恢复时，仅对旧版本修复器阻断、且源文与语义门禁仍全部通过的排版失败页重新验收一次。同版本失败不重复入队。不触发定时任务恢复，不调用额外模型；验收通过后沿用逐页自动正式部署队列。
