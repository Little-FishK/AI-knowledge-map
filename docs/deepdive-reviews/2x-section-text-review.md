## 2 神经网络（neural-network）

### 2.1 为什么需要神经网络

本节要回答一个最根本的问题：既然有简单的线性模型，为什么还要更复杂的东西？。 1.1 线性模型的能力到哪里为止 一个线性模型学的是输入的一个 加权和 。以二分类为例，它能画出的分界只有一条直线、一个平面、或更高维里的一个「超平面」——本质上是一刀平的切分。 y′ = w₁x₁ + w₂x₂ + … + wₙxₙ + b。 预测分数 y′ 是加权和的结果；权重 w 决定每个输入的影响方向与强弱，输入 x 是样本特征，偏置 b 决定这条边界整体平移多少。 图示：线性边界无法分开同心环，曲线可以。 图 1 左：内圈一类、外圈一类，任何直线都会同时切错两边。右：一条闭合曲线才能把它们分开。神经网络要造的，正是这种弯曲的边界。 。 1.2 「手工造特征」为什么不够 你可能会说：给线性模型喂一些组合特征（比如 x₁x₂ 、 x₁² 、到圆心的距离）不就弯了吗？确实——特征工程能把一些非线性问题掰成线性。但当输入是几千、几百万维（一张图的每个像素、一段话的每个词），而有用的组合又事先不知道时， 靠人枚举特征会迅速失控 。 神经网络的真正价值 不是「层多」，而是让模型 在训练中自己学出有用的中间特征 ，而不再需要人一个个手工设计。后面会看到，隐藏层就是这些「学出来的特征」所在的地方。 1.3 那「多堆几层线性」行不行 一个自然的想法：既然一层不够，多叠几层线性变换总该更强吧？把两层写出来（先不加任何非线性）：。 h = W₁x + b₁ y = W₂h + b₂。 把第一行代进第二行：。 y = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)。 这里 y 是两层复合后的输出， W₁、W₂ 是两层权重， b₁、b₂ 是两层偏置， x 是原始输入。 数学结论 两个线性/仿射变换复合，结果 仍是一个线性/仿射变换 （记 W = W₂W₁ 即可）。所以无论叠多少纯线性层，整体永远等价于 一层 ——深度本身不产生任何新的表达能力。 这就逼出了下一个问题：既然深度靠「叠线性」换不来能力，那能力到底从哪里来？答案是在层与层之间插入一个 非线性 函数。它是谁、怎么起作用——是第 4 节的主题。在那之前，我们得先把网络的结构讲清楚。 工程提醒：必要，但不是万能 神经网络擅长高维感知数据（图像/语音/文本）、复杂非线性关系、大规模样本。对小的表格数据、需要严格可解释、或几条规则就够的问题，线性模型、树模型或显式规则往往 更合适、更省、更可控 。

### 2.2 网络的结构：它由什么组成

上一节说到「非线性要插在层之间」。那么「层」「节点」到底是什么？本节把结构拆开，看每个零件负责什么。 图示：一个 2-2-1 的全连接前馈网络。 图 2 贯穿全页的最小网络。每条连线是一个可学习的权重 w （高亮那条只是示意其中一条）；每个非输入圆圈是一个节点，先加权求和、再过激活函数。 。 组成； 它是什么； 它解决什么。 输入层； 承载特征向量 x，通常不做学习计算； 把现实对象（像素、词、数值）变成一串数字。 权重 w； 每条连线上的可学习系数； 决定信息被放大、抑制还是反向。 偏置 b； 每个非输入节点的可学习常数； 平移触发门槛，使节点不必过原点。 节点 / 神经元； 先加权求和，再过激活函数； 检测某一种模式并输出响应强度。 隐藏层； 输入与输出之间的中间层； 逐层形成对任务更有用的新表示。 激活函数 φ； 作用在加权和上的非线性函数； 打破「多层仍等于一层」的线性坍缩。 输出层； 把最终表示映射为任务输出； 产生数值、概率或类别分布。 。 2.1 一个节点到底算了什么 z = w·x + b = Σᵢ wᵢxᵢ + b a = φ(z)。 z 叫预激活值； a 是节点过完激活后、传给下一层的输出。 把节点想成「可学习的模式探测器」 向量 w 指定它关心哪个方向；点积 w·x 衡量输入与这个方向有多吻合；偏置 b 调节它多容易被触发；激活函数决定这份响应怎样通过。一个节点，只会检查 一种 模式。 2.2 为什么一层要放很多节点 既然一个节点只认一种模式，那真实任务往往同时依赖很多模式——于是自然要很多节点。 识别一张图，可能既要看横向边缘、纵向边缘、颜色对比，还要看这些局部怎样组合。所以一层会安排许多节点 并行地看同一份输入 ，各自学不同的 w 和 b 。这一层的输出于是不再是一个答案，而是 m 个探测器响应拼成的 新向量 ：。 a = [a₁, a₂, …, a_m]ᵀ。 下一层不再直接面对原始输入，而是面对这些响应——它可以把若干「边缘响应」组合成「角点」，再把角点组合成「局部形状」。 隐藏层的意义就在这里：它为下一层制造更好用的输入。 。 矩阵只是压缩记号，不是新原理 同时算一层的 m 个节点时，把它们的权重按行排成一个矩阵 W ，就能把 m 条同样结构的式子缩写成一行： z = Wx + b ， a = φ(z) 。看到矩阵不必紧张，它只是「别一条条抄」的省事写法。 2.3 参数量：网络为什么容易变大 一个全连接层，若有 n_in 个输入、 n_out 个节点，参数量是：。 参数量 = n_in × n_out + n_out。 比如我们的例子 2 输入 → 2 隐藏 → 1 输出： (2×2+2) + (2×1+1) = 9 个参数。真实网络动辄上亿。参数越多、表达力越强，但计算、显存和 过拟合 风险也越大。网络设计的核心不是「越大越好」，而是让容量匹配数据量和任务难度。

### 2.3 前向传播：网络怎样给出答案

结构有了，先看它「正着用」时怎么算出一个预测——这是后面讲「学习」的前提。 前向传播（forward pass）就是从输入到输出，一层层算下去：。 预处理输入 x（标准化数值、编码类别、缩放像素等）。 算第一隐藏层的预激活 z⁽¹⁾ = W⁽¹⁾x + b⁽¹⁾ 。 过激活函数 a⁽¹⁾ = φ(z⁽¹⁾) 。 把 a⁽¹⁾ 当作下一层的输入，重复「线性变换 + 非线性」。 输出层按任务选一个合适的变换，得到预测 ŷ 。 推理 ≠ 训练 真实使用时通常 只做前向传播 ，不改参数，只回答「在当前参数下，输出是什么」。训练则还要多回答三件事：错了多少？每个参数该负多大责任？下一步怎么改？——这正是第 6–8 节要建立的。

### 2.4 激活函数：非线性从哪里来

第 1.3 节欠下的账：能力靠层间的非线性。这个非线性，就是激活函数 φ。 图示：ReLU、Sigmoid、tanh 三种激活函数的形状。 图 3 三种常见激活函数的形状。它们的共同点是 都不是直线 ——正是这个「拐弯」给了网络表达非线性的能力。 。 函数； 公式 / 范围； 典型用途； 主要代价。 ReLU； max(0, z)； 多数隐藏层的稳健起点； z<0 时梯度为 0，可能「死亡」。 Leaky ReLU； max(αz, z)； 缓解死亡 ReLU； 负半轴还要选个 α。 Sigmoid； 1/(1+e⁻ᶻ)，0~1； 二分类输出概率、门控； 两端饱和，隐藏层易梯度消失。 tanh； −1~1； 需要零中心输出时； 仍会饱和。 GELU； 平滑门控； 现代 Transformer 隐藏层常见； 计算略复杂。 Softmax； eᶻⁱ / Σⱼeᶻʲ； 互斥多分类的输出层； 类别多时计算与校准需注意。 。 4.1 ReLU 这么简单，凭什么能造出复杂边界 ReLU 在 z=0 处有一个「折点」。单个 ReLU 节点把输入空间切成「激活 / 不激活」两块；很多节点叠在一起，就把空间切成许多小块， 每块内部近似是直的、块与块之间斜率不同 。层层组合，这些分段直线就能拼出任意复杂的弯曲边界——这正好回应了图 1 里那条「需要曲线」。 4.2 先分清：隐藏层的激活 vs 输出层的变换 你可能会困惑 「Sigmoid、Softmax 不是也常出现在最后一层吗，它们到底算激活还是别的？」——这里要先划清界限，别把两件事混一起：。 位置； 它要回答的问题； 常见选择。 隐藏层； 怎样产生复杂、可组合的内部表示？； ReLU、GELU、tanh。 输出层； 最终答案应该是什么范围和含义？； 线性、Sigmoid、Softmax。 。 隐藏层的激活是为了 制造非线性 ；输出层的变换是为了 把内部数值翻译成有含义的答案 （比如一个概率）。它们长得像，目的不同。 输出层到底选哪种，不能只看它自己，还要连着「任务」和「损失函数」一起定——这个账留到第 6 节还。 。

### 2.5 根本原理：可微分的函数复合

结构、前向、非线性都有了，现在把它们抽象成一句能记一辈子的话。 一句话 神经网络把一个复杂映射，拆成很多简单、 可微分 的小函数首尾相接。 函数复合 提供表达能力（能表示多复杂的关系）， 可微分 提供可训练性（能算出每个参数该往哪调）。这两半，正好对应后面的前向与反向。 5.1 表示学习：层在「换坐标系」 每一层都在 重新编码 上一层的信息。对图像，早层可能响应边缘纹理，中层组合成局部形状，高层再组合成对象部件与类别证据。要点不是这些层一定对应人能命名的概念，而是它们逐层产生了对 最终任务 更好用的坐标系统——这就是「表示学习」，也是 1.1 节说的「自动学特征」的实现。 5.2 深与宽是两个不同的旋钮 维度； 增大它通常意味着； 常见风险。 宽度（每层节点数）； 同一抽象层级上并行检测更多模式； 参数、显存、过拟合上升。 深度（隐藏层数）； 用更多级复合表达层级结构； 梯度传播与优化更难。 。 别被「万能逼近」误导 理论上足够大的网络能逼近几乎任意连续函数，但这 不等于 它容易训练、也 不等于 它能凭空得到数据里没有的规律。表达能力、可优化性、样本效率、泛化能力，是四个必须分开看的问题。

### 2.6 从内部数值到答案：输出层与损失

第 4.2 节欠的账在这里还：最后一个隐藏层给出的还只是一堆内部数值，要训练它，必须连续回答两个问题——这些数值怎样表示答案？答案又错了多少？。 6.1 输出层：规定「答案的含义」 任务； 输出层变换； 输出的含义； 为什么这样选。 回归； 线性 / 无激活； 任意实数； 房价、温度不该被压进 0~1。 二分类； Sigmoid； 正类概率 0~1； 把一个实数压成概率。 互斥多分类； Softmax； 各类概率、和为 1； 类别互相竞争，只能选一个。 多标签； 每类独立 Sigmoid； 每个标签各自的概率； 多个标签可同时成立。 。 可见 4.2 节说的「输出层变换」不是孤立技巧，而是 网络内部表示与真实任务之间的接口 。含义定下来，才能定义一种与之匹配的「错误度量」。 6.2 损失函数：把「错」变成一个可优化的数字 模型没法直接优化「看起来还行」。它需要一个 标量 目标 L ，度量预测 ŷ 与真实 y 差多少。训练就是找一组参数 θ （网络里全部权重和偏置），让训练集上的平均损失尽量低、同时还能推广到新数据：。 θ* = arg min_θ (1/N) Σᵢ L(f(xᵢ; θ), yᵢ)。 N 是训练样本数， i 是样本编号， f 是网络， xᵢ 与 yᵢ 是该样本的输入和真实答案， L 是单样本损失， θ* 是使平均损失最小的参数。 损失； 示例公式； 直觉。 均方误差 MSE； (ŷ − y)²； 大误差被平方放大，常用于回归。 二元交叉熵 BCE； −[y ln ŷ + (1−y) ln(1−ŷ)]； 正确类给的概率越低，罚得越重。 多类交叉熵； −Σₖ yₖ ln pₖ； 只盯真实类别被分到的概率。 。 损失 ≠ 评价指标 损失是模型要最小化的 训练信号 ，必须可求导；准确率、F1、AUC 是给人看的 评价指标 ，往往不可导，因此一般不直接拿来做反向传播的目标。

### 2.7 梯度下降：为什么要朝梯度的反方向走

现在有了一个「错多少」的数字，可网络有成千上万个参数。问题变成：该同时怎样改这些参数，才能让损失下降？。 7.1 梯度先告诉你的其实是「上升最快」的方向 梯度 ∇_θ L 是损失对每个参数的偏导数拼成的向量。关键要澄清一个常见误解：它 不是 直接指向最低点，而只描述当前位置附近——如果朝各个方向都走相同长度的一小步， 沿梯度方向损失升得最快 。 L(θ + εu) ≈ L(θ) + ε ∇L(θ)·u （‖u‖ = 1）。 图示：一维损失曲线上的梯度下降。 图 4 把损失想成一条山谷。梯度指向「上坡最陡」的方向，所以每一步朝它的 反方向 （下坡最陡）走一小段，就能逐步逼近谷底。 。 直接回答标题的问题 梯度给出「最快上升」，取负就是「最快下降」——这就是梯度下降。（顺带：并没有一个唯一的「下降最慢方向」；只要选得几乎与梯度垂直，下降就能慢到接近 0，白白浪费一步。）。 7.2 方向对，还不等于一步到位 负梯度只保证在 足够小 的邻域内最陡。损失面是弯的，步子迈大了可能冲过谷底，所以还要用 学习率 η 控制步长：。 θ ← θ − η ∇_θ L(θ)。 η 太小则训练慢，太大则震荡甚至发散。 把它放进一个循环，就是最基本的训练过程：。 随机初始化参数，打破节点间的对称（见 10.1）。 取一小批数据前向传播，得到预测。 算这批的损失。 反向传播，得到每个参数的梯度（第 8 节）。 优化器按梯度和学习率更新参数。 重复许多批、许多轮，并盯着训练/验证曲线。 术语； 准确含义。 参数 parameter； 模型内部 训练学到 的权重和偏置。 超参数 hyperparameter； 训练者 手动设 的学习率、批大小、层数等。 batch； 一次参数更新用到的一小批样本。 epoch； 训练集被完整过一遍。 iteration / step； 一次「前向 + 反向 + 更新」。 。

### 2.8 反向传播：链式法则如何分配责任

第 7 节反复用到「每个参数的梯度」。可网络有几百万参数，这些梯度到底怎么高效地算出来？。 先纠一个最常见的误解 反向传播 不是 另一种优化器，而是 高效计算梯度的方法 。算完梯度后，真正更新参数的是梯度下降 / Adam。两者分工不同。 它从输出端出发，用链式法则把「一个参数的微小变化」怎样一环环传到损失，逐层相乘：。 ∂L/∂w = ∂L/∂ŷ · ∂ŷ/∂a · ∂a/∂z · ∂z/∂w。 链式法则把「参数变 → 节点变 → 预测变 → 损失变」这条因果链接了起来。 8.1 信用分配问题 一个预测可能是几百万参数共同作用的结果。损失只说「最终错了多少」，没说哪条连接该负责。梯度恰好回答： 只把某个参数增大一丁点，损失会怎么变 。正梯度说明增大它会让损失上升（所以该减小它），负梯度反之。 8.2 为什么不干脆「每个参数试一遍」 一个朴素办法：把某个权重稍微调大，重算一次损失看变化，再调回去换下一个。一百万个参数，就要约一百万次额外的前向计算——不可行。 反向传播抓住了网络里的 共享结构 ：许多靠前的参数，最终都要经过同一个靠后的节点才影响损失。于是只需先算一次「损失对这个后续节点有多敏感」，再把这份结果沿各条进入路径分发下去，就能继续分给更早的参数—— 算过的下游影响不为每个参数重算 。一次从后往前的遍历，就拿到全部梯度。 做法； 怎样估计参数影响； 主要代价。 逐个试参数； 每改一个参数，重做一次完整前向； 参数越多，重复计算越多。 反向传播； 从损失出发，逐层复用已算出的下游影响； 一次反向即得全部梯度。 。 不必先学新术语 「计算图」「动态规划」可以用来精确描述这种复用，但它们 不是 理解反向传播的前提。核心就一句： 从后往前算一次，把同一份下游影响沿不同路径分发，而不是为每个参数从头再算。 。

### 2.9 完整手算：一次前向 + 一次更新

前面所有零件，在这里合成一次真实的数字演算。用的正是开头那个 2→2→1 的网络。 任务 ：输入 x = [1, 2] ，真实标签 y = 1 。网络 2 输入 → 2 个 ReLU 隐藏节点 → 1 个 Sigmoid 输出。做一次学习率 η = 0.1 的梯度下降更新。 9.1 初始参数 W₁ = [[0.5, −0.25], [1.0, 0.5]]， b₁ = [0, −1]，W₂ = [1.2, −0.7]， b₂ = 0.3。 W₁ 的每一行对应一个隐藏节点。 9.2 前向传播 隐藏层预激活 z₁ = W₁x + b₁ = [0.5·1 − 0.25·2, 1·1 + 0.5·2 − 1] = [0, 1] 。 ReLU： a₁ = [max(0,0), max(0,1)] = [0, 1] 。 输出预激活 z₂ = 1.2·0 + (−0.7)·1 + 0.3 = −0.4 。 Sigmoid： ŷ = 1/(1+e^0.4) ≈ 0.4013 。 二元交叉熵： L = −ln(0.4013) ≈ 0.913 。 9.3 反向传播 一个漂亮的简化 Sigmoid 与二元交叉熵搭配时，输出层的梯度极简： ∂L/∂z₂ = ŷ − y 。这也是二分类默认这样配对的实用原因之一。 δ₂ = ŷ − y = 0.4013 − 1 = −0.5987 。 输出权重梯度 ∂L/∂W₂ = δ₂·a₁ = [0, −0.5987] ；偏置 ∂L/∂b₂ = −0.5987 。 传回隐藏层 ∂L/∂a₁ = W₂ᵀδ₂ = [−0.7184, 0.4191] 。 ReLU 导数：节点1 的 z=0 取 0，节点2 的 z=1 取 1，故 δ₁ = [0, 0.4191] 。 第一层梯度 ∂L/∂W₁ = δ₁·xᵀ = [[0,0],[0.4191,0.8382]] ； ∂L/∂b₁ = [0, 0.4191] 。 9.4 更新并验证 W_new = W_old − 0.1·∂L/∂W b_new = b_old − 0.1·∂L/∂b。 参数； 更新前； 梯度； 更新后。 W₂ 第二项； −0.7000； −0.5987； −0.6401。 b₂； 0.3000； −0.5987； 0.3599。 W₁ 第二行； [1.0, 0.5]； [0.4191, 0.8382]； [0.9581, 0.4162]。 b₁ 第二项； −1.0000； 0.4191； −1.0419。 。 用新参数再前向一次，预测从 0.4013 升到约 0.4702 ，损失从 0.913 降到约 0.755 。一次更新很小，但成千上万批累积起来，网络就逐渐长出有效的内部表示。 这才是「学习」 训练不是把答案存进某个节点，而是让 所有参数沿着能降低总损失的方向，一起发生微小的协同变化 。

### 2.10 训练为什么会失败

原理讲通了，落地时还有一层现实：同样的网络，训练常常就是不收敛。先认识几种典型失败。 现象； 根因； 常见应对。 梯度消失； 深层链式乘积里很多小于 1 的导数连乘； ReLU/GELU、残差连接、合适初始化与归一化。 梯度爆炸； 连乘与权重尺度过大； 降学习率、梯度裁剪、归一化、合理初始化。 死亡 ReLU； 节点长期落在负半轴，输出和梯度都为 0； 降学习率、Leaky ReLU、检查初始化。 训练损失不降； 数据/标签错、学习率不当、梯度断裂； 先用极小数据集故意过拟合，逐层查数值与梯度。 训练好、验证差； 记住了训练细节，没学到可泛化规律； 更多数据、正则化、早停、减小模型（见第 11 节）。 。 10.1 初始化不是细节 如果同一层所有节点用 完全相同 的初始参数，它们会收到相同梯度、永远保持相同，等于只有一个节点在干活。随机初始化就是用来 打破这种对称 ；Xavier/Glorot、He 这类方法还会按层宽控制方差，让信号和梯度在层间不过快放大或缩小。 10.2 归一化与残差连接 批归一化 / 层归一化帮忙控制中间数值的尺度；残差连接让一层去学「在输入基础上加点什么」，同时给梯度开一条更直的回传路。 它们不是神经网络定义里必需的零件，却是深层网络能稳定训练的关键工程结构 ——这也是原理层和工程层的分界。

### 2.11 泛化：训练集好还不够

10.1 提到「训练好、验证差」。为什么这是核心难题，而不是小毛病？。 神经网络参数极多，多到足以 把训练样本背下来 。可真正的目标是在 没见过 的数据上也保持低误差——这叫泛化。所以必须始终把数据分成训练集 / 验证集 / 测试集，并按验证表现来挑架构和超参数。 图示：训练损失持续下降，验证损失先降后升。 图 5 训练损失一路降，不代表模型一路变好。当验证损失开始回升，模型已经在「背」而非「学」——那一刻正是该早停的地方。 。 方法； 作用机制； 注意。 L2 / 权重衰减； 惩罚过大的权重，偏向更平滑的解； 太强会欠拟合。 Dropout； 训练时随机屏蔽部分节点，减少共适应； 推理时关闭并处理缩放。 早停； 验证损失开始变差就停； 要保存最佳验证检查点。 数据增强； 制造保持标签不变的合理变化； 增强要符合真实任务不变性。 减小模型； 直接降低容量； 可能牺牲表达能力。 。

### 2.12 把整条因果链连起来

泛化是最后一道检验，但它不是凭空冒出的新主题。现在把全页串成一条链，逐环检查「每个概念为什么必须存在」。 输入 x 把现实对象表示成数字；单个线性模型表达不了复杂的非线性关系。 （§1） 。 节点用权重和偏置检查一种模式；很多节点并行，形成一层新表示。 （§2） 。 层间的激活函数打破线性坍缩，使多层复合能构造复杂函数。 （§4） 。 前向传播把输入逐层变成内部表示；输出层再翻译成有任务含义的预测。 （§3、§6） 。 损失函数把预测错误压缩成一个可比较、可求导的数字。 （§6） 。 反向传播用链式法则算出每个参数对损失的责任；负梯度给出最快下降方向。 （§7、§8） 。 优化器反复更新参数，让训练损失下降；验证数据再检查这种改进能不能迁移到没见过的样本。 （§9、§11） 。 为什么到这里才算闭环 网络能拟合训练数据，只说明「表达 + 优化」成功；只有 验证表现也变好 ，才说明它学到的关系有泛化价值。所以这条链不是停在「损失下降」，而是停在「未见数据上受检验」。

### 2.13 常见误解

误解； 更准确的理解。 节点就是生物神经元； 只是受生物启发的数学计算单元，不能据此推断认知机制。 层数越多一定越好； 深度提高表达潜力，也提高优化难度与成本。 隐藏层会自动学成人类概念； 它学的是对任务有用的分布式表示，未必可命名、可解释。 反向传播 = 梯度下降； 反向传播 算 梯度；梯度下降 / Adam 用 梯度更新。 梯度指向下降方向； 梯度指向 最快上升 方向；梯度下降用它的反方向。 训练损失低就说明成功； 还要看验证、测试与真实分布上的表现。 万能逼近 = 无所不能； 只说明存在某种近似能力，不保证数据够、训得动、能泛化。 。

### 2.14 检查你是否真的理解

不用激活函数时，为什么十层全连接网络仍等价于一层？。 权重和偏置分别控制什么？为什么偏置不是可有可无？。 隐藏层叫「隐藏」，是因为它不可观测，还是因为它夹在输入和目标之间？。 前向传播、反向传播、优化器各自完成什么工作？。 梯度明明指向损失上升最快的方向，为什么梯度下降还要先算它？「下降最慢的方向」为什么没有实用价值？。 学习率太大时，损失曲线通常会怎样？。 二分类为什么常用 Sigmoid + 二元交叉熵这对搭配？。 训练损失继续降、验证损失却上升，说明了什么？。 为什么梯度消失会 先 伤害靠近输入的层？。 参考答案 线性/仿射变换的复合仍是一个线性/仿射变换，可把多组矩阵与偏置合并成一组。 权重控制输入的方向与强度；偏置平移响应阈值，使决策边界不必过原点。 主要因为它们不是数据里直接给的输入或标签，而是模型内部学到的中间表示。 前向传播算预测；反向传播用链式法则算梯度；优化器用梯度更新参数。 梯度的反方向就是同等步长下的最快下降方向；几乎与梯度垂直的方向下降可以慢到接近 0，甚至一阶近似下不变，因此无法有效减少损失。 可能震荡、突然升高甚至发散，无法稳定收敛。 Sigmoid 把输出压成 0~1 概率；交叉熵对「错且自信」的预测强惩罚，且两者搭配后梯度极简（ŷ − y）。 模型在过拟合；应考虑早停、正则化、增数据或减容量。 靠近输入的层，其梯度要穿过更多后续层的小导数连乘，因此更容易趋近 0。

## 2.1 反向传播：把一个结果的责任高效分回全部参数（backprop）

### 2.1.1 为什么不能把每个参数轻轻推一下试错

如果只想知道参数增大一点会怎样，有限差分不是已经能近似导数了吗？。 这条路走的是纯数值路线：不手写任何导数公式，只把第 i 个参数向两侧各推一个微小扰动，用损失的变化去近似梯度。写成式子就是中心差分。 ∂L/∂θᵢ ≈ [L(θᵢ+ε)−L(θᵢ−ε)]/(2ε)。 读这一行要盯住它索取什么、又交回什么：喂进去的只有某个参数当前的取值和一个人为选定的步长 ε，交回来的是损失在这个参数方向上的近似斜率。中间的动作全写在分子分母里——先在参数两侧各跑一次完整前向拿到两个损失，再让两者之差被 2ε 除，把“扰动了多大”折算成“每单位变化损失涨多少”。差商越贴近真实导数，说明步长选得越合适，所以实践中常换几个 ε 看看结果稳不稳。 麻烦出在代价和数值两端。中心差分每个参数至少要做两次前向，百万参数就要约两百万次，十亿参数更不可能；而且 ε 太大会有截断误差，太小又会被浮点舍入吞掉，两头都让差商失真。这也就划定了它的位置：抽查少量参数可以，承担训练规模不行。 真正的机会来自一个事实：所有参数最终汇入同一个标量损失，中间大量计算是共享的。反向传播把这些共享路径只处理一次。

### 2.1.2 计算图怎样把复杂函数拆成局部问题

面对嵌套乘法、加法和非线性，怎样避免一次推整条巨大公式？。 办法是干脆不去推那条整式。框架在前向执行时把每一步运算随手登记下来，让整个函数变成一张有向无环图：每个节点是一次局部运算，每条边是一次数据依赖。贯穿示例被记录成的样子就是下面这张图。 图示：ŷ=wx 与半平方损失的计算图和反向梯度。 前向从左到右算值；反向从右到左传“损失对这里有多敏感”。图里每个方框只表示一次局部运算，没有任何一处需要对整条公式做一次性求导。 这张图吃进去的是前向留下的两样东西：运算之间的连接关系，以及乘法节点上的 x、损失节点上的 ŷ−y 这类必要中间值；它交付的是一条能按链式法则逐段拼接的梯度通路。分工也随之确定——加法、乘法、矩阵乘、激活函数各自只实现自己那一小块局部导数，谁都不必知道整个网络长什么样，复杂网络的梯度由这些局部规则拼接而成。 代价是一条硬边界：反向能不能走通，完全取决于前向有没有把它要用的中间值保存下来。图纵然还在，中间值一旦被丢弃或覆盖，链条就断在那里——第 7 节的显存开销和第 8 节的原地修改故障，根子都在这条边界上。

### 2.1.3 上游梯度乘局部导数是什么意思

反向经过一个节点时，究竟拿到什么、计算什么、传出什么？。 把镜头推近到单个节点，就能看清敏感度是怎样一站站接力传下去的。设 z=f(u) 且损失依赖 z ：这个节点拿到的是下游送来的上游梯度，用到的是自己那条局部导数，传出去的是对本节点输入的梯度。 ∂L/∂u = ∂L/∂z · ∂z/∂u。 动作只有两步：先接住上游梯度，再乘上本地的局部导数。之所以能这么拆，是因为第一项说的是“输出 z 变化一点，最终损失变多少”，第二项说的是“输入 u 变化一点，z 变多少”；两句首尾相接，这个乘积回答的就是：把 u 挪动一点点，最终损失会跟着变多少。反向传播并没有发明新的微积分，只是安排了高效的复用顺序——整张图的梯度都由这一个动作逐节点组合而成。 局部操作； 前向； 反向给输入。 加法； z=a+b ； 两边都接收上游梯度。 乘法； z=ab ； ā=ż·b, b̄=ż·a 。 平方； z=u² ； ū=ż·2u 。 ReLU； z=max(0,u) ； u>0 时传递，否则为 0。 矩阵乘； Z=WX ； 按转置乘法得到 W̄ 与 X̄ 。 。 每种运算需要提供的，就只有表里第三列那一格。这也把公式的成立条件摆到了明处：它依赖局部导数存在且被正确实现。ReLU 在 0 处并不可导，框架只能约定取一侧的次梯度；某个自定义算子若把反向规则写反，前向数值照常正确，整条链上的梯度却全是错的。

### 2.1.4 完整手算：−4 怎样一步步出现

不省略任何中间节点，从损失 1 开始倒着走一遍会得到什么？。 前两页直接给出了 ∂L/∂w=−4 ，却没交代这个数是怎么冒出来的；这一节把它一步步摆开。把前向拆成 u=wx 、 e=u−y 、 L=½e² ，先由左至右把三个中间值算实，再让损失种子沿同一串节点倒流回 w 和 x。 方向； 节点； 计算； 值。 前向； u=wx ； 2×2 ； 4。 前向； e=u−y ； 4−6 ； −2。 前向； L=½e² ； ½×4 ； 2。 反向； 损失种子； ∂L/∂L ； 1。 反向； 经过平方； ∂L/∂e=1×e ； −2。 反向； 经过减法； ∂L/∂u=−2×1 ； −2。 反向； 经过乘法到 w； ∂L/∂w=−2×x ； −4。 反向； 经过乘法到 x； ∂L/∂x=−2×w ； −4。 。 这张表要分两半读：上半段是反向的原料，u=4、e=−2 这些前向值连同 1 这个损失种子必须先到位；下半段是产物，每个变量最后各自拿到一份属于自己的梯度。原料缺不得，是因为平方节点的局部导数正是 e，乘法节点的局部导数正是 x 与 w。产物则是一路缩放出来的：损失种子每经过一个节点就被对应的局部导数乘一次——过平方乘 e 得 −2，过减法乘 1 保持不变，过乘法到 w 时乘 x=2，−4 于是落在最后一行。要留心的是，整张表只对 x=2、y=6、w=2 这一组取值成立，换一个 w，所有中间值和梯度都得重算一遍。 为什么从 1 开始？ 因为最终节点就是损失自身， dL/dL=1 。这个 1 像一单位“敏感度”，随后被每个局部导数缩放并传回。 最后一行那个负号可以直接读出意思：把 w 稍微增大一点，损失就会下降。它并不是在说 w 应该增大 4——步子迈多大是优化器的事，这里只回答“往哪个方向、以多快的初始速率变化”。

### 2.1.5 分叉路径为什么要累加梯度

一个变量同时参与两条计算路径时，只沿其中一条反传会漏掉什么？。 设 u=w²+w 。参数 w 一条路径经过平方，另一条直接进入加法，两条路径都会把自己的影响带到 u 上，于是总导数是两份贡献之和：。 du/dw = 2w + 1。 反向遍历真正做的事就藏在这个加号里：两条下游路径各自把 2w 和 1 送回 w 节点，w 节点收下的不是其中任何一条，而是它们相加之后的总梯度——相加意味着这份梯度包含了全部下游影响。若只沿平方那条路反传，得到的 2w 会静悄悄比真值小一截：梯度看上去仍是个合理的数，损失也照常下降，只是慢于应有的速度。实现层面对应的典型错误，就是把新到的贡献覆盖到旧值上而不是累加。 残差连接、权重共享和循环网络都会遇到这种累加：同一份权重在多个分支或多个时间步上被反复使用，每一次使用都是一条独立的下游路径。 批次累加和图内分叉不是同一件事。 图内分叉是总导数必需的路径求和；跨 mini-batch 的梯度累积是为了模拟更大有效批量，需要显式决定何时清零。

### 2.1.6 张量很多时为什么不显式构造巨大雅可比

从向量到向量的层有一整块雅可比矩阵，框架难道要把它全部存下来吗？。 不必，突破口在于输出端只有一个标量。训练通常从标量损失反传，对节点 y=f(x) ，下游已经给出向量 v=∂L/∂y ；本层要交给上游的是 vᵀJ ，即向量—雅可比积，其中 J=∂y/∂x 才是那块完整雅可比。这个乘积整体不过是一个向量，J 只是中间的临时产物——既然要的只是乘积，就没有理由先把 J 造出来再乘一遍。 所以框架实现的从来不是“求雅可比”，而是“给我一个下游梯度向量，我直接还你结果”：接收的是与该层输出同形的梯度向量，交回的是与该层输入同形的梯度，中间那块动辄上亿元素的方阵从头到尾没在显存里出现过。矩阵乘用一次转置乘法完成，卷积用相关运算完成，注意力也有自己的融合规则，每种层都把这条捷径写死在反向实现里。 模式； 适合的输出/输入关系； 直觉。 反向模式； 大量输入参数 → 少量标量输出； 一次反向得到损失对所有参数梯度。 前向模式； 少量输入 → 大量输出； 沿给定输入方向向前传播导数。 。 表里两行的分界，说到底是“输入多还是输出多”。神经网络训练正是参数极多、损失只有一个标量，一次反向就能把所有参数的梯度带回来，因此反向模式尤其合适；反过来，若输入只有寥寥几个却要观察大量输出的变化，前向模式反而更省。

### 2.1.7 反向为什么比纯推理占更多内存

参数没变多，训练显存为什么远高于只做前向推理？。 因为很多局部导数并非凭空算得出来，它们要用前向留下的值：ReLU 需要知道输入是否大于零，矩阵层需要输入激活，归一化需要均值方差这类统计量。推理算完一层就能把上一层的激活丢掉，训练却必须把它们一路留到反向来取——训练比推理多出来的那部分占用，第一笔就是这些被扣住的激活。 把训练时占住显存的东西点一遍，大致是三类：前向产生的激活、反向算出的参数梯度、优化器自己维护的状态。所以显存读数远高于推理时，它的含义相当具体：不是模型忽然变大了，而是大量中间值正被保留待用。 梯度检查点给出另一种权衡：前向只保存少数几个检查点激活，其余的不存；反向走到那一段时重新执行一次该段前向，把中间值现算出来。用额外算力换回内存，数学上的梯度分毫不差。代价是重算过程必须可重复——dropout 要能复现同一个掩码，原地操作和带副作用的算子要格外小心，否则第二次前向得到的值与第一次不同，反向就会拿着错误的中间值继续往下算。

### 2.1.8 哪些代码操作会悄悄切断或污染计算图

公式正确、程序也能运行，梯度为什么仍可能是零、None 或错误数值？。 这类问题的共同点是：出错的不是数学，而是代码对计算图做了手脚。张量被转成普通数组、被原地覆盖、被以合法却错误的形状广播，图就在某处被切断或污染，而前向数值看上去毫无异样。能拿来判断的只有两样：代码里实际执行的张量操作，和梯度检查给出的信号——是 None、是恒零、是 NaN，还是数值系统性偏小；最终要得到的，是把现象定位到某一类具体故障上。排查顺序建议由粗到细：先确认图是不是干脆被切断了，再依次看原地修改、梯度未清零、精度溢出和错误广播。 故障； 机制； 检查方法。 detach / 转成普通数组； 明确停止记录后续依赖； 检查 requires-grad 和图边界。 原地修改保存的激活； 反向需要的前向值已被覆盖； 启用异常检测，避免危险 in-place。 忘记清零梯度； 多数框架默认累加到旧值； 记录每步梯度并明确 zero-grad 时机。 混合精度下溢/溢出； 小梯度变 0 或大值变 Inf； 损失缩放、检查 finite 比例。 不可微离散操作； 局部没有可用连续导数； 使用代理、估计器或改写目标。 错误广播； 形状合法但梯度在错误维度求和； 检查张量形状和小例子手算。 。 对上表里的某一行，只意味着排查范围缩小了，并不等于找到了唯一根因。混合精度下溢和忘记清零完全可能同时存在，修好一个之后现象照旧；所以每改一处都要重新跑一遍梯度检查，而不是看到症状消失就收工。

### 2.1.9 运行示例：用有限差分给自动梯度做体检

反向传播很快，但怎样获得一份独立证据证明实现没有写错？。 让第 1 节那个“太慢、不能用来训练”的办法回来当裁判：有限差分虽然扛不起全部参数的梯度，却能对少数几个参数给出一份与自动微分完全独立的证据。仍用贯穿示例，在 w=2 处取 ε=10⁻⁴ ：。 g num =[L(2+ε)−L(2−ε)]/(2ε) ≈ −4。 喂给它的只是同一个前向在参数两侧算出的两个损失，吐出来的是数值梯度；随后将数值梯度与反向梯度比较相对误差 |g−g_num|/(|g|+|g_num|+δ) 。在双精度、小模型、确定性前向中两者应非常接近，相对误差小到只剩浮点噪声，就说明反向实现大概率正确。 不接近却未必是反向写错了。若 ReLU 恰在折点、随机层未固定、 ε 不合适或损失尺度极端，检查本身就会误报。下面这套顺序，正是为了先把这些干扰逐个排除掉：。 只取很小网络和少量参数，切到双精度。 关闭 dropout 等随机性，固定数据和状态。 用中心差分而非单边差分。 同时试几个数量级的 ε ，寻找稳定区间。 先查单层局部规则，再查端到端组合。 即便五步全部通过，它证明的也只是“在这几个参数、这个取值点上，两种算法给出同一个数”，属于抽查而非证明。

### 2.1.10 把整条因果链连起来

从一次前向到参数被更新，反向传播在哪些环节承担责任、又在哪些环节不负责？。 前向按计算图得到预测与标量损失，并保存必要中间值。 损失节点以 ∂L/∂L=1 作为反向种子。 逆拓扑遍历让每个节点接收上游梯度。 节点用局部导数计算向量—雅可比积。 多条下游路径的贡献在共享变量处相加。 遍历结束后，每个可训练参数得到 ∂L/∂θ 。 有限差分和局部测试抽查梯度实现。 优化器随后才读取梯度并更新参数；目标是否正确仍由损失与评测负责。

### 2.1.11 常见误解

误解； 更准确的说法。 反向传播就是梯度下降； 反向传播算梯度；梯度下降或 Adam 使用梯度更新。 它模仿大脑把错误传回神经元； 它是计算图上的链式法则与动态规划式复用，不是生物学习机制声明。 每层只把同一个误差复制回去； 上游梯度会被每个局部雅可比变换，并在分叉处求和。 自动微分等于数值差分； 自动微分组合解析局部规则，除浮点误差外给出机器精度导数；差分是近似检查。 梯度通过就证明训练正确； 它只证明对当前代码和损失的导数一致，目标、数据和评测仍可能错。 。

### 2.1.12 检查你是否真的理解

为什么有限差分适合检查少量参数，却不适合训练十亿参数模型？。 对 L=(wx+b)² ，写出 ∂L/∂w 和 ∂L/∂b 。 若 u=w²+w ，为什么不能只保留平方路径的梯度？。 反向模式为什么适合“很多参数到一个损失”？。 自动梯度与有限差分不一致时，至少列出三个优先检查项。 参考答案 每个参数需额外前向，成本随参数数线性爆炸；反向传播复用共享中间结果，一次逆向得到全部梯度。 令 u=wx+b ，则 ∂L/∂w=2u·x ， ∂L/∂b=2u 。 总导数包含所有下游路径贡献，漏掉直接路径会把 2w+1 错算成 2w 。 一次从少量标量输出反向，就能同时计算对大量输入参数的敏感度，无需显式雅可比。 检查 detach/图切断、原地修改、随机性、数据类型、广播形状、梯度累加、差分步长和不可微折点。

## 2.2 梯度消失与爆炸：深度怎样把局部导数放大成指数效应（vanishing-gradient）

### 2.2.1 输出层知道错了，早期层为什么收不到消息

反向传播明明会走过每一层，为什么靠近输入的参数仍可能几乎不更新？。 反向传播经过一个节点时，把上游梯度乘以局部导数。深层网络的早期参数离损失更远，信号必须经过更多次乘法。如果大多数乘数在相关方向小于 1，梯度不断缩小；大于 1 则不断放大。浮点精度和优化器随后还会进一步影响这些极小或极大数值。 结果不是所有层都同样慢：常见现象是输出附近层仍能学习，早期特征几乎冻结；或某一步梯度突然爆炸，使权重、损失和激活变成 Inf/NaN。

### 2.2.2 链式法则怎样把深度写成连乘

### 2.2.3 激活函数为什么直接进入反向尺度

权重不变时，仅换激活函数为什么就能改变深层可训练性？。 先把这一步在计算里的位置钉住。前向时第 k 层先算出预激活 zₖ=Wₖhₖ₋₁ ，再把它送进激活函数得到 hₖ=φ(zₖ) 。反向走到同一处，自动微分手上拿着的是损失对该层输出的梯度 ∂L/∂hₖ ，要往下交出的则是损失对预激活的梯度 ∂L/∂zₖ = ∂L/∂hₖ ⊙ φ′(zₖ) 。被逐元素乘上去的 φ′(zₖ) 就是激活导数——激活函数在当前那个具体预激活值上的斜率。所以这一环节吃进的是预激活值 zₖ 与上游梯度 ∂L/∂hₖ ，吐出的是按斜率重新加权、形状完全不变的 ∂L/∂zₖ ：斜率是多少，流经该单元的信用信号就按几倍被放大或压小。 图示：Sigmoid 函数及其导数，远离零时导数趋近零。 sigmoid 输出有界，但两端饱和区几乎不传梯度；层层乘上不超过 0.25 的因子会迅速衰减。 图两端那两段几乎水平的曲线，就是这一页反复出现的饱和：预激活的绝对值一旦变大，sigmoid 的输出被挤到 0 或 1 附近再也涨不动，函数变平，斜率随之趋近于零。 σ′(z)=σ(z)(1−σ(z)) 把这件事写得很直白——σ 逼近 0 或 1 时两个因子必有一个趋零；即便落在最有利的 z=0 ，乘积也只有 0.25。把这个上限代回第 2 节的连乘，就能看清它为什么“直接进入反向尺度”：每层的局部雅可比除了权重那一份，还额外挂着一个 φ′ 因子，于是该层的有效尺度 c 至多是 0.25 乘上权重在这个方向的伸缩。十层 sigmoid 光激活这一项就贡献 0.25¹⁰≈9.5×10⁻⁷ 的收缩，权重得把每层反过来放大四倍才勉强抵消。换成 ReLU，正区导数恒为 1，这个乘子从链条里消失，同一套权重下 cᴷ 不再被激活单方面往下拽——这就是权重一点没动、只换激活也能让深网重新可训练的原因。 激活； 局部导数特征； 新风险。 sigmoid； 最大 0.25，饱和区接近 0； 深层与长序列易消失。 tanh； 中心可到 1，两端仍饱和； 状态离开中心后衰减。 ReLU； 正区为 1，负区为 0； 负区长期为零的“死亡”单元。 GELU/SiLU； 平滑、负区仍有小导数； 不能单独保证整体雅可比稳定。 。 不过导数等于 1 并不等于安全。ReLU 在负区的导数恰好是 0，某个单元若被偏置或一次过大更新推得长期落在负区，流经它的梯度会被完全归零，它就成了再也醒不过来的“死亡”单元；tanh 中心处虽能取到 1，状态离开原点后同样会滑进饱和。GELU、SiLU 用平滑曲线让负区保留一点小导数，缓解了这种硬截断，但它们只改写了 J=Dφ·W 中 Dφ 那一半， W 的奇异值仍可能把某些方向压得很小，所以换激活不能单独保证整体雅可比稳定——矩阵那一半正是下一节要看的东西。

### 2.2.4 权重矩阵为什么让同一层同时有收缩和放大方向

“平均梯度范数正常”为什么仍可能掩盖某些信息方向已经消失？。 线性层加激活的局部雅可比形如 J=Dφ·W 。权重矩阵的奇异值描述不同方向被放大或缩小多少，激活导数再对方向加权。最大奇异值长期大于 1 可能引发爆炸，最小相关奇异值很小则让部分方向消失。 只看一个全局平均值不够。 少量巨大梯度可把整体范数抬高，同时多数层或通道接近零。应按层、模块、参数类型和时间步记录分布、分位数与更新比率。

### 2.2.5 RNN 怎样把“深度”换成时间距离

循环网络参数层数不多，为什么仍难学几十步以前的信息？。 RNN 将同一状态转换沿时间展开： hₜ=φ(Wₕhₜ₋₁+Wₓxₜ) 。从第 T 步损失传回第 t 步，要乘 T−t 个状态雅可比，因此序列距离就是有效深度。早期信息可能在前向被覆盖，反向信用也可能衰减。 图示：RNN 时间展开及远距离反向梯度路径。 参数共享不会减少反向路径长度；同一矩阵反复相乘同样会造成指数效应。

### 2.2.6 LSTM/GRU 门控怎样建立更稳定的状态通道

门控网络为什么比普通 RNN 更容易保留长期信息？。 LSTM 在隐藏状态之外单独维护一条细胞状态 cₜ ，它的更新是近似加法的： cₜ=fₜ⊙cₜ₋₁+iₜ⊙c̃ₜ 。这里的遗忘门 fₜ 和输入门 iₜ 都是由当前输入与旧状态算出、取值在 0 到 1 之间的逐元素系数， c̃ₜ 是本步新写入的候选内容， ⊙ 表示按元素相乘。沿这条通道往回走时，相邻两步之间的局部导数主要就是 fₜ 自己，而不像普通 RNN 那样每步都要再乘一遍 Wₕ 和饱和非线性的导数。代回第 2 节的连乘视角：跨 100 步的尺度约等于 100 个遗忘门值之积， 0.99¹⁰⁰≈0.366 仍然可用；而普通 RNN 在同样跨度上，tanh 导数与权重谱的乘积早已把信号压到 10⁻⁵ 量级。 GRU 走的是另一条路：它没有独立的细胞状态，而是把「保留旧的」和「写入新的」绑在一次凸组合里， hₜ=(1−zₜ)⊙hₜ₋₁+zₜ⊙h̃ₜ 。更新门 zₜ 接近 0 时状态几乎原样复制过去，这一步的有效乘数就接近 1−zₜ ，同样能把长路径的尺度维持在 1 附近；但保留多少与写入多少由同一个门决定，无法像 LSTM 那样一边几乎完整保留旧值、一边大量写入新内容。两者的共同点是把每步的有效乘数从「权重谱 × 激活导数」换成一个模型可以学着调到接近 1 的门值。 门控不是无限记忆保证：门值由数据学习，长期小于 1 仍会衰减， 0.9¹⁰⁰≈2.66×10⁻⁵ 与普通 RNN 的困境没有本质区别；状态容量、优化和序列噪声也会限制有效记忆。

### 2.2.7 初始化怎样让第一步信号尺度不立即失控

权重随机值都很小看似安全，为什么过小和过大都可能失败？。 若每层输出方差都缩小，前向激活和反向梯度会随深度消失；方差放大则会爆炸或把激活推入饱和区。Xavier/Glorot 初始化按输入和输出宽度选择方差，适合近似对称激活；He 初始化考虑 ReLU 约一半单元为零，使用更大方差保持尺度。 方法； 典型方差尺度； 主要假设。 Xavier/Glorot； 约 2/(fan_in+fan_out) ； 前后向方差折中，tanh/线性附近。 He/Kaiming； 约 2/fan_in ； ReLU 类激活的门控比例。 正交初始化； 方向范数初始更稳定； 形状允许且增益选得合适。 。 表中第三行的正交初始化正好接回第 4 节的奇异值视角。所谓正交矩阵，是指它的各列互相垂直、且每列长度都等于 1，这等价于它的奇异值全部为 1：它把输入向量整体旋转到新的方向，却既不放大也不压缩任何方向的长度。用它当起点， J=Dφ·W 里的 W 在初始时刻对所有方向都给出 c≈1 ，于是 cᴷ 不随层数漂移，深层线性路径的信号范数几乎保持不变——这与 Xavier、He 只对「平均方差」做统计约束不同，正交是对每个方向逐一保尺度。实际使用时还要把这个矩阵乘上一个称为增益（gain）的标量常数，用来预先补偿后面激活函数造成的能量损失：ReLU 平均砍掉约一半能量，所以常配 √2≈1.414 的增益，tanh 则取略大于 1 的经验值。增益取错，正交带来的保尺度性质会立刻被激活重新破坏。 初始化只控制起点；训练会改变权重谱和激活分布，因此仍需残差、归一化、调度与持续监控。

### 2.2.8 残差、归一化和裁剪为什么不能互相替代

常见稳定技巧都能“防训练崩”，它们实际改变的是同一段数学吗？。 把每种技巧放回 J K …J₁ 这条乘积链上，就能看出它们插在完全不同的位置。残差连接的做法是把子模块写成 y=x+F(x) ：输入 x 不经任何变换直接加到子模块输出 F(x) 上。于是这一块的雅可比变成 I+∂F/∂x ，其中 I 是单位矩阵，代表那条「原样通过」的恒等路径。哪怕 ∂F/∂x 在某些方向接近 0，这一层的乘数仍有来自 I 的那个 1，梯度不会在此处被清零；代价是分支 F 的尺度若失控， I+∂F/∂x 也会明显大于 1 而参与放大。 归一化动的是另一样东西。它先在某一组统计范围内（BatchNorm 沿批次维度、LayerNorm 沿同一样本的特征维度）算出这批激活的均值 μ 与标准差 σ ，做 x̂=(x−μ)/σ ，再乘上可学习的 γ 并加上 β 。这一步把送进下一层的激活钉在一个固定量级上，预激活因此不容易漂进 sigmoid、tanh 那种导数只剩 0.01 的饱和区， Dφ·W 的条件也不至于随训练越走越糟。但除以 σ 只统一了整体尺度，并不能把 W 的各个奇异值都拉到 1：原本被压缩得最厉害的那个方向，归一化之后相对其他方向依然被压缩。 梯度裁剪根本不碰前向和雅可比，它等反向算完才动手：先量出全局梯度范数 ‖g‖ ，若超过阈值 τ ，就把整个梯度乘上 τ/‖g‖ 缩回去，方向不变、长度封顶。所以它对某个异常批次带来的尖峰非常有效；而当 ‖g‖ 本来就只有 10⁻⁸ 时，裁剪条件根本不会触发，也没有任何环节会把它重新放大。损失缩放同样是纯数值手段：FP16 训练里先把损失乘上一个大系数 S （常取 1024 或动态调整）再反向，让原本会掉到半精度最小可表示值以下的梯度落回可表示区间，更新参数前再除回 S 。它挽救的是「数被舍入成 0」，而不是「数学上算出来就是很小」。 方法； 直接改变； 主要帮助； 不能单独解决。 残差连接； 雅可比加入恒等短路径； 深层信用传播、退化问题； 分支尺度失控、错误目标。 归一化； 激活尺度和局部条件； 数值范围、可优化性； 所有方向谱保持 1。 门控； 学习状态保留/写入系数； 长时间依赖； 无限序列记忆。 梯度裁剪； 过大梯度的最终范数； 爆炸与异常批次； 消失梯度。 损失缩放； 低精度反向数值范围； 防浮点下溢； 真实数学梯度过小。 。

### 2.2.9 运行示例：怎样证明是梯度消失而不是泛泛的“训练慢”

损失停滞时，哪些观测能把根因定位到反向路径？。 先验证任务可学： 小数据、小深度模型应能过拟合，排除数据和损失错误。 记录分层激活： 均值、方差、饱和比例、ReLU 零比例随深度变化。 记录分层梯度： 范数、中位数、最大值和 finite 比例；比较靠近输入与输出的层。 记录更新/参数比： 有小梯度但优化器是否仍产生可见更新。 做深度消融： 同一任务把 50 层减到 5 层；若浅层能学，路径长度成为强证据。 替换单一机制： 只改初始化、激活或加入残差，观察梯度剖面是否恢复。 检查数值精度： FP16 下零梯度可能是下溢，而非数学连乘本身。 观测； 更可能的问题。 浅层梯度系统性远小于深层； 长路径消失。 所有层梯度均为 None/零； 计算图切断、冻结或损失无依赖。 偶发巨大尖峰与 NaN； 爆炸、异常批次或精度溢出。 梯度正常但参数不变； 学习率、优化器参数组或缩放问题。 。

### 2.2.10 把整条因果链连起来

从一层局部导数到训练成败，哪些环节把小偏差累积成系统问题？。 损失在输出端产生初始梯度。 反向每过一层就乘局部雅可比。 激活饱和、权重谱和路径方向共同决定伸缩。 深度或时间距离让这些伸缩指数累积。 早期层因此几乎无更新，或全局梯度爆炸失控。 合适初始化先稳定起点尺度。 门控、残差和归一化改变长期路径与局部条件。 裁剪与精度管理处理极端更新和数值表示。 分层监控与消融证明根因，而不是凭技巧有效就倒推机制。

### 2.2.11 常见误解

误解； 更准确的说法。 只要网络深就必然梯度消失； 取决于局部雅可比尺度、路径和架构；现代深网可被稳定训练。 ReLU 完全解决梯度消失； 正区导数为 1 有帮助，但负区为零，权重矩阵仍会缩放。 梯度裁剪同时解决消失和爆炸； 裁剪只能限制过大范数，不能创造已经消失的信号。 梯度为零一定是数学消失； 也可能是 detach、冻结、不可微操作或低精度下溢。 残差保证梯度永远为 1； 单块含恒等项，但多块、归一化和分支雅可比仍改变整体传播。 LSTM 和 GRU 的保留机制是一回事； LSTM 用独立细胞状态做加法更新，GRU 用一个更新门做凸组合插值。 。

## 2.3 批归一化：用批统计稳定通道尺度（batch-norm）

### 2.3.1 BatchNorm 在一次前向中做什么

为什么同一个激活在训练批次不同的时候会得到不同输出？。 这里考察的 BatchNorm 前向，会把统计集合 B 中同一通道的激活按当前均值和方差标准化，再用 γ、β 恢复可学习的尺度与偏移；它缓解的是训练中通道尺度不断变化、使优化难以选择稳定步长的问题。输入是批激活 x ，输出是形状不变的 y 。结果应读成“相对于当前集合的标准分数再做通道仿射”，而不是某个样本自身的绝对分数；当批很小、成员相关或分布异常时，这个解释的可靠性就会下降。 μ B =(1/m)Σxᵢ σ² B =(1/m)Σ(xᵢ−μ B )² yᵢ=γ(xᵢ−μ B )/ σ² B +ε +β。 B 是当前统计集合， m 是其中参与统计的激活数量， xᵢ 是第 i 个输入激活， μB 与 σ²B 是批均值和方差， yᵢ 是输出。训练时，集合 B 中的激活共同产生均值和方差，所以一个元素既直接影响自己的分子，也通过统计量影响整批输出。γ、β 是每通道可学习参数；ε 限制小方差时的放大。 “均值 0、方差 1”只描述仿射变换之前的批统计，经过 γ/β 后输出不必满足它；有限 ε 和有限 batch 也会让实际值略有偏差。

### 2.3.2 卷积张量究竟沿哪些轴统计

对形状 [N,C,H,W]，为什么参数量只有 2C？。 先固定通道 c ：卷积 BatchNorm 接收四维激活 [N,C,H,W] ，跨 N、H、W 汇总这一通道的 N×H×W 个值，得到 μc、σ²c ，再把同一组 γc、βc 广播回该通道，输出仍是 [N,C,H,W] 。这样既避免不同语义通道被混成一个尺度，也说明每类参数为何只有 C 个；输出中的每个位置表示它相对本通道统计的偏离。表中的规则依赖张量语义而非维度编号：换成 NHWC 布局要换轴，全连接或一维卷积也不能照搬二维空间轴。 图示：卷积 BatchNorm 对每个通道跨批次与空间统计。 每个通道独立汇总 N×H×W 个值，不在通道之间求均值；因此 γ、β、运行均值与运行方差各有 C 个。 输入类型； 典型形状； 每特征统计的元素。 全连接； [N,C]； N。 一维卷积； [N,C,L]； N×L。 二维卷积； [N,C,H,W]； N×H×W。 。

### 2.3.3 手算一组 BatchNorm

同一通道只有两个值 1 和 3 时，标准化与仿射输出是什么？。 这个手算用最小可核对输入揭开一次 BatchNorm 变换：给定同一通道的批激活 [1,3] 与仿射参数 γ=2、β=0.5 ，先求共同统计，再输出 [−1.5,2.5] 。它要验证的不是“套公式”本身，而是 γ、β 为什么能在标准化之后重新设定通道尺度；因此最终结果不应再解释成零均值、单位方差。 为突出主步骤，下面忽略 ε：。 步骤； 计算； 结果。 批均值； (1+3)/2 ； 2。 批方差； ((1−2)²+(3−2)²)/2 ； 1。 标准化； (x−2)/1 ； [−1,1] 。 仿射； 2·x̂+0.5 ； [−1.5,2.5] 。 。 γ/β 能恢复任意每通道线性尺度；若最佳变换恰是恒等，网络也能学习与当前统计匹配的参数。但它不能消除“统计量由谁估计”的 batch 依赖。

### 2.3.4 训练和推理是两条不同的数据路径

单张图片推理时，为什么不能继续使用当前批均值？。 训练与推理组成一套带状态的双路径协议：训练输入一个当前批，输出按 μB、σ²B 归一化的激活，同时更新运行状态；推理输入任意线上样本或请求批，输出则由冻结的 μrun、σ²run 决定。机制上的切换解决了线上拼批不稳定的问题，也给出直接诊断：同一图片在 eval 模式换邻居后若输出变化，说明仍读了当前批统计或模式切换实现有误。 图示：BatchNorm 训练使用批统计并更新运行统计，推理使用冻结运行统计。 训练输出使用当前批统计；运行统计只为未来推理积累。推理输出不应随线上请求如何拼批而改变。 若推理仍处于 train 模式，同一图片与不同邻居拼批会得到不同结果；batch=1 且空间维也很小时，方差甚至接近零。若训练期间没有正确更新或保存运行统计，切到 eval 后也会突然劣化。

### 2.3.5 运行统计是模型状态，不是普通日志

每批均值怎样变成部署时的长期估计？。 部署时往往没有足够大的代表性批次，训练产生的运行统计便承担长期参照：它们把每步批统计压缩成随模型保存的指数移动平均。每次更新接收旧的 μrun 、当前 μB 和系数 α ，写回新的 μrun ；推理读取这个状态来居中激活。因而运行均值不是训练日志，数值偏向近期批次时，含义就是模型更相信近期分布，而不是总体均值必然估准。 μ run ← (1−α)μ run + αμ B 。 设旧运行均值 10、本批均值 14、α=0.1，新值为 10.4。若连续批次来自不同类别或增强强度，指数移动平均会偏向最近分布；训练太短、最后阶段数据异常或微调时冻结错误，都可能让状态不代表部署数据。 momentum 命名在不同框架中可能指 α，也可能指旧值的系数 1−α。 迁移配置时要核对更新公式，运行方差的估计约定也必须按实现对齐，不能只复制同一个数字。

### 2.3.6 为什么 BatchNorm 常让优化更容易

“减少内部协变量偏移”是唯一解释吗？。 把批激活送入 BatchNorm 后，张量形状不变，但通道尺度被当前统计重新参数化，后续层接收到的是更可控的数值范围。它要缓解的是尺度敏感造成的陡峭损失与学习率选择困难：标准化削弱绝对尺度的影响，可学习仿射保留表达能力，于是参数扰动对应的损失和梯度往往更平滑。训练加速、可用更大学习率或初始化敏感性下降，才是应观察的结果；“层输入分布不再变化”既不是输出承诺，也不是唯一机制。 原论文强调层输入分布被稳定；后续工作指出，仅用分布漂移不足以完整解释收益，损失与梯度对参数扰动更平滑、尺度重参数化允许更大学习率，也是重要机制。实践上更稳妥的结论是：在许多卷积网络与合适 batch 下，BN 改善条件、加快训练并降低初始化敏感性。 不要把经验收益推广成定理。网络架构、优化器、数据增强与 batch 构成会改变结果；现代无 BN 架构也可通过初始化、残差缩放和其他 Norm 稳定训练。

### 2.3.7 批噪声为何带来隐式正则

同一个样本每次被不同批伴随，表示为什么会轻微扰动？。 把固定样本分别放进不同训练批，输入变化的只是它的批邻居，输出却会因 μB、σ²B 改变而轻微波动；这类由有限批统计引入的随机扰动就是批噪声。它通过阻止网络依赖某个精确激活尺度而可能形成隐式正则，观察到适度波动可解释为训练扰动而非算子不确定性。不过 batch 越小只代表噪声通常更强，不代表泛化必然更好；统计失真超过可优化范围时，损失震荡和精度下降会先出现。 因此增大 batch 不只是提高吞吐，还可能减弱 BN 噪声。比较大/小 batch 时，应区分学习率、训练步数、统计质量和隐式正则四个变化。

### 2.3.8 小 batch 何时真正失效

判断统计可靠性的应该是 N，还是每通道参与统计的总元素数？。 不要只看批维 N 。这里的有效统计量，是每个通道真正为均值和方差提供近似独立信息的元素；卷积张量表面输入 N×H×W 个值，输出则是一份统计可靠性判断以及是否需要同步、冻结或换归一化方案的依据。空间位置能补充样本数，所以早期高分辨率层在小 N 下仍可能稳定；深层特征图缩小或位置高度相关时，有效独立数量会低于表面乘积，同样 N 的估计反而更噪。 这里的“归纳偏好”指归一化结构预先规定模型更容易利用哪类数据规律：BN 假设同一通道可以跨样本与空间位置共享统计，GroupNorm 则在每个样本内把一组通道与空间位置合并统计，不依赖同批的其他样本。两者的统计轴不同，同一激活因而会使用不同的均值和尺度；直接把已有 BN 层换成 GroupNorm 时，原有卷积权重与 γ/β 不能保证复现原函数，通常需要重新训练或微调。 方案； 改变什么； 代价/边界。 SyncBatchNorm； 跨设备聚合本层批统计； 增加通信与同步等待。 冻结 BN； 训练也使用既有运行统计； 新域不匹配时偏差保留。 GroupNorm； 单样本内按通道组统计； 统计轴与样本耦合改变，通常需重新训练或微调。 增大每卡 batch； 改善本地估计； 显存和优化配方改变。 。

### 2.3.9 分布式训练中的“全局 batch”有三个口径

优化器看到 256 张图，为什么 BN 可能只看到 16 张？。 设 8 张卡、每卡微批 16、累积 2 步：一次优化更新接收的梯度样本总量是 256，但普通 BN 每次前向只输入本卡当前 16 张及其空间位置，并立即输出基于这份局部统计的激活。梯度全局批、每卡微批与 BN 统计批因此是三种口径；前两者的聚合发生在反向同步或时间累积，不能追溯改写已经完成的归一化。SyncBN 会在当前步跨卡汇总统计，使 BN 看到 128 张，但通常仍不会跨两个累积步。 复现实验必须分别记录全局优化 batch、每卡微批、设备数、是否同步与空间尺寸。只写“batch size=256”无法重建 BN 行为。

### 2.3.10 域迁移时运行统计可能先于权重失效

训练照片换成医学影像或新相机后，为什么 eval 模式输出整体漂移？。 运行均值和方差记录源域的通道分布；换相机、机构或预处理后，输入变成目标域激活，输出仍由源域冻结统计居中缩放，这个错配就是要定位的问题。亮度、对比度或传感器变化会把许多通道整体推离 μrun ，继而放大或压缩后续表示；BN 前激活相对运行统计的标准化偏差，因而可解释为统计失配证据，而不只是最终分类器退化。可在严格控制下用代表性目标域无标签数据重新估计统计、继续微调，或选择不依赖 batch 的架构。 线上监控可比较 BN 前激活相对运行均值的标准化偏差、预测置信度与切片指标。只监控最终平均准确率会晚于统计漂移信号。

### 2.3.11 卷积—BN 融合怎样保持推理等价

推理时统计固定，为什么可以把 BN 折进前一层？。 卷积—BN 融合接收卷积的 W、b 以及冻结的 γ、β、μrun、σ²run、ε ，输出一组新的 W′、b′ 。它利用推理 BN 已成为固定通道仿射变换这一事实，把缩放并入权重、把居中和平移并入偏置，从而省去独立算子；验收时，融合前后逐层输出只应有允许的浮点舍入差异，而不能靠最终类别碰巧相同来判断等价。 对卷积输出 Wx+b ，固定 BN 可改写为：。 W′=γW/ σ² run +ε b′=γ(b−μ run )/ σ² run +ε +β。 W、b 是原卷积权重和偏置， γ、β 是 BN 缩放和平移， μrun、σ²run 是冻结运行统计， ε 是稳定常数； W′、b′ 是融合参数。融合前后在 eval 状态应给出相同输出，只允许可接受的浮点舍入差异。 这样省去独立 BN 算子，但只对 eval 状态与匹配的运行统计成立。融合后继续训练、遗漏卷积偏置、轴广播或 ε 不同都会破坏等价；量化时还需重新检查通道尺度与校准。

### 2.3.12 怎样诊断与验收 BatchNorm

这组验收把 BatchNorm 当作“数值变换＋模式切换＋持久状态”的整体来测试，目的在于拦住形状正确却统计协议错误的实现。输入包括可手算激活、不同批邻居、保存前后状态、多卡配置和部署域切片；输出应同时给出逐层误差、状态一致性与任务指标。顺序上先用最小例锁定公式和轴，再对照 train/eval、多卡、序列化和融合路径；任何 eval 邻居依赖或加载后状态差异都应解释为阻断性故障。 手算最小例： 核对 [1,3]、γ=2、β=0.5 的输出。 检查轴： 逐通道与参考实现比较均值、方差和输出。 测批依赖： train 模式换同批邻居应可能变化，eval 模式必须不变。 审计状态： 保存/加载后运行均值、方差和批计数完全一致。 扫有效 batch： 按层记录 N×H×W、统计噪声与任务指标。 比多卡路径： 单卡、普通多卡、SyncBN 分别记录统计口径。 测融合等价： 融合前后用多批输入比较逐层最大误差与最终指标。 做域切片： 新设备、增强、季节或机构分别检查漂移。

## 2.4 优化器与学习率调度：把瞬时梯度变成可控训练轨迹（optimizer-schedule）

### 2.4.1 梯度为什么还不是一次可靠更新

反向传播已经算出每个参数的斜率，直接减去它还缺什么？。 梯度只描述当前批次、当前位置的一阶方向。它可能含采样噪声，不同参数的数值尺度可能相差几个数量级，狭长谷地中还会在陡峭方向反复变号。优化器的工作不是重新定义目标，而是决定怎样把这份局部、带噪的方向证据转换成稳定更新。 组件； 回答的问题； 不负责什么。 损失函数； 什么结果算更好？； 怎样高效求导。 反向传播； 当前损失对参数多敏感？； 参数走多远。 优化器； 怎样结合梯度历史形成更新？； 目标是否代表真实需求。 调度器； 训练不同阶段用多大全局步长？； 修复数据与标签错误。 。

### 2.4.2 SGD 是最小基线，不是“没有优化器”

最简单的优化器究竟保存什么状态？。 θ t+1 =θ t −η t g t 。 SGD 只使用当前 mini-batch 梯度 gₜ 和学习率 ηₜ ；它没有每参数历史状态，因此额外内存小、行为容易解释。梯度噪声会让每一步抖动，但长期平均可能仍朝有用方向前进。 SGD 的“简单”是重要基线：如果一个复杂优化器只在训练损失早期更快，却没有改善相同步数、算力或验证指标，就不能宣称整体更好。

### 2.4.3 Momentum 怎样让一致方向积累、交替方向抵消

损失突然 NaN 时，降低学习率、裁剪和损失缩放解决的是同一问题吗？。 混合精度 让适合低精度的前向、反向张量运算使用 FP16 或 BF16，同时把对数值范围更敏感的归约、优化器状态以及常见的主参数副本保留为 FP32。输入是同一批数据与参数，输出仍是一份供优化器使用的梯度；这种组合以更小显存和更高吞吐换取额外的精度管理，而具体保留哪些算子为 FP32 由框架与硬件决定。 全局范数裁剪 限制一次异常梯度的更新方向长度，主要缓解爆炸； 损失缩放 在低精度反向前放大损失，防止小梯度下溢，更新前再还原； 有限值检测 在 Inf/NaN 时跳过更新并调整缩放。它们保护不同环节，不能把消失梯度、错误目标或长期过大峰值学习率“裁好”。

## 2.5 残差连接：给深层变换保留一条恒等信息高速路（residual-connection）

### 2.5.1 更深网络为什么可能连训练集都做得更差

如果额外层理论上可以学成恒等映射，深网络至少不该比浅网络差，现实为什么会退化？。 把较浅网络的中间表示 x 交给新增模块后，可以把一次训练尝试看成明确的输入—输出任务：输入是已经可用的 x ，输出至少应当仍是 x ，只有发现可降低训练损失的变化时才改成 x+Δx 。矛盾就在这里——模型容量增加了，训练集上的误差却可能上升，说明困难来自“保住已有解”的优化路径，而不是模型表达力不足。 普通堆叠把这项保留任务藏在一串权重与非线性里，优化器必须偶然把整串参数调成恒等；残差块则用一条无参数捷径直接传递 x ，只让另一条分支学习 Δx 。因此加深时，原解在结构上对应“令新分支接近零”，但这只改善训练可达性，并不替代数据、正则化或泛化评测。 这里讨论的“深度退化”专指一种优化现象：在数据、目标和训练预算可比时，更深模型连训练误差都高于较浅模型。把浅网络产生的表示 x 送入新增模块，最低要求是仍输出 x ，有用时再输出相对 x 的修正；因此它要解决的不是验证集泛化差，而是新增深度为何连已有训练解都难以保住。 把一个训练好的浅网络后面加几层，新增层理论上可输出原输入，保留原性能。但普通非线性层要通过权重和激活精确合成恒等映射，优化器不一定容易找到；路径变长还加剧尺度与梯度问题。于是更深模型可能训练误差更高，这叫深度退化，和“训练很好、验证差”的过拟合不同。 残差连接把恒等映射直接写进架构，使新增分支只需学相对输入的修正。

### 2.5.2 完整映射怎样改写成增量

目标映射是 H(x) 时，为什么学习 F(x)=H(x)−x 可能更容易？。 换一种参数化并没有改变目标函数，而是改变了模块要直接拟合的对象：残差块把“学习整个 H ”定义为“保留输入，再学习相对输入的差值”。一次前向计算先复制输入 x ；捷径把一份原样送到加法点，变换分支把另一份映射成 F(x) ，最后逐元素相加得到 y 。当 H(x) 接近 x 时，最容易表达的解便从复杂的恒等重构变成 F(x)≈0 。 残差学习在参数化层面把完整目标 H(x) 拆成保留项 x 与可学习增量 F(x) 。计算时，捷径把 x 原样送到加法点，变换分支只产生差值 H(x)−x ，两路逐元素相加后得到目标输出。 y = x + F(x) ⇔ F(x)=H(x)−x。 x 是块输入， H(x) 是希望得到的完整映射， F(x) 是残差分支学习的增量， y 是捷径与增量相加后的块输出。若理想映射接近恒等，普通层仍要把 x 重新生成一遍；残差分支只需输出很小修正。令分支最后一层接近零时，块一开始就是近似恒等，训练再逐渐学会“在已有表示上改多少”。 输入场景； 理想 H(x)； 残差 F(x)。 已有特征已经足够； 约等于 x； 约等于 0。 需要轻微校正； x 加小变化； 只学习小变化。 需要彻底变换； 远离 x； 分支仍可学习大残差，但优势减弱。 。

### 2.5.3 前向为什么有一条不经过变换分支的通道

即使 F 暂时学坏或接近零，输入信息怎样继续向后？。 沿一次前向传播看得最清楚：加法点接收同一个输入派生出的两个张量，一个是原始 x ，另一个是分支输出 F(x) ，并输出同形状的 y=x+F(x) 。这条直接搬运 x 的路径称为恒等捷径；它解决的是新分支尚未学会有用变换时，旧表示不应被迫穿过新权重而丢失的问题。 两路并非选择关系。每次调用残差块， F 仍会执行，随后加法节点同时接纳保留项和修正项；若 F(x)=0 ，输出退化为 x ，若 F(x) 有用，输出便在原表示上增量更新。也正因为采用相加，两路必须形状一致，且过大的分支仍可能盖过保留下来的信息。 绕过 F 、把输入直接送到相加点的下路就是恒等捷径。一个输入 x 同时复制到两路：上路执行变换并产生 F(x) ，下路保留 x ；加法节点把两路合成 y=x+F(x) ，所以捷径保留信息的机制不是关闭或跳过变换分支。 图示：残差块的变换分支与恒等捷径。 两条路径都执行：上路学习变换，下路保留输入；输出是相加，不是二选一。 恒等通道使表示不会因为某个新分支暂时无用就被迫重写。它也帮助特征跨多个块复用，但若分支输出尺度远大于 x ，恒等信息仍可能被淹没。

### 2.5.4 反向为什么出现恒等项

损失对输入的梯度怎样同时经过捷径和变换分支？。 令下游传回的上游梯度为 g_y=∂L/∂y 。当前块的反向输入包括 g_y 与分支局部雅可比 J_F(x) ，输出则是送往更早层的 g_x=∂L/∂x 。对 y=x+F(x) 求导时，直接项 x 给出单位雅可比 I ，分支给出 J_F ，于是两路梯度在输入处相加。 这一定义解释了残差为何缓解长链上的衰减：当 J_F 很小时，单块的 g_x≈g_y ，信号可近似原样越过该块。读数接近 1 只说明这个局部方向接近恒等，并不意味着整网梯度恒为 1；跨越许多块时仍要连乘不同的矩阵 I+J_F 。 这里的输入雅可比描述块输出 y 对块输入 x 的局部变化，它由捷径的单位雅可比与分支雅可比共同组成。反向传播接收下游给出的 ∂L/∂y 和当前分支的 J_F(x) ，链式法则分别计算捷径贡献与分支贡献，再相加得到 ∂L/∂x ；这正是上游梯度能绕开小分支导数返回输入的原因。 ∂y/∂x = I + J F (x)。 ∂L/∂x = ∂L/∂y · [I + J F (x)]。 I 来自 x 直接相加的捷径；即使分支局部导数很小，仍有一份上游梯度可直接到达输入。若分支雅可比接近零，单块梯度近似原样传递。 为什么仍不能说“残差保证梯度为 1”？ 单块是 I+J_F ，不是只有 I ；多块还要连乘多个 I+J_F ，其方向可能相互放大、缩小或抵消。归一化和投影捷径也会改变主路径。

### 2.5.5 完整数值例子：普通连乘与近恒等路径差多少

用一个标量方向计算，短路径的优势能有多大？。 这个标量实验专门回答“局部导数靠近 1 会把深度乘积改变多少”。输入是每块同一方向上的有效导数 d 与深度 n=20 ，计算规则是链式法则的连续乘积，输出是从第 20 块传回起点的倍率 d²⁰ 。它把抽象的短梯度路径变成可核对的数值，而不是把更好训练简单归因于参数更多。 逐步看，普通堆叠每过一块乘 0.8 ，20 次后只剩 0.0115 ；近恒等残差块若每块为 0.98 ，20 次后仍有 0.668 ，分支导数为零时则保持 1 。因此结果应解释为“把单块雅可比拉近 1 可显著延缓衰减”，而不是“残差让任意深度、任意方向都稳定”。 下面把“20 层后的梯度倍率”作为可计算输出：给定每块在同一标量方向上的局部导数 d 和块数 20，连续应用链式法则得到 d²⁰ 。这个对照量化了普通层的 0.8 连乘为何造成衰减，以及残差块把有效导数拉近 1 后能保留多少梯度。 结构； 每块局部导数； 20 块后梯度倍率。 普通层； 0.8； 0.8²⁰≈0.0115 。 残差块，分支初始导数 0； 1+0=1 ； 1²⁰=1 。 残差块，分支导数 −0.02； 0.98； 0.98²⁰≈0.668 。 残差块，分支导数 +0.02； 1.02； 1.02²⁰≈1.486 。 。 这只是单方向简化，不代表真实网络每层共享常数。但它说明让分支初始接近零为何有用：把每块雅可比放在 1 附近，深度累积不再从一开始就把信号压到百分之一。

### 2.5.6 形状不同时捷径为什么需要投影

输入和分支输出宽度或分辨率不同，两个张量还能直接相加吗？。 可以把投影捷径看成加法前的形状适配器：它接收原张量 x 和分支所需的目标形状，输出 P(x) ，使 P(x) 与 F(x) 能逐元素对应。卷积块通常用 1×1 卷积改变通道数，并用步幅同步下采样；宽度变化的 Transformer 则可用线性层完成映射。 这样得到的 y=P(x)+F(x) 仍保留“两路在加法点汇合”的残差接口，却不再拥有严格的恒等主干：梯度也要经过 P 的雅可比。因此投影适合放在通道或分辨率确实变化的阶段边界；形状本来相同时继续使用恒等捷径，才能保留最短、最直接的路径。 投影捷径用一个可学习线性映射把 x 变为与 F(x) 相同的形状。它接收原输入与目标宽度或分辨率，通过通道映射及必要的步幅产生 P(x) ，再执行 P(x)+F(x) ；这样保住了相加接口，但主路径的含义已从严格恒等变为可学习投影。 逐元素相加要求形状相同。卷积网络改变通道数或下采样时，常用 1×1 卷积和步幅把捷径投影为 P(x) ，输出变成 y=P(x)+F(x) ；Transformer 宽度变化可用线性投影。 捷径； 优点； 代价/边界。 严格恒等 x； 无参数、梯度直接； 只适用于相同形状。 线性/1×1 投影 P(x)； 匹配宽度与分辨率； 新增参数，不再保证严格恒等。 补零/池化； 参数少； 信息与尺度处理需谨慎。 。 投影应集中在确实改变阶段的边界，而不是每块都把捷径变成复杂网络，否则会削弱最短路径的意义。

### 2.5.7 分支尺度和零初始化为什么影响“从恒等开始”

公式中有 x ，为什么分支仍可能把主干淹没或让深网爆炸？。 为了把“分支太强”变成可操作的诊断，可用 r=||F(x)||/||x|| 表示残差分支尺度。它以同一批输入产生的主干激活和分支激活为观测，输出一个沿层深可比较的范数比：训练初期 r 很大，说明加法结果主要被分支控制； r 长期接近零，则提示分支可能没有学到有效修正。 零初始化针对的正是这个尺度问题。把分支末层权重或归一化尺度初始化到零附近，或把 F(x) 乘一个随深度选择的小系数，会让初始输出接近 x ，随后再由训练逐步放大有用修正。缩放也有边界：系数过小会压住分支梯度和容量，所以要把 r 与梯度、更新量及任务收益一起检查，而不能只追求越小越好。 分支尺度关注 F(x) 相对主干 x 的激活大小；加法不会自动让两路同量级，所以它直接关系到恒等信息能否保留。诊断时同时记录两路范数、沿深度的激活变化和梯度，把这些观测转成 ||F(x)||/||x|| 及初始化或缩放决策：早期比值很大提示分支过猛，长期近零则可能意味着优化不足或该块没有贡献。 若每个 F(x) 方差与 x 相当，许多分支相加会让激活随深度增长。常见措施包括：让分支末层权重或归一化尺度近零初始化、显式乘小残差系数、按深度缩放初始化，以及监控主干/分支范数比。 观测； 可能问题； 应检查。 ||F(x)||/||x|| 从早期就很大； 分支初始化或学习率过猛； 末层初始化、残差缩放、预热。 随深度激活范数持续增长； 分支方差累积； 归一化位置与深度缩放。 分支长期接近零； 优化不足或不需要该块； 梯度、容量和任务收益。 捷径与分支尺度差异极端； 一条路径被完全淹没； 两路统计及加法前尺度。 。

### 2.5.8 Transformer 的 Pre-Norm 与 Post-Norm 改变哪条路径

归一化放在子层之前或相加之后，为什么会影响深层训练？。 两种布局可以用同一组输入直接比较：给定主干表示 x 与子层 F ，Pre-Norm 输出 x+F(LN(x)) ，Post-Norm 输出 LN(x+F(x)) 。前者把归一化放进变换分支的入口，后者把归一化放在两路相加之后；位置差异决定了主干梯度是否必须穿过 LN。 这正是它们解决深层优化问题时的关键差别。Pre-Norm 保留了一条更接近严格恒等的 x 路径，通常让很深的 Transformer 更容易训练；Post-Norm 则规范化每次相加后的整体表示，可能带来不同的表示尺度与收敛行为。选择不能脱离深度、初始化、残差缩放和末端归一化单独判断，Pre-Norm 并非在所有预算和任务上都占优。 Pre-Norm 先归一化子层的输入，再把子层输出加回未经该归一化的 x ；Post-Norm 则先计算残差和，再对整个结果归一化。给定同一个 x 与子层 F ，两种次序产生不同的残差输出和反向主干：前者让恒等路径更直接，后者让捷径贡献也经过相加后的 LN，因此深层优化常更敏感。 形式； 示意； 主干性质； 常见权衡。 Post-Norm； y=LN(x+F(x)) ； 捷径也经过相加后的 LN； 原始 Transformer 形式；很深时优化更敏感。 Pre-Norm； y=x+F(LN(x)) ； x 主干更接近严格恒等； 通常更易稳定训练深层；最终表示和收敛性质不同。 。 Pre-Norm 让梯度可沿 x 主干少受子层和归一化影响，但不是无条件更好；模型深度、残差缩放、初始化和最终归一化共同决定效果。

### 2.5.9 残差连接与其他“跳线”到底有什么不同

图上都画一条跨层线，为什么语义和计算可能完全不同？。 判断一条跨层线属于哪类连接，可以给它同样的多路特征输入，再观察输出的形状和计算过程：逐元素相加得到与输入同宽的增量结果，通道拼接得到更宽的联合表示，门控产生按比例混合的结果，条件跳层才可能直接复用旧状态并省去模块计算。连接的定义来自这种合并语义，而不是图上是否画了“短路”。 机制上的差别也决定了解释方式。ResNet 的 x+F(x) 强调在旧表示上修正并提供短梯度路径；DenseNet 与常见 U-Net 的拼接保留各路特征供后续层再融合；Highway 让门参数决定保留多少、变换多少。标准残差块即使分支贡献很小也照常执行 F ，所以它的适用边界是改善信息与优化路径，不能据此宣称减少了推理 FLOPs。 辨认“跳线”不能只看画法，而要沿数据流检查它接收哪些特征、如何合并、模块是否实际执行。ResNet 把同形状的 x 与 F(x) 相加，DenseNet 和常见 U-Net 把多路特征按通道拼接，Highway 用门混合两路，动态跳层才可能条件性不执行模块；这些操作分别输出定宽增量、增宽特征、门控结果或省算力路径，因而解决的问题并不相同。 结构； 合并方式； 主要目的。 ResNet 残差； 逐元素相加 x+F(x) ； 增量学习与短梯度路径。 DenseNet； 通道拼接； 复用所有先前特征，宽度增长。 U-Net 跳连； 常为拼接，也可相加； 把高分辨率编码特征送到解码端。 Highway/门控残差； 学习门控制两路比例； 动态决定保留与变换。 动态跳层； 条件性不执行模块； 节省推理计算。 。 残差不等于跳过计算。 标准残差块每次仍执行 F ，只是把结果与捷径相加；它改善信息与梯度路径，不自动降低 FLOPs。

### 2.5.10 运行示例：怎样证明残差改善的是可优化性

加残差后分数变好，怎样区分“参数更多”“正则不同”和“深层路径更易训练”？。 这里所谓“证明可优化性”，并非只报一个最终分数，而是构造能排除替代解释的受控对照。实验输入是等深的普通堆叠与残差堆叠，以及一致的数据、宽度和训练预算；输出包括训练误差轨迹、各层梯度与更新量、主干/分支尺度，而验证分数只作为后续泛化观察。 执行机制是一条相互约束的证据链：先在参数量尽量匹配时比较两种结构，再扫描深度寻找普通网络训练退化而残差网络仍可拟合的区间，同时记录早层梯度是否恢复；最后用零初始化和残差缩放消融检验近恒等起点是否贡献了稳定性。只有这些变化共同出现，才更支持“残差改善深层优化”，而不是参数、正则或偶然波动造成的提升。 把它设计成受控优化实验：给定等深的普通堆叠与残差堆叠，固定宽度、数据和优化预算，输出训练误差曲线、分层梯度、更新比以及主干/分支尺度。随后扫描深度并加入零初始化消融；只有残差模型在深度增加时仍降低训练误差、早层梯度也恢复，才支持“短路径改善可优化性”这一解释。 做等深对照： 普通堆叠与残差堆叠保持宽度、数据、优化预算尽量一致。 比较训练误差： 残差若显著降低深模型训练误差，支持缓解退化，而不只是泛化正则。 做深度扫描： 比较 10/20/50/100 层，观察普通网络何时退化、残差何时维持。 记录分层梯度： 检查早期层范数和更新比是否恢复。 记录分支/主干尺度： 确认收益不是某一路爆炸。 做零初始化消融： 检验从近恒等开始是否改善早期稳定性。 最后看验证： 可优化性改善不保证未知数据一定更好，仍需正则和评测。

### 2.5.11 把整条因果链连起来

残差从一个加法，怎样一路影响到极深模型的训练？。 普通深层要求每个新增模块重构完整表示。 长路径使信息与梯度连续经过局部变换。 残差块把目标改写为输入加增量。 恒等捷径保留前向信息，即使分支暂时接近零。 反向雅可比包含 I+J_F ，提供短梯度路径。 零初始化或残差缩放让多块从近恒等状态开始。 投影只在形状变化处匹配捷径。 归一化位置与分支尺度维持长期稳定。 训练误差、梯度剖面和深度消融共同证明是否真的缓解退化。

### 2.5.12 常见误解

误解； 更准确的说法。 残差连接会跳过这一层； 变换分支仍执行；捷径只提供额外相加路径。 有恒等项就绝不会梯度消失； 多块仍连乘 I+J_F ，分支、投影和归一化会改变谱。 残差只对 CNN 有用； Transformer、MLP、扩散网络等也广泛使用增量与捷径。 加法和拼接是同一种跳连； 加法保持宽度并混合表示；拼接增加通道并保留各路。 网络越深只要加残差就越好； 深度还受数据、容量、尺度、算力和优化预算约束。 。

### 2.5.13 检查你是否真的理解

为什么新增普通层理论上能学恒等，但优化上仍可能让训练误差上升？。 从 y=x+F(x) 推导 ∂y/∂x ，并解释恒等项的意义。 20 个导数为 0.8 的普通层与分支导数为 0 的残差块，梯度倍率分别是多少？。 宽度变化时为什么不能直接相加，投影捷径带来什么代价？。 怎样用实验区分残差改善优化与单纯增加参数的效果？。 参考答案 普通非线性参数化未显式包含易达恒等解，长路径和尺度问题让优化器难找到它。 ∂y/∂x=I+J_F ；I 让上游梯度可沿不经过分支雅可比的直接路径返回。 普通层约 0.8²⁰=0.0115 ；近零分支残差块为 1²⁰=1 。 逐元素加法要求相同形状；投影能匹配形状，但增加参数且主路径不再严格恒等。 控制宽度、数据和预算做等深/深度扫描，比较训练误差、分层梯度、参数匹配与零初始化消融。

## 2.6 卷积神经网络 CNN：让同一个局部检测器扫遍空间（cnn）

### 2.6.1 卷积是滑动窗口上的共享内积

为什么一套边缘核能在图片任意位置工作？。 Y[i,j,o]=Σ u,v,c K[u,v,c,o]X[i+u,j+v,c]+b[o]。 X 是输入特征图， Y 是输出特征图； i、j 是输出空间位置， o 是输出通道； u、v 是核窗口内位置， c 是输入通道； K 是共享核权重， b[o] 是输出通道偏置。求和表示取当前位置的局部窗口，与核逐项相乘后跨窗口和输入通道相加。 核 K 在空间各位置复用，只随输入/输出通道变化。局部连接减少计算，权重共享让同一模式移动时响应也随之移动。输出正负只表示当前核的响应方向和强度，不自动等于某个可命名对象。深度学习库常实现互相关而不翻转核，但通常仍称卷积。 贯穿例子： 用 2×2 核 K=[[1,0],[0,−1]] 扫描 3×3 灰度图 X=[[1,2,0],[0,3,1],[2,1,0]]，步幅1、无填充。

### 2.6.2 四个窗口得到一张 2×2 特征图

局部内积怎样响应左上到右下的亮度差？。 Y=[[1−3, 2−1],[0−1, 3−0]]=[[-2,1],[-1,3]]。 窗口左上角； 窗口； 内积。 (0,0)； [[1,2],[0,3]]； 1−3=−2。 (0,1)； [[2,0],[3,1]]； 2−1=1。 (1,0)； [[0,3],[2,1]]； 0−1=−1。 (1,1)； [[3,1],[1,0]]； 3−0=3。 。 正负号表示两条对角位置的相对亮度，而非“发现了对象”。训练会从任务损失中学习许多核，再经非线性组合。

### 2.6.3 步幅、填充和膨胀决定输出几何

尺寸错一格为何会让残差相加失败？。 out=⌊(in+2p−d(k−1)−1)/s⌋+1。 in 是单个空间轴的输入长度， out 是输出长度， k 是核宽度， p 是两侧填充量， s 是步幅， d 是膨胀率，向下取整表示只保留完整落入规则的窗口。对 32×32 输入、k=3、p=1、s=2、d=1，out=⌊(32+2−2−1)/2⌋+1=16。same padding 通常让 s=1 时尺寸不变；偶数核或 s>1 时不同框架的左右填充规则可能不同。 参数； 主要作用； 常见风险。 padding p； 保留边缘/尺寸； 引入人工边界。 stride s； 下采样； 混叠、小目标丢失。 dilation d； 扩大覆盖； 栅格效应。 。

### 2.6.4 通道决定参数量，不由图片面积决定

3×3 卷积从64通道变128通道有多少参数？。 参数=(kₕk𝓌Cᵢₙ+1)Cₒᵤₜ=(3×3×64+1)×128=73,856。 kₕ、k𝓌 是核的高和宽， Cᵢₙ 是输入通道数， Cₒᵤₜ 是输出通道数；每个输出通道还有一个偏置，所以括号内加 1。空间位置共享这 73,856 个参数，无论特征图是 16×16 还是 256×256。参数量不随图片面积变，但乘加计算量会随输出空间面积增长。 1×1 卷积不混合邻居，只在每个位置混合通道；depthwise 卷积每通道单独做空间核，再用 pointwise 混合通道，显著降低计算，但通道交互和硬件效率仍须实测。

### 2.6.5 原创图：共享核产生平移等变响应

### 2.6.6 感受野按跳距逐层增长

三层 3×3、stride=1 的单元能看多大区域？。 rₗ=rₗ₋₁+(kₗ−1)jₗ₋₁， jₗ=jₗ₋₁sₗ。 l 是层编号， rₗ 是该层单元在原输入上的理论感受野边长， jₗ 是相邻单元中心映回输入时的跳距， kₗ 是核宽， sₗ 是步幅。从 r₀=1、j₀=1 开始，三层 3×3、s=1 得 r=3、5、7，因此理论感受野为 7×7。若第二层 stride=2，则后续每增加一个核位置会跨更大输入距离。 层； k/s； 跳距 j； 感受野 r。 输入； —； 1； 1。 conv1； 3/1； 1； 3。 conv2； 3/1； 1； 5。 conv3； 3/1； 1； 7。 。 理论覆盖不等于有效贡献：梯度往往集中在中心。检测、分割需用多尺度特征连接高分辨率细节与深层语义。

### 2.6.7 下采样前不过滤会产生混叠

棋盘纹理缩小后为何会变成不存在的图案？。 stride卷积或池化减少采样率，超过新奈奎斯特频率的细节会折叠为低频伪影。最大池化带来局部稳定性，但可能保留噪声峰值；平均/低通后再降采样更抗混叠。小物体若小于一个下采样单元，可能完全消失。 更小特征图不是免费压缩。 必须按目标尺寸、旋转、缩放、边界位置和压缩噪声做切片测试。

### 2.6.8 等变、不变与数据增强不能混为一谈

CNN 是否天生对旋转、缩放都不敏感？。 性质； 含义； 普通卷积是否天然具备。 平移等变； 输入移动，特征同样移动； 近似；边界/stride会破坏。 分类平移不变； 移动后类别不变； 需聚合与训练。 旋转/尺度不变； 变换后输出不变； 否；需增强或专门结构。 。 增强相当于告诉模型哪些变换应保持标签。若对数字6做180°旋转仍强制同标签，增强反而注入错误不变性。

### 2.6.9 CNN、ViT 与混合骨干各有计算甜点区

注意力出现后为什么卷积仍广泛存在？。 CNN 的局部先验、成熟内核和多尺度金字塔在有限数据、端侧和密集预测中高效；ViT 更直接建立全局内容关系，规模化训练表现强，但注意力成本和数据需求更高。现代 ConvNeXt、混合注意力及视觉基础模型说明两类设计不断互借。 约束； 优先验证。 端侧低延迟； depthwise CNN、量化。 小目标检测； 高分辨率、多尺度 CNN/混合骨干。 全局关系与大规模预训练； ViT/混合注意力。 视频流； 时空卷积与缓存策略。 。

### 2.6.11 可视化特征不能替代干预验证

看到某通道对“轮子”高激活，就能把它命名为轮子检测器吗？。 最大激活样本只展示相关性，通道也可能响应纹理、背景或共现位置。应配合遮挡、反事实替换、特征消融和跨数据集复现，观察干预是否稳定改变输出。单张显著图漂亮，不代表网络真正依赖该区域，更不能证明因果机制。

## 2.7 循环神经网络 RNN：把历史压进一个不断更新的状态（rnn）

### 2.7.1 同一个单元在时间上反复使用

参数量为何不随序列长度增加？。 hₜ=φ(Wₕhₜ₋₁+Wₓxₜ+b)， yₜ=g(Wᵧhₜ)。 t 是时间步， xₜ 是当前输入， hₜ₋₁ 与 hₜ 是更新前后的隐藏状态； Wₕ 变换旧状态， Wₓ 变换当前输入， b 是偏置， φ 是状态激活； Wᵧ 和 g 把状态变成当前输出 yₜ 。 所有时间步共享 Wₕ、Wₓ 和 b，所以序列变长只增加重复计算，不增加这组参数。hₜ 不是一份可检索的完整日志，而是模型为当前任务学到的历史摘要。共享参数让模型可处理任意长度，也让同一个变换及其误差反复作用。 贯穿例子： 用一维 RNN 读取三天设备信号 x=[1,0,2]，φ 暂取恒等函数，Wₕ=0.5、Wₓ=1、b=0、h₀=0。

### 2.7.2 三步递推可以逐项手算

最后状态到底混合了哪些历史？。 沿用上一节的一维输入 x=[1,0,2]、Wₕ=0.5、Wₓ=1、b=0、h₀=0，并令激活为恒等函数。 h₁=1； h₂=0.5； h₃=0.5×0.5+2=2.25。 展开 h₃ 可得 2+0.5×0+0.5²×1。最近输入权重为 1，两步前输入权重为 0.25；若 Wₕ=0.5，早期信息按距离指数衰减。若 Wₕ=1.2，影响可能增长，但状态与梯度也更易爆炸。 t； xₜ； 计算； hₜ。 1； 1； 0.5×0+1； 1。 2； 0； 0.5×1+0； 0.5。 3； 2； 0.5×0.5+2； 2.25。 。

### 2.7.3 时间展开把循环变成深度为 T 的计算图

递归参数怎样收到来自未来损失的责任？。 图示：三步 RNN 时间展开与反向传播路径。 图 1 前向是顺序递推；BPTT 将三次使用同一参数的梯度相加。序列越长，需保存的激活和梯度路径越长。 反向传播穿过展开图并累加每次参数复用的贡献。截断 BPTT 每 K 步切断图，内存从依赖整段变为依赖 K，但超过 K 步的直接信用路径也被切断。

### 2.7.4 梯度问题来自雅可比反复相乘

为什么 Wₕ=0.5 与 1.2 会走向两个极端？。 ∂hₜ/∂hₖ = ∏ i=k+1…t diag(φ′ᵢ)Wₕ。 hₖ 是较早第 k 步状态， hₜ 是较晚第 t 步状态；乘积遍历中间时间步 i， diag(φ′ᵢ) 是激活函数逐坐标导数组成的对角矩阵， Wₕ 是每步复用的状态权重。在一维线性例子中，跨 d 步梯度就是 Wₕᵈ：0.5¹⁰≈0.00098，早期责任几乎消失；1.2¹⁰≈6.19，容易爆炸。非线性饱和会进一步让 φ′ 接近零。 现象； 表现； 常用缓解； 不能解决。 梯度爆炸； loss/范数突增、NaN； 梯度裁剪、初始化、归一化； 长期记忆容量。 梯度消失； 早期 token 学不到责任； 门控、残差、较短路径； 被状态丢掉的原文。 。

### 2.7.5 LSTM 用近似加法通道控制记忆

门控为何比普通 tanh RNN 更容易保留信息？。 cₜ=fₜ⊙cₜ₋₁+iₜ⊙c̃ₜ， hₜ=oₜ⊙tanh(cₜ)。 cₜ₋₁、cₜ 是旧、新细胞状态， c̃ₜ 是候选内容； fₜ 是遗忘门， iₜ 是输入门， oₜ 是输出门， ⊙ 表示逐元素乘法， hₜ 是暴露给外部的隐藏状态。 遗忘门 f 决定旧记忆保留比例，输入门 i 决定写入多少候选，输出门 o 决定暴露多少状态。若 f≈1、i≈0，c 可沿近似恒等路径传递，梯度不必每步都穿过完整非线性。GRU 合并状态与部分门，参数更少。 门不是符号规则或硬存储槽；它们是数据驱动的连续向量。即使 f=0.99，跨 500 步保留比例也只有 0.99⁵⁰⁰≈0.0066。

### 2.7.6 教师强制制造训练—推理输入差异

训练每一步都看真答案，为什么上线会滚雪球？。 训练序列生成器时，常把真实 yₜ₋₁ 输入下一步；推理时只能输入模型自己的预测。一处错误把状态带到训练中很少见的区域，后续错误继续累积，这叫 exposure bias。 方法； 作用； 代价/边界。 计划采样； 逐步混入模型预测； 目标有偏、调度敏感。 序列级损失； 直接优化最终指标； 梯度估计噪声大。 beam/约束解码； 推理时减少局部错误； 不修复训练分布错位。 。

### 2.7.7 双向、堆叠与多对多只是读取方式变化

分类、标注和生成各该取哪个输出？。 many-to-one 取末状态做序列分类；many-to-many 为每步输出标签；编码器—解码器把输入压为状态再生成另一序列。双向 RNN 同时读取左右文，适合离线标注，却不能用于严格在线的未来未知场景。堆叠层提升容量，也拉长优化路径。 双向不等于预测未来。 它只适用于推理时完整序列已可见的任务；实时传感器不能偷看尚未到达的数据。

### 2.7.8 RNN 与注意力的核心差别是访问历史的方式

小状态和全量 KV 历史分别换来了什么？。 维度； RNN； 自注意力/Transformer。 历史表示； 固定状态压缩； 保留各位置 KV。 训练并行； 时间依赖强； 位置可并行。 单步流式状态； 固定大小； KV 随长度增长。 精确回看； 困难； 可直接连接旧位置。 典型优势； 端侧、传感器、低延迟； 大规模训练、长程交互。 。 实际速度取决于内核、批量和硬件。对每秒一个传感器值的在线异常检测，小 GRU 可能比大型 Transformer 更合适；对需要引用数千 token 之前原句的任务则相反。

### 2.7.9 评测要把长度、流式约束和状态恢复拆开

平均准确率为何不能证明 RNN 真正记住长依赖？。 按依赖距离画性能曲线，并加入干扰项、状态重置、缺包和超长外推。部署时测每步延迟、状态大小、批处理吞吐、冷启动和断线恢复；若把隐藏状态跨用户复用，会造成上下文串扰与隐私泄漏。 隐藏状态属于会话状态。 应绑定身份、设置生命周期、可重置并版本化；模型升级后旧状态未必兼容。

把“循环”理解成计算图共享，而不是无限记忆。 误区； 更准确的理解。 隐藏状态保存全部历史； 它是固定容量的任务相关压缩。 裁剪梯度能解决消失； 它主要限制爆炸。 LSTM 可以无限记忆； 门控改善路径但仍会衰减和覆盖。 双向 RNN 可用于实时预测； 它需要完整未来上下文。 Transformer 让 RNN 完全过时； 流式小状态场景仍有优势。 。 层级； 依赖与延伸。 先修； 神经网络、反向传播、梯度消失。 本页核心 ； 递推状态、BPTT、门控、教师强制。 对比； Transformer、状态空间模型、注意力。 应用； 语音、时间序列、流式推理。 。

### 2.7.11 把因果链连起来

### 2.7.12 误区与自测

你能否不用背术语，解释它的机制、边界与验证方法？。 例子中 h₃ 为什么等于2.25？。 Wₕ=0.5 时跨10步梯度约多少？。 截断 BPTT 的主要代价是什么？。 梯度裁剪主要缓解什么？。 双向 RNN 何时不适用？。 假设“循环神经网络 RNN：把历史压进一个不断更新的状态”在离线示例上表现正常、上线后核心结果却下降，你会怎样按输入、内部变换、输出反馈和适用边界定位问题？。 如何为“循环神经网络 RNN：把历史压进一个不断更新的状态”设计一个最小对照实验，证明观察到的改善来自核心机制，而不是数据、提示、权限或评测口径同时变化？。 。 参考答案 h₃=0.5h₂+x₃=0.5×0.5+2=2.25。 0.5¹⁰≈0.00098，表现为梯度消失。 超过截断窗口的直接信用分配路径被切断。 限制梯度爆炸；不能恢复已经消失的长期信号。 严格在线、未来输入尚不可见的实时场景。 先保存同一失败样本及环境，确认输入、权限和前置条件没有漂移；再记录关键中间状态，检查机制是否按本页描述完成变换；随后把原始输出与独立指标、人工终验对照；最后用边界样例和对照实验复测。只有定位到首次偏离预期的环节，才能判断应修改数据、机制、评测还是使用边界。 固定数据、模型版本、提示、权限、预算和评测，只改变一个与核心机制直接相关的因素，并在多个样本与随机种子上重复；同时保存中间状态和失败样本。若差异只在目标因素变化时稳定出现，才支持机制解释，否则应继续排查混杂变量。

## 2.8 Token 与分词：模型真正读写的离散语言（tokenization）

### 2.8.1 一段文字要经过哪几道门

从用户按键到嵌入向量，中间不是一次简单的“按词切开”。 图示：从 Unicode 文本到嵌入向量的分词流水线。 每一步都必须版本化；“大致相同”的实现不够，因为一个边界差异会改变后续全部 ID。 规范化可能统一某些等价字符，预切分常利用空格或正则建立候选边界，子词算法再在边界内组合，最后查词表并按模板插入 BOS、EOS、角色或工具 token。不同模型可选择不同管线，不能从屏幕上的字符数推断 token 数。

### 2.8.2 字符、字节、子词与 ID 分别是什么

“一个字就是一个 token”为什么只在偶然情况下成立？。 层级； 例子； 保证； 不保证。 Unicode 码点； 猫 、 é ； 抽象字符编号； 一个视觉字形只含一个码点。 UTF-8 字节； 猫 编为 3 字节； 任意 Unicode 可编码； 边界与人类字符一致。 子词片段； token + ization ； 有限词表可组合开放文本； 片段本身有完整语义。 token ID； 31415 ； 可索引嵌入矩阵某一行； 跨 tokenizer 仍表示同一片段。 。 组合音标、emoji 肤色修饰符和零宽连接符尤其容易让“可见字符数”失效。可靠系统应保留原文与字符偏移的映射，而不是把 token 边界冒充用户看到的字符边界。

### 2.8.3 手算一次 BPE：高频相邻对怎样变成新符号

BPE 学到的是合并规则，不是一张人工词典。 设玩具语料只含 low 5 次、 lower 2 次。初始把每个词写成字符加词尾符 </w> ，并按词频统计相邻对：。 轮次； 最高频相邻对； 频次； 合并后的表示。 0； l + o ； 7； lo w </w> ； lo w e r </w> 。 1； lo + w ； 7； low </w> ； low e r </w> 。 2； low + </w> ； 5； low</w> ； low e r </w> 。 。 第三轮优先把完整的 low 合成一个词尾 token，因为它出现 5 次； lower 仍可由 low 、 e 、 r 等组合。真实训练会有预切分、并列频次规则和实现细节，但“反复加入最有压缩收益的相邻合并”这一机制不变。

### 2.8.4 BPE、Unigram 与字节级方案在优化什么

它们都产生子词，但搜索方向不同。 方法； 训练思路； 编码特点； 典型风险。 BPE； 从小符号集向上合并； 按固定合并序列得到确定切分； 贪心规则未直接优化语言模型目标。 Unigram； 从大候选词表向下剪枝； 按片段概率选择高似然切分，可采样多种切分； 概率模型与剪枝实现更复杂。 字节级子词； 以 256 个字节为完备底座再合并； 没有真正的未知字符； 低覆盖语言或罕见串可能很长。 。 “无未知 token”只说明能编码，不说明编码高效。一个罕见字符即使能回退为多个字节 token，也会占用更多上下文位置，并让模型从更碎的证据中学习组合。

### 2.8.5 词表大小是一笔参数—序列长度交换

词表翻倍，模型付出和节省的分别是什么？。 嵌入参数量 ≈ |V| × d；注意力配对数 ≈ L²。 词表 |V| 变大，常见片段更可能由一个 token 表示，平均序列长度 L 可能缩短；但输入嵌入和输出分类矩阵随词表增长，罕见 token 获得的更新也更少。若输入输出权重共享，参数账会不同，但覆盖与稀疏训练的权衡仍在。 不能只比较“每字符 token 数”。 同时报告词表参数、实际语料长度分布、吞吐、下游质量和语言切片；压缩率更高不等于语义学习一定更好。

### 2.8.6 分词效率为什么会影响多语言公平性

相同语义的信息，为何不同语言可能消耗不同上下文预算？。 词表是从训练语料频率中学出的。高资源语言的常见词形更容易成为长 token，低资源语言可能被拆成字符或字节。可用“fertility（每词或每字符 token 数）”与压缩率按语言统计，但还要结合形态结构、书写系统和任务质量，不能把某个语言天然较多 token 直接解释为歧视。 要测什么； 为什么； 避免的误判。 每语言长度分布； 估计成本与截断概率； 只看全局平均。 数字、姓名、代码切片； 检查复制与边界能力； 只测自然段落。 任务准确率随 token 长度； 分离语言与长度因素； 把所有差异归因于 tokenizer。 。

### 2.8.7 特殊 token 和聊天模板为何属于模型协议

同一句用户问题，加上不同角色标记为什么会得到不同结果？。 预训练或指令微调会让特定 ID 承担“序列开始”“用户开始”“助手开始”“工具结果”等控制含义。聊天模板决定这些 ID 的顺序、换行和结束边界。漏掉助手前缀、重复 BOS，或把 EOS 当普通文本，都会让模型进入训练中不熟悉的状态。 新增 token 还需要扩展嵌入和输出矩阵并训练新行；仅把字符串登记到词表，不会自动赋予概念。模板、tokenizer 文件、词表哈希与权重应作为一个发布单元。

### 2.8.8 数字、代码和复制任务为什么对边界敏感

分词不会决定模型全部能力，却会改变要学习的最短路径。 若长数字按不稳定长度片段切分，逐位运算和复制需要在片段内部恢复位结构；若缩进、换行或运算符边界被合并，代码模型要同时学习内容和隐藏边界。相反，把每个字符都拆开会显著增加长度。合理设计应通过真实任务验证，而不是凭“更像人类词语”判断。 生成时 token 也是解码单位：流式输出可能暂时只有不完整 UTF-8 字节，停止串也可能跨 token 边界。服务端应在字节解码和停止匹配上处理跨块状态。

### 2.8.9 Unicode 和偏移量怎样制造静默故障

屏幕看起来相同的文本，底层序列可能为什么不同？。 预组字符 é 与 e 加组合重音可以视觉相同却由不同码点组成；全角字符、不可见控制符和跨文字系统的形似字符也可能绕过字符串规则。规范化可减少部分差异，但也可能改变要求逐字保真的任务，因此必须明确采用何种 Unicode 形式。 标注系统常以字符、UTF-16 代码单元或 UTF-8 字节保存偏移；tokenizer 又输出自己的 offset mapping。混用单位会让实体高亮、训练标签和审计证据错位，而且通常不会报错。

### 2.8.10 怎样做一次可复现的 tokenizer 验收

能把普通英文编码再解码，不代表接口已经可靠。 固定工件： 保存词表、合并规则/模型、规范化、预切分、特殊 token、模板和哈希。 做往返测试： 普通文本、空串、换行、组合字符、emoji、CJK、RTL、代码和随机字节。 做黄金 ID 测试： 固定若干字符串及其精确 ID，跨语言实现逐项比对。 验证 offset： 把 token 偏移重新映射到原文，检查组合字符和代理对。 验证模板： 打印完整聊天 ID，确认角色、BOS/EOS 和工具边界只出现预期次数。 统计分布： 按语言和任务报告 token 长度、截断率、未知/字节回退和延迟。 验证流式： 随机切分输出块，确认 UTF-8 解码和停止串检测结果不变。

### 2.8.11 把整条因果链连起来

用户产生 Unicode 字符串，其中可能包含组合字符和不可见符号。 规范化与预切分确定候选边界。 BPE、Unigram 或字节级规则把文本覆盖成有限词表片段。 词表把片段映射到整数 ID，模板插入控制 token。 嵌入矩阵按 ID 查行，模型只对这条离散序列计算。 切分粒度改变序列长度、训练频率和要学习的组合路径。 解码与流式服务把 token 恢复为字节和可见文本。 任一工件或边界规则变化，都必须与权重共同验证和发布。

### 2.8.12 常见误解

误解； 更准确的说法。 token 就是词； token 可是词、子词、字符、字节片段或控制符。 字符数等于 token 数； Unicode 组合、语料覆盖和合并规则都会改变比例。 字节回退表示所有语言同样高效； 它只保证可编码，罕见串仍可能被拆得很长。 词表越大越好； 序列可能变短，但参数、稀疏更新和迁移成本会上升。 只要文本相同就能替换 tokenizer； ID 与嵌入行绑定，模板和特殊 token 也参与训练协议。 。

### 2.8.13 检查你是否真的理解

在玩具 BPE 中，为什么 l+o 的频次是 7？。 字节级方案为什么没有未知字符，却仍可能让某些语言更昂贵？。 词表从 32k 增至 64k 时，至少哪两项资源会向相反方向变化？。 为什么只修改特殊 token 的 ID 就可能破坏模型？。 实体标注偏移正确但高亮错位，你会优先检查哪些单位？。 参考答案 low 出现 5 次、 lower 出现 2 次，两者开头都有该相邻对。 任意文本能由字节覆盖，但低覆盖片段可能需要多个字节 token，增加长度与截断。 嵌入/输出矩阵参数通常增大，而平均序列长度可能减小；最终算力变化需实测。 该 ID 对应已训练嵌入和控制语义；重排后模型会读到另一行向量。 原文偏移究竟按码点、UTF-16 单元还是 UTF-8 字节，以及规范化前后是否混用。

### 2.8.14 概念依赖与延伸学习

方向； 接下来读； 关键问题。 ID 如何变向量； 嵌入 ； 离散索引怎样通过训练获得几何关系？。 顺序如何进入模型； 位置编码 ； token 已切好后，模型怎样知道先后和距离？。 长度为何昂贵； 自注意力 ； 序列长度怎样进入时间与显存复杂度？。 协议怎样训练； 指令微调 ； 角色和回答边界怎样成为监督信号？。 上线怎样守住边界； 模型服务 ； 流式解码、截断和版本如何监控？。 。 过关标准 给你一段多语言文本和一个模型包，你能画出从原始字节到 ID 的每一步，手算一次 BPE 合并，并列出更换词表、模板或规范化时必须重验的接口。

## 2.9 嵌入 Embedding（embedding）

### 2.9.1 什么是嵌入

本节回答：想让机器判断「两段话意思相近」，第一步要解决什么？。 嵌入是一种把文本映射成连续向量的表示方法。 它要解决的问题是：机器只会算数字，不能直接比较两段文字的意思。所以第一步是把文本变成数字——但不是随便变，而要变得让「意思近」体现成「数字近」。把一段文本输入嵌入模型，它先编码文本、再输出一个几百到几千维的向量；两个向量的距离越近，就表示这两段文本语义越相近。可以把它想成给每段话在一张「语义地图」上标了个坐标——但这张地图是某个模型自己的坐标系，换一个嵌入模型，同一段话的坐标就不再可比。 图示：语义空间里，意思相近的内容聚在一起。 图 1 把内容放进一张「语义地图」：意思相近的自动聚成一簇。注意「怎么退货」和「商品返还流程」——它们没有共同关键词，却因为意思相近而挨在一起。这正是嵌入的全部价值所在。 。

### 2.9.2 凭什么「距离能等于语义」

最关键的疑问：向量的远近，凭什么正好对应意思的远近？这不会是碰巧吧？。 向量的远近为什么等于语义，不是碰巧，可以理解为训练目标逼出来的几何性质；它用于回答的正是凭什么向量远近能对应意思远近。训练时输入大量意思相近或无关的样本对，先据这些配对调整参数、再让相近的向量靠拢、无关的向量推开，最终输出一个语义被编码进几何的向量空间。相近样本被不断拉近，就表示模型学到了它们的关联。 更早的词向量，靠一个更朴素的假设 「 上下文相似的词，意思也相似 」。「猫」和「狗」周围出现的词（喂、养、可爱、宠物店）高度重合，于是让它们的向量自然靠近。无论哪种训练方式，「距离 = 语义」都不是设计出来的规则，而是 训练的副产品 。

### 2.9.3 它把「语义」变成了可计算的东西

有了这张语义地图，我们具体能算什么？。 余弦相似度是一个用两个向量夹角的余弦值比较方向的指标。它用于解决怎样判断两段话是不是在讲同一件事：不再需要它们共享字面词汇，只要看两个向量的夹角——夹角越小、越同向，就越相近。于是输入两个嵌入向量，先算点积、再除以两者长度，就输出一个相似度分数——语义第一次变成了能用一个数直接比较的量。 相似度 = cos(θ) = (A·B) / (‖A‖ ‖B‖)。 符号逐个解释： A 和 B 是要比较的两个嵌入向量； θ 是它们之间的夹角； A·B 是点积； ‖A‖ 与 ‖B‖ 是各自的长度。分母先消除长度影响，因此余弦只比较方向。结果范围是 −1 到 1：越接近 1 越同向，接近 0 表示近乎垂直，接近 −1 表示方向相反。它只表示 同一嵌入模型空间 里的相似程度，不能跨模型比较，也不能脱离真实任务直接解释为“正确概率”。 一个经典演示：向量还能做算术 国王 − 男人 + 女人 ≈ 女王 。这说明向量空间里的 方向本身 就承载了语义关系（这里「从男到女」是一个稳定的方向）。语义被编码进了几何。 这就是一大片技术的地基 「把语义变成可算的向量」直接撑起了： 检索与语义搜索、向量数据库、RAG、聚类 ——它们本质都在做「找向量最近的邻居」或「把相近的向量归堆」。理解嵌入，就理解了这些的共同底层。

### 2.9.4 手算一个余弦相似度

“更同向”怎样变成一个可复算的排名？。 这次手算描述余弦相似度怎样把方向差异变成可排序的分数，为的是解决更同向怎样落成可复算排名。用二维玩具向量代替真实的数百维向量。查询 q=[1,0] ，候选“返还商品”是 a=[0.8,0.6] ，候选“列车时刻”是 b=[−0.6,0.8] ；三者长度都为 1：。 候选； 点积； 余弦与结论。 a； 0.8 ； 0.8 ，更相关。 b； −0.6 ； −0.6 ，更不相关。 。 展开计算分别是 1×0.8 + 0×0.6 = 0.8 与 1×(−0.6) + 0×0.8 = −0.6 ；因为三个向量都是单位长度，分母均为 1。整个过程输入查询与候选向量，先做点积、再按长度归一，就输出每个候选的相似度。 图示：查询向量与两个候选向量的夹角比较。 余弦只比较方向，不比较长度。真实检索常先把向量归一化，使点积直接等于余弦相似度。 数值高只表示模型空间里的相似，不等于业务上正确。 阈值必须在真实查询、难负例与标签上校准；不同模型的 0.8 没有统一含义， 不能跨模型直接照搬 。

### 2.9.5 两个容易混的「嵌入」

你可能已经注意到：有时说嵌入是「模型里的一层」，有时又说它是「一个独立模型」。这是两回事，别混。 ； Transformer 内部的输入嵌入层； RAG 里说的「嵌入模型」。 是什么； 模型架构的一部分； 一个独立训练的模型。 输出谁的向量； 每个 token 的向量； 整 段文本 的一个向量。 目标； 给 Transformer 喂输入（见其深读页）； 让整段话的语义可比较、可检索。 。 为什么要分清 这里比较的是两个同名却不同的嵌入，为了解决该用哪一个嵌入的选型问题。两者名字都叫「嵌入」，但一个是把 token 送进模型的第一层，一个是产出「整段文本表示」的专用模型：嵌入层先逐词给向量、再交给后续网络，嵌入模型则直接把整段话汇总成一个向量。它们输入同样是文本，输出却分别是每个词的向量或整段文本的一个向量。用途不同表示不能互相替代，但两者都叫嵌入，混用就会让选型和实现出错。

### 2.9.6 最典型的用武之地：语义搜索

回到开头那个例子——嵌入到底让什么「关键词搜索做不到的事」成为可能？。 关键词搜索靠 字面匹配 ：查询词必须和文档里的词对上，所以查「怎么退货」命中不了只写「商品返还流程」的文档。语义搜索正是为了解决关键词搜索漏掉这类没有共同词的相关文档——它指的是按意思而非字面找最近邻的检索方式：输入查询和文档库，先把两者都嵌入成向量、再输出离查询最近的那些文档，匹配的是意思不是字。于是「退货」和「返还流程」尽管没有共同词，也能被召回；某文档被召回，就表示它与查询意思相近，但召回质量依赖嵌入好坏，平均召回好也不保证每条都对。 它是 RAG 的心脏 检索增强生成（RAG）回答问题前，就是用嵌入做语义搜索、从知识库里捞出相关材料，再交给大模型作答。 嵌入的质量，直接决定了检索能不能捞对 ——而检索捞得对不对，往往是 RAG 效果的真正瓶颈（见「检索」「向量数据库」「RAG」节点）。

### 2.9.7 实践里的两个坑

用嵌入最容易在哪翻车？下面两个坑描述换模型和否定两种失败，认识它们是为了避免嵌入在工程落地时最常见的两类翻车。 换嵌入模型，必须重建整个索引 。同一批文本输入不同模型，输出的向量先落到不同空间、再被拿来混用，就会得到一堆噪声——A 模型的「猫」和 B 模型的「猫」坐标毫无可比性。换模型 = 全部重新嵌入。 对「否定」不敏感 。「适合儿童」和「 不 适合儿童」，字面几乎一样，向量也可能 非常接近 ，但这只表示表面相似、意思其实正相反。这类「一个字翻转全意」的场景，光靠向量相似度容易出错，要用别的手段兜底（如加规则、重排、结构化过滤）。 顺带解两个新词：高维与降维。 “高维”只表示一个向量有很多坐标，例如 768 维就是 768 个数共同描述一段文本；维数增加后，样本间距离可能越来越接近、难以区分，这类现象常被概括为“维度灾难”。训练后的嵌入通常不是随机散点，而会形成与训练任务有关的结构，所以高维距离仍可能有用；但这不是保证，必须用真实检索样本验证。为了让人观察，常用“降维”把数百维临时映射成二维或三维图。降维图只是一种有损投影：它适合发现可疑簇和离群点，不能证明原空间的检索质量，也不能取代 Recall@k 等任务指标。 如何验证检索质量： 先建立带相关等级的查询—文档小金集，报告 Recall@k、nDCG 或 MRR，再按否定表达、数字、专有名词、语言和文本长度切片。若平均召回很好但“不适合儿童”仍命中“适合儿童”，应诊断为困难负例与排序边界问题，加入结构化过滤或重排；不要只看二维降维图是否“聚成一团”。换模型时还要在同一金集上复测并重建索引。

### 2.9.8 把整条因果链连起来

从对象到向量、再到检索结果，中间哪些选择共同定义“相似”？。 机器要比「意思」，先得把文本变成数字，且让「意思近」体现成「数字近」——这就是嵌入。 （§1） 。 「距离 = 语义」不是设计的，是训练让相近靠拢、无关推开逼出来的。 （§2） 。 于是判断两段话是否同义，只需算向量夹角；语义第一次变成可计算的量。 （§3） 。 余弦相似度把向量方向关系变成可排序的数，但阈值只能由真实任务校准。 （§4） 。 注意区分两个「嵌入」：Transformer 的输入嵌入层（每个 token）vs 独立的嵌入模型（整段文本）。 （§5） 。 它最典型的用途是语义搜索：按意思而非字面找最近邻，这是 RAG 的心脏。 （§6） 。 两个必知的坑：换模型要重建索引、对否定不敏感。 （§7） 。 过关标准 如果你能讲清「向量的距离为什么能等于语义」，并说出「语义搜索凭什么能召回没有共同关键词的文档」，你就抓住了嵌入的内核。

### 2.9.9 常见误解

哪些说法把任务相关的表示空间误当成了天然语义真理？。 误解； 更准确的理解。 嵌入就是把词编个号； 是变成 连续向量 ，且让语义相近的向量靠近；编号没有「远近」可言。 距离等于语义是设计出来的规则； 是训练目标（让相近靠拢）逼出来的副产品。 不同模型的向量可以混用； 不能；不在同一空间，换模型必须重建索引。 语义相似度什么都能判； 对「否定」等一字翻转的情形不敏感，需别的手段兜底。 「嵌入层」和「嵌入模型」是一回事； 一个输出 token 向量、是架构一层；一个输出整段文本向量、是独立模型。 。

### 2.9.10 检查你是否真的理解

嵌入把文本变成什么？关键性质是什么？。 向量的距离凭什么能对应语义的远近？（用「训练目标」解释）。 有了嵌入，判断两段话是否同义为什么不再需要共享关键词？具体算什么？。 「Transformer 的输入嵌入层」和「RAG 的嵌入模型」有何区别？。 语义搜索为什么能召回「怎么退货 / 商品返还流程」这种没有共同词的配对？。 为什么换一个嵌入模型就必须重建整个索引？。 为什么嵌入对「适合儿童 / 不适合儿童」这种否定容易判错？。 参考答案 变成一个高维连续向量；关键性质是语义相近的文本，向量距离也近。 训练时用「相近/无关」的样本对，调参数让相近的向量靠拢、无关的推开，反复后向量几何就编码了语义。 因为语义已被编码进向量，只要算两个向量的夹角（余弦相似度）即可，不必有共同字面词。 前者是架构一层、输出每个 token 的向量；后者是独立模型、输出整段文本的一个向量，用于检索。 因为它匹配的是意思而非字面：两句话意思相近，向量就靠近，于是查询能找到它。 因为不同模型的向量不在同一空间，坐标不可比；旧库的向量和新模型的查询向量混用会得到无意义的结果。 因为字面几乎一样，向量也很接近，但意思相反；纯相似度分不出这一字之差的语义翻转。

## 2.10 位置编码与 RoPE：让注意力知道顺序和距离（positional-encoding）

### 2.10.1 注意力只比较内容时缺少什么

把输入 token 同步重排，为什么输出也只是同步重排？。 自注意力用每个 token 的内容生成 Q、K、V，再按点积混合。若没有位置向量、位置偏置或因果遮罩，重排输入只是重排 Q/K/V 的行列，最终输出以同样方式重排。这叫排列等变：模型保留“哪个输出属于哪个输入”，却没有额外坐标区分第 1 位和第 7 位。 因果遮罩会引入“只能看过去”的方向结构，因此严格说自回归层并非完全无序；但它仍需要位置机制表达精确距离、周期与顺序模式。把“无位置注意力”说成排列不变，会混淆输出同步变化与池化后整体不变。

### 2.10.2 位置可以加到表示、分数或几何变换中

图示：四类位置机制进入注意力的不同位置。 位置不是一种固定“编码格式”，而是一类把坐标关系注入不同计算位置的设计。 方法； 注入位置； 主要表达； 外推特点。 学习绝对表； 与 token 嵌入相加； 每个索引独立向量； 表外位置没有训练参数。 正弦绝对编码； 与 token 嵌入相加； 多频坐标； 函数可计算到表外，但模型未必会用。 相对偏置 / ALiBi； 注意力 logits； 位置差或距离惩罚； 结构上更自然地延伸距离。 RoPE； 旋转 Q/K； 内容点积中的相对相位； 可计算但会遇到未训练相位与频率分辨率。 。

### 2.10.3 正弦编码为什么要一组快慢不同的钟

只用一个周期为什么会混淆远处位置？。 PE(pos,2i)=sin(pos / 10000 2i/d )；PE(pos,2i+1)=cos(pos / 10000 2i/d )。 先读符号： PE 是要加到 token 表示上的位置向量； pos 是该 token 从 0 开始的位置索引； d 是位置向量总维数； i 是第几组正弦—余弦维度，所以 2i 与 2i+1 是同一组的两个坐标。常数 10000 控制从快到慢的频率范围，并不是序列最大长度。 低维对变化快，分辨局部位移；高维对变化慢，提供长尺度坐标。每个 sin/cos 对可看作圆上的指针，多组不同速度的指针共同形成位置签名。单一频率会周期性重复，多频组合把混淆推到更远。 由于正弦的和差关系，平移后的坐标可由原坐标的线性组合表示，这给模型学习相对位移提供了结构。但“存在这种表达”不代表有限层和有限数据必然学到稳定的长度外推。

### 2.10.4 手算 RoPE：点积怎样只留下位置差

二维向量旋转后，绝对角度为什么相消？。 先看一对维度。 q 是某个位置的查询内容向量， k 是另一个位置的键内容向量；令 q=k=(1,0) 。 m 与 n 分别是查询和键的位置索引，每前进一位旋转角 θ=60° ； R(α) 表示把二维向量旋转角度 α ，上标 ᵀ 表示转置，因此左右相乘得到一个点积分数。位置 m 的查询是 R(mθ)q ，位置 n 的键是 R(nθ)k ：。 (R(mθ)q)ᵀ(R(nθ)k)=qᵀR((n−m)θ)k=cos((n−m)θ)。 旋转矩阵做点积时，查询和键共同经历的绝对旋转会相消，只剩键相对查询多转的 (n−m)θ ；所以同时把二者位置向后平移相同距离，不会改变这一项的分数。 m； n； 位置差 n−m； 点积。 0； 0； 0； cos 0°=1 。 0； 1； 1； cos 60°=0.5 。 2； 3； 1； cos 60°=0.5 。 0； 2； 2； cos 120°=−0.5 。 。 (0,1) 与 (2,3) 的绝对位置不同，但相对位移相同，因此这对维度贡献相同。真实 RoPE 把高维向量两两分组，每组使用不同频率，并保留 q、k 内容本身的方向关系。

### 2.10.5 RoPE 的几何图像：每对维度是一只指针

把公式画成圆上的旋转，能看出哪些不变量？。 图示：二维向量在三个位置按固定角度旋转。 旋转保持向量长度；改变的是相位。不同频率对提供不同距离尺度，类似多只转速不同的指针。 RoPE 通常只施加到 Q/K 的部分或全部头维度，不旋转 V。旋转比例、基频、维度配对顺序和实现中的复数/实数布局都必须与训练权重一致。

### 2.10.6 相对偏置与 ALiBi 在分数上直接表达距离

如果任务关心“离我多远”，为什么不直接修改 logits？。 score(i,j)=qᵢ·kⱼ/ d + b(i−j)。 这条式子在做什么： i 是发起注意的查询位置， j 是被查看的键位置； qᵢ 和 kⱼ 是二者的查询、键向量； d 是键向量维数，除以其平方根用于控制点积尺度； b(i−j) 是由相对距离决定的附加偏置。 score(i,j) 是 softmax 之前的注意力原始分数，也就是这里所说的 logits。 相对位置表示可为每个截断距离学习偏置或向量。ALiBi 使用各注意力头不同斜率的线性距离惩罚，在因果注意力中通常让更远历史获得更负偏置；不同头覆盖不同距离尺度。它不需要绝对位置表，却也带有“距离越远通常越不相关”的归纳偏好，未必适合所有结构。

### 2.10.7 长上下文缩放究竟改了什么

把位置 64K 映射到训练时 8K 范围，收益和代价是什么？。 位置插值把新位置压缩到训练位置区间，使 RoPE 相位不至于走到完全未见区域；其他方法会调整基频或按维度分段缩放。压缩带来覆盖，却降低相邻位置的相位差，相当于用有限角度分辨率表示更多位置。短距离区分与长距离覆盖因此存在权衡。 这里的“困惑度”是模型对下一个 token 有多不确定的整体指标，越低通常表示语言建模越好；但它会被大量只需看附近文本的容易位置平均掉，所以不能单独证明模型利用了远处信息。 层面； “扩展成功”证据； 常见假阳性。 可运行； 目标长度不报错、不越界； 只改配置最大长度。 语言建模； 困惑度随长度没有灾难性上升； 大量容易的局部预测掩盖远距失败。 检索； 针在不同深度都能找回； 固定针、固定模板被记住。 推理利用； 多证据、顺序敏感任务随长度稳定； 只测单点复制。 。

### 2.10.8 频率、混叠与注意力衰减怎样限制远距关系

位置函数能算到任意整数，为何质量仍会退化？。 快速频率在长距离上多次绕圈，不同位移可能具有相似相位；慢频率覆盖远但对相邻位置不敏感。多频组合缓解而非消除这个问题。模型又只在有限长度分布上学过如何组合这些频率，超出后注意力模式、归一化尺度和内容检索都可能改变。 “RoPE 支持长度”不是一个只由公式决定的常数。 它还依赖基频、缩放、训练最大长度、长度采样、微调数据、KV cache 实现以及你把“支持”定义为可运行、可检索还是可推理。

### 2.10.9 KV cache 为什么最容易出现位置静默错位

缓存内容都对，position ID 错一位会发生什么？。 自回归生成会缓存历史 K/V。新 token 的 Q/K 必须使用它在完整序列中的位置，而不是当前小批张量中的局部索引。前缀复用、滑动窗口、分页缓存、左填充和批量长度不同时，位置起点尤其容易错。错误通常保持形状合法，只表现为质量下降。 验收应比较“完整序列一次前向”和“逐 token 带 cache 前向”的 logits，在多个长度、填充方向和缓存切块下要求数值接近；同时记录 RoPE 基频、缩放类型、旋转维度和 position ID 生成规则。

### 2.10.10 怎样评测模型是真的使用了位置

先测短长度基线： 避免把原有能力不足归咎于外推。 扫长度也扫深度： 同一证据放在开头、中间、结尾和随机位置。 加入顺序对照： 打乱证据顺序或交换主体客体，答案应相应改变。 从复制升级到组合： 单针检索、多针聚合、时间顺序和跨段推理逐级测。 控制内容难度： 用同一内容改变填充长度，隔离位置影响。 比较 cache 路径： 全量前向与增量前向 logits 对齐。 报告分布而非最大值： 按位置、长度和任务给出成功率与置信区间。

### 2.10.11 把整条因果链连起来

从离散序列到“模型真的会用远处信息”，中间经过哪些必要环节？。 tokenizer 产生有顺序的离散序列，但内容嵌入本身不含坐标。 无位置自注意力只按内容关系计算，排列输入会对应排列输出。 绝对编码、相对偏置或 Q/K 旋转加入坐标结构。 RoPE 让 Q/K 点积同时依赖内容和相对相位。 训练长度分布教会模型怎样解释这些频率和距离。 缩放可把更多索引映射到可计算范围，但改变局部与远距分辨率。 KV cache 必须延续全序列 position ID 与相同旋转配置。 最终用长度×位置×任务矩阵验证有效利用，而非只看窗口声明。

### 2.10.12 常见误解

误解； 更准确的说法。 无位置注意力是排列不变； 逐 token 输出是排列等变；输入重排，输出同步重排。 因果遮罩等于完整位置编码； 它提供可见方向，但不足以表达丰富距离与精确索引。 RoPE 给 token 向量加一个位置向量； 它通常按位置旋转 Q/K，在点积中形成相对相位。 公式可算到 1M 就支持 1M； 可计算不等于训练见过，也不等于任务能利用。 只要单针检索通过就具备长推理； 复制、聚合、顺序与推理是不同难度层级。 。

### 2.10.13 检查你是否真的理解

排列等变与排列不变的区别是什么？。 二维 RoPE 例子中，为什么位置 (0,1) 与 (2,3) 的点积相同？。 正弦编码为何同时需要快频和慢频？。 位置插值可能牺牲哪类分辨率？。 增量推理质量下降但全量前向正常，你会优先检查什么？。 参考答案 等变是输出随输入同样重排；不变是整体输出完全不变。 旋转矩阵的绝对角相消，两对位置差都为 1，因此留下相同相对角。 快频区分局部，慢频覆盖长距离，多频共同减少周期混淆。 把更多位置压入训练角度范围会缩小相邻位置相位差，可能损失局部分辨率。 position ID 起点、RoPE 配置、缓存切块/填充规则，并比较 cache 与全量 logits。

## 2.11 注意力机制（attention）

### 2.11.1 要解决的核心难题

本节回答：理解一句话里的某个词，到底难在哪？。 理解一个词，几乎总要看它和句子里 哪些别的词 有关。处理「她」，就得联系到「小红」；而「小红」可能在好几个词之外。真正的难题在于： 相关的词可能离得很远 ，而且 该看谁是随内容变的 ——不能靠固定规则（比如"只看前三个词"）来决定。注意力就是专门解决这个难题的一套机制：让模型自己决定每个位置该看向序列中的哪些位置，而不是由外部规则指定。 它怎样做到？每个词先产出一组表示，再逐个和其他词比较内容相关度，最后按相关度高低汇总信息——相关度高的词会贡献更多。输入是序列里全部词的一组表示，输出是每个词看过全序列后的新表示。正因为权重来自内容比较，某个词被看重，就表示它在当下与当前词更相关，而不是因为它在句子里离得最近。 旧办法为什么不够 在注意力之前，主流是循环网络（RNN）：像读书一样 按顺序 一个词一个词处理，把“记忆”沿链条往后传。长路径会让早先信息更难保留，而且时间步之间难以并行；门控 RNN 能缓解但不能消除这两个结构约束。注意力的权重虽由内容驱动，但注意力本身不能保证模型一定把权重放到正确位置——它提供的是一种机制，而非正确性的保证。第 5 节会逐项比较。

### 2.11.2 核心机制：Query / Key / Value

怎么让模型「自己决定该看哪些词」？答案是一套三步的匹配-加权流程；这套流程可以理解为让每个词自己去和别人比匹配、再按匹配度汇总信息的机制，用于解决模型该重点看句中哪些词的问题。 每个词先产出三个向量，各有分工：。 向量； 角色； 一句话。 Query（查询）； 我在找什么； 「她」发出：我在找我指代的那个人。 Key（键）； 我能提供什么； 每个词亮出一张「标签」，供别人匹配。 Value（值）； 我的实际内容； 一旦被选中，真正被汇总走的信息。 。 于是每个词输入自己的查询、键、值，先算查询与所有键的匹配，再归一成权重、按权重汇总所有值，输出一个看完全场后的新表示。具体三步是：。 算匹配度 ：用当前词的 Query 去和 所有 词的 Key 做点积——点积越大，越「对味」。 归一化成权重 ：把这排匹配度过一个 softmax，变成一组相加为 1 的权重（谁匹配高，谁权重大）。 加权求和 ：按这组权重，把所有词的 Value 加权平均，作为当前词「看完全场后」得到的新表示。 Attention(Q, K, V) = softmax( Q·Kᵀ / d ) · V。 符号逐个解释： Attention 表示这整套注意力计算的输出。Q、K、V 分别是所有可见 token 的查询、键、值向量排成的矩阵；上标 T 表示转置，使每个查询能与每个键做点积；d 是每个键/查询向量的维数，除以它的平方根是为防止维数增加时点积过大；softmax 把每个查询对应的一排分数变为和为 1 的权重，最后乘 V 完成加权求和。掩码和位置偏置若存在，会在 softmax 前共同修改分数。 图示：处理「她」时，注意力权重偏向「小红」。 图 1 处理「她」时，它的 Query 和每个词的 Key 匹配，softmax 后「小红」拿到最高权重，于是「她」主要汇总了「小红」的信息。粗细即权重大小。 。 抓住这一句 权重不是按“离得近就固定更大”的规则分配，而是由 Query–Key 内容匹配、位置机制和掩码 共同算出。「她」看向「小红」，主要因为它们在这个头里“对味”，而不是仅仅因为相邻；如果模型使用 RoPE、相对位置偏置或局部窗口，距离和可见性也会影响最终分数。权重高只表示该词在这个头里更匹配，但这不是解释概率，也不能证明它是结论的唯一原因。

### 2.11.3 手算一次缩放点积注意力

从两组匹配分数到最终输出，softmax 和 Value 各改变了什么？。 这段手算描述缩放点积注意力怎样把分数变成一次加权混合，为了看清权重到底怎样落到具体数值。设单个查询 q=[1,0] ，两个键 k₁=[1,0] 、 k₂=[0,1] ，键维度 d=2 ；对应值为 v₁=[2,0] 、 v₂=[0,4] ：。 步骤； 计算； 结果（约）。 点积； [q·k₁,q·k₂] ； [1,0] 。 缩放； [1,0]/ 2 ； [0.707,0] 。 softmax； exp(s)/Σexp(s) ； [0.670,0.330] 。 加权和； 0.670v₁+0.330v₂ ； [1.340,1.320] 。 。 第一把键更匹配，所以它的 Value 权重更大；输出却不是复制 v₁ ，而是两个 Value 的混合。Key 决定“取多少”，Value 决定“取什么”，二者不能混为一谈。整个手算输入查询、键、值，先做点积与缩放、再归一并加权求和，就输出一个混合向量。权重更大，就表示这把键更匹配。 注意力权重不是解释概率。 它只描述当前头、当前层的一次信息混合系数；残差、其他头和后续层仍会改写表示。高权重不证明某 token 是模型结论的唯一原因。

### 2.11.4 自注意力：句子内部互相看

上一节的 Q、K、V 都从哪来？这决定了「谁在看谁」。 查询、键、值都来自同一句话的注意力，称为 自注意力（self-attention） 。它解决的问题是：句子内部各词如何互相参照才能理解彼此的角色和关系——比如「她」需要在同一句中定位「小红」。 自注意力输入同一句话的词表示，先让每个词与同句所有词比较相关度，再按权重汇总输出每个词看过全句后的新表示——我们的运行示例「她」在同一句里找到「小红」，就是这样。某个词主要看向另一个词，就表示两者在句内更相关。 但这只是同一句内部的关系。换成跨句，就需要另一种变体：交叉注意力（见下）。 还有一种「跨着看」 如果 Query 来自一个序列、Key/Value 来自 另一个 序列，就是 交叉注意力 ，常见于翻译（让译文的每个词去看原文）。机制完全一样，只是「看的对象」换成了另一串。本页之后仍以自注意力为主。

### 2.11.5 为什么它是转折点

最关键的一节：注意力到底比之前的 RNN 强在哪，值得取而代之？。 相较于按时间步串行传递的经典 RNN，它改善了两个关键瓶颈：。 从输入输出看，它接收整段序列中所有 token 的表示，并同时输出每个位置融合可见上下文后的新表示；“并行”指这些位置不必像 RNN 那样等待前一个时间步完成。注意力之所以是转折点，可以理解为它用一层内的直接连接替代了旧的逐步传递，正是为了解决长距离依赖难学和无法并行这两个瓶颈：计算时每个位置先与所有可见位置直接匹配，再并行地一次算完。路径更短，就表示远距信息更容易学到，但更短的路径不保证权重一定落在正确位置。 图示：RNN 逐步传递路径长，注意力任意两词直连。 图 2 经典 RNN 中相隔 n 个时间步的信息要经过长度随 n 增长的传递链；全局注意力让任意两个可见位置在一层内直接交互。路径更短有利于学习远距依赖，但仍要经过投影、softmax 与后续层，并非“没有衰减”。 。 长距离信息路径更短 。RNN 里隔 n 个词通常要走 n 步；全局自注意力让任意两位置在一层内直接交互。短路径有利于学习远距离依赖，但不保证模型一定会把权重放在正确位置。 可以并行 。RNN 必须算完第 t 步才能算第 t+1 步；注意力的所有位置 同时 计算，能吃满 GPU。 第二点被严重低估 「能并行」直接决定了「把模型和数据一起放大」在工程上 可行 。没有并行，训练大模型的时间会长到不现实—— 没有注意力的并行，就没有缩放定律那条路，也就没有今天的大模型规模。 。

### 2.11.6 多头注意力：为什么要好几组

一组注意力只能按一种方式衡量「相关」。可词与词的关系有很多种，一组够吗？。 多头注意力 是一种在同一层并行跑多组注意力、各看一种相关方式的机制，用于解决单组注意力只能按一种方式衡量相关的问题。它输入同一批词表示，先在各自的子空间分别做注意力，再把多组结果拼接、投影，输出综合了多个视角的新表示。有些头会呈现语法、指代或位置模式——这只表示分工可能在训练中形成，但这种分工是学出来的、而非架构预先指定，也有许多头相互冗余。 分工若出现，是训练学出来的 没人预先指定某个头“专管指代”。多头提供的是多个表示子空间和并行路由机会，最后拼接并投影；能否形成稳定可解释分工要靠实证分析。

### 2.11.7 它的代价：平方级开销

这么强，代价是什么？答案藏在「每个词都要看所有词」这句话里。 平方级开销 衡量的是每个词都要与所有词两两匹配带来的成本，搞清它是为了解决长上下文为什么又慢又贵。设 n 是序列的 token 数，模型输入序列里全部位置的表示，先让每个位置与所有位置两两算分、再归一化与加权，输出每个位置的新表示；因此注意力分数矩阵有 n² 个元素，计算量与朴素显存占用随长度平方增长。长度翻倍成本就翻四倍，这表示开销是超线性的，但实际总成本还包含投影与前馈层，FlashAttention、滑窗或稀疏注意力也会改变显存常数或复杂度。 算一笔账 1 千个 token 的输入，注意力要算约 100 万对；10 万个 token 就是约 100 亿 对。这就是长上下文推理又慢又贵的原因——不是厂商不愿意给，而是每一档长度都要付超线性的代价。 这条平方开销直接约束了两件事：。 它是 上下文窗口 无法随意放大的根本原因——窗口越长，开销越吃不消。 长窗口还会暴露 「中间迷失」 等位置偏差：模型可能更善用开头和结尾的信息。这是训练分布、位置表示和注意模式等多因素结果，不能只归因于“权重被摊薄”。 一整条优化路线 围绕这个瓶颈，有稀疏注意力（只算部分位置对）、滑窗注意力（只看邻近范围）、以及工程层面的 FlashAttention（不降复杂度，但大幅减少显存搬运）。它们缓解开销，但「平方」这个根本量级仍在。 怎样验证优化真的有效： 固定模型权重、精度、batch 和硬件，按 1K、4K、16K 等长度同时记录任务正确率、峰值显存、吞吐与 p95 延迟；再做证据位置置换，确认加速没有通过截断或局部窗口悄悄损伤远距信息。若速度提高但长距离题准确率下降，先诊断可见范围与 mask，再比较内核实现，而不是只看注意力热图。

### 2.11.8 把整条因果链连起来

从匹配分数到可扩展序列建模，关键因果环节怎样闭合？。 理解一个词要看句中相关的词，而相关的词可能很远、且随内容变——旧的 RNN 应付不了。 （§1） 。 注意力用 Q/K/V 三步：Query·Key 算匹配、softmax 成权重、按权重加权求和 Value。 （§2） 。 softmax 把缩放分数变成权重，Value 加权和产生新的表示；权重不是因果解释。 （§3） 。 Q/K/V 都来自同一句话时，就是自注意力：句子内部互相看。 （§4） 。 它让任意两位置在一层内直接交互、又能并行训练，改善经典 RNN 的长路径与串行瓶颈。 （§5） 。 多头提供多个投影子空间；专门化可能出现，也可能冗余。 （§6） 。 标准全局注意力的分数矩阵有平方级开销；长上下文还会出现位置偏差，但“中间迷失”不能只归因于平方复杂度。 （§7） 。 过关标准 如果你能讲清「注意力的权重为什么由内容而非位置决定」，并说出「它凭哪两点取代了 RNN、又为什么这对大模型规模至关重要」，你就抓住了它的内核。下一步：看这块机制怎样被包装成可堆叠的标准层——「Transformer」深读页。

### 2.11.9 常见误解

哪些直觉把信息混合、解释性与位置关系混成了一件事？。 误解； 更准确的理解。 注意力只靠「位置远近」决定看谁； 基础项来自 Query·Key 内容匹配；位置编码、相对偏置与掩码也可共同改变分数，并非固定按距离分配。 注意力就是 Transformer； 注意力是一种机制；Transformer 是用它搭起的可堆叠架构（见其深读页）。 多头是为了算得更快； 是为了从 多个不同视角 看相关，分工是学出来的。 上下文窗口不够是厂商小气； 是注意力平方级开销的硬约束，每加长一档都超线性变贵。 注意力自己知道词序； 不带位置表示的自注意力对排列等变；词序要另外注入（见 Transformer 的位置编码）。 最高注意力权重就是模型答案的原因； 它只是某层某头的混合系数；残差、其他头和后续层共同决定输出。 。

### 2.11.10 检查你是否真的理解

## 2.12 归一化：控制表示尺度，稳定深层优化（normalization）

### 2.12.1 归一化在解决哪类条件问题

为什么深层网络里“数值大小”会影响优化，即使函数表达能力没变？。 某层激活若整体过大，后续线性层、注意力 logits 或非线性可能进入饱和和溢出区；过小则信号与梯度可能被舍入或残差淹没。不同样本、token 和层的尺度持续漂移，会使固定学习率面对不断变化的“局部曲率”——也就是损失曲面在当前位置有的方向很陡、有的方向很平，导致同一步长在不同方向效果悬殊。 归一化把输入映射到更受控的尺度，再用可学习 γ （以及某些形式的 β ）恢复任务需要的幅度和偏移。这是重参数化和条件改善，不是保证每层输出永远服从标准正态分布。

### 2.12.2 LayerNorm：先中心化，再按标准差缩放

一个 token 的 d 维向量怎样得到自己的均值和方差？。 μ=(1/d)Σxᵢ σ²=(1/d)Σ(xᵢ−μ)² LN(x)ᵢ=γᵢ(xᵢ−μ)/ σ²+ε +βᵢ。 符号逐个解释： x 是当前 token 的隐藏向量， xᵢ 是它第 i 个坐标， d 是坐标总数， Σ 表示把全部坐标相加； μ 是均值， σ² 是方差， ε 是防止方差过小时除法失控的小正数； γᵢ 与 βᵢ 是第 i 维可学习的缩放与偏移， LN(x)ᵢ 是该维最终输出。 均值和方差由当前 token 的全部隐藏维计算； γᵢ,βᵢ 是跨样本共享、逐隐藏维学习的参数。使用总体方差分母 d ，不是统计课中无偏估计的 d−1 ，因为这里不是从样本估总体方差，而是在定义一个确定性变换。 图示：LayerNorm 沿每个 token 的隐藏维独立统计。 每一行独立统计。若实现误沿 sequence 维统计，张量形状可能仍合法，但语义已经完全不同。

### 2.12.3 手算 LayerNorm：向量 [1,2,3] 变成什么

先忽略 ε，并令 γ=1、β=0。 步骤； 计算； 结果。 均值； (1+2+3)/3 ； 2。 离均差； [1−2,2−2,3−2] ； [−1,0,1] 。 方差； (1²+0²+1²)/3 ； 2/3≈0.667 。 标准差； 2/3 ； ≈0.816 。 归一化； [−1,0,1]/0.816 ； [−1.225,0,1.225] 。 。 结果均值为 0、均方约为 1。若所有输入都加 10，中心化后结果不变；若输入乘正数 5，标准化结果也近似不变。仿射参数随后可以为不同维度重新学习尺度与偏移。

### 2.12.4 RMSNorm：保留均值，只控制均方根

不减均值，能省掉什么，又保留什么？。 RMS(x)= (1/d)Σxᵢ²+ε RMSNorm(x)ᵢ=γᵢxᵢ/RMS(x)。 如何读式子： RMS(x) 是向量 x 的均方根尺度； xᵢ 是第 i 个坐标， d 是坐标数， Σ 把各坐标平方相加， ε 负责数值稳定； γᵢ 是第 i 维可学习缩放， RMSNorm(x)ᵢ 是该维输出。它直接用 xᵢ 除以整体均方根，公式中没有减均值这一步。 仍用 x=[1,2,3] 、 γ=1 、忽略 ε： RMS= 14/3 ≈2.160 ，输出约为 [0.463,0.926,1.389] 。它的均方为 1，但均值不为 0；这正是与 LayerNorm 的核心区别。 性质； LayerNorm； RMSNorm。 减均值； 是； 否。 控制量； 中心化后的方差； 原向量均方根。 对整体正比例缩放； 近似不敏感； 近似不敏感。 对整体平移； 中心化会消除； 会改变方向和输出。 常见参数； γ、β； 通常 γ，无 β。 。

### 2.12.5 统计轴决定它是 LayerNorm 还是另一种算法

名字都叫 Norm，依赖关系却完全不同。 方法； 典型统计轴； 依赖其他样本； 训练/推理规则。 BatchNorm（卷积）； batch 与空间，对每通道统计； 是； 训练批统计；推理常用移动统计。 LayerNorm； 单样本/单 token 的隐藏维； 否； 两阶段规则相同。 RMSNorm； 单 token 的隐藏维均方根； 否； 两阶段规则相同。 GroupNorm； 单样本内的通道分组与空间； 否； 两阶段规则相同。 。 LayerNorm 适合变长序列和小 batch，不是因为它“效果一定更好”，而是单 token 统计不随同批其他样本改变。若模型定义要求在多个维度共同归一化， normalized_shape 必须精确匹配，不能凭最后一维习惯猜测。

### 2.12.6 归一化保留什么，又抹掉什么

尺度不敏感是优点，也可能删除任务需要的信号。 忽略 ε 和仿射参数时，对正数 a ，LayerNorm 满足 LN(ax+b·1)=LN(x) ：整体缩放与各维共同平移被消除。RMSNorm 满足 RMSNorm(ax)=RMSNorm(x) ，但不对共同平移不变。它们保留维度之间的相对模式，却弱化绝对幅度。 可学习 γ/β 能恢复每个通道的固定尺度与偏移，但不能恢复被当前样本统计完全消去的整体均值或尺度。若幅度本身携带置信度、能量或计数信息，必须确认架构中还有旁路保留它。

### 2.12.7 Pre-Norm 与 Post-Norm 改变的是残差梯度路径

只移动 Norm 的位置，为什么深层训练难度会明显变化？。 图示：Pre-Norm 和 Post-Norm 残差结构对比。 Pre-Norm 的残差主干有更直接的恒等路径；Post-Norm 每层相加后都经过 Norm，深层梯度更依赖其雅可比。 图注中的“雅可比”是输出对输入各坐标导数组成的矩阵，它描述梯度穿过该变换时会被怎样缩放和旋转。Pre-Norm 通常让深层 Transformer 更容易优化，减少对学习率预热和初始化的敏感；但架构选择还影响最终表示尺度和深度利用，不能把一个已训练 Post-Norm 模型无损改成 Pre-Norm。

### 2.12.8 ε 不是装饰：它决定小方差区的增益上限

当向量几乎所有维度相同时，除法会发生什么？。 若方差为 10⁻¹² ，标准差仅 10⁻⁶ ，微小舍入噪声会被放大约一百万倍。加入 ε=10⁻⁵ 后，分母约 0.00316 ，增益受控。ε 越大越稳，但也更明显地偏离单位方差目标。 实现还可能采用 variance+ε 或 variance +ε ，二者在小方差区不同。迁移权重、量化或替换算子时，应匹配原公式、ε 数值和累加精度，而不是只匹配层名。

### 2.12.9 混合精度下为什么统计量常要升到 FP32

输入是 FP16/BF16，直接平方和求和有什么风险？。 平方会扩大动态范围，求均值又会累积舍入误差。FP16 的指数范围较窄，较大激活平方可能溢出；BF16 范围大但有效尾数短，小差异可能丢失。常见稳健实现以更高精度计算均值、方差/RMS 和倒数平方根，再转换回模型精度。 “没有 NaN”不代表实现正确。 错误的归一化轴、低精度统计或广播 γ 的维度都可能产生有限数值，却系统性改变模型。应以参考实现逐层比较输出与梯度，而不只跑通生成。

### 2.12.10 归一化之后仍会爆炸：故障可能在别处

有 Norm 的 Transformer 为何仍可能出现 loss spike？。 现象； 可能链路； 应观察。 Norm 输入 RMS 逐层增大； 残差分支长期同向累积； 残差主干与分支更新的 RMS 比。 Norm 输出正常但注意力 NaN； QK logits、掩码或 softmax 溢出； 每头 logits 最大值与全遮罩行。 特定 batch 突然尖峰； 异常长度、数据或损失缩放； 样本 ID、token 数、梯度范数。 换推理后端质量下降； ε、精度、轴或融合算子不一致； 逐层输出最大误差。 。 Norm 只约束它所在位置的表示；学习率、初始化、损失尺度、残差累积和注意力 softmax 仍可能失控。诊断时沿数据→层输入→Norm 输出→子层输出→残差和→损失逐段测量。

### 2.12.11 怎样验收一个归一化实现

手算小向量： 用本页 [1,2,3] 分别核对 LN 与 RMSNorm。 测不变性： 缩放、共同平移输入，验证输出变化符合各自定义。 测退化输入： 全相同、极小方差、极大值和零向量。 检查轴： 改变同 batch 其他样本或相邻 token，LayerNorm 输出不应变化。 比参考前后向： FP32、FP16/BF16、多种长度下比较输出和梯度。 检查仿射广播： γ/β 应沿预期隐藏维逐元素作用。 做端到端等价： 融合算子、量化后端与原实现比较逐层误差及最终指标。

### 2.12.12 把整条因果链连起来

深层残差和子层变换使表示尺度随层与样本变化。 LayerNorm 或 RMSNorm 沿指定隐藏维计算当前 token 的统计量。 中心化/均方根缩放降低对整体偏移或尺度的敏感性。 γ/β 为每个特征恢复可学习的尺度与偏移。 Norm 在残差分支前后的位置改变恒等梯度路径。 ε 与累加精度控制小方差和大数平方的数值风险。 注意力 logits、残差累积和损失仍需独立稳定措施。 轴、公式和精度作为权重契约，通过逐层等价测试守住。

### 2.12.13 常见误解与自测

误解； 更准确的说法。 归一化让输出服从标准正态； 它控制指定统计量，不规定完整分布形状。 LayerNorm 与 BatchNorm 只差名字； 统计轴、样本依赖和训练/推理规则都不同。 RMSNorm 是便宜但完全等价的 LayerNorm； 它不中心化，保留并响应共同平移。 有 Norm 就不会梯度爆炸； 残差、logits、学习率和损失仍可失控。 ε 越小越精确； 过小会放大小方差噪声，精度与稳定要共同选择。 。 手算 [1,2,3] 的 LayerNorm 时，为何方差分母是 3？。 给向量所有维度加 10，LN 与 RMSNorm 分别怎样变化？。 为什么改变同 batch 另一条样本不应改变 LayerNorm 输出？。 Pre-Norm 更直接的梯度路径在哪里？。 融合 Norm 算子能生成正常文本，但质量略降，应怎样定位？。 参考答案 这里是在定义当前向量的统计变换，不是在用样本估计未知总体，使用均方分母 d。 忽略 ε 时 LN 不变；RMSNorm 因不减均值而改变。 它只沿当前 token 的隐藏维统计，不使用 batch 维。 残差主干 x→x+F(Norm(x)) 保留未经过 Norm 子层的恒等路径。 逐层比较参考/融合算子的 FP32 与模型精度输出、梯度，核对轴、ε、仿射广播和累加精度。

## 2.13 Transformer（transformer）

### 2.13.1 Transformer 是什么

本节回答：注意力这么强了，为什么还需要「Transformer」？它多做了什么？。 注意力只解决了一件事： 怎么在位置之间传信息 。但要把它变成一个能学会语言的 大模型 ，还差一步——需要一块能 重复堆叠 的标准积木，让信息一层层被加工。Transformer 就是这块积木：它把注意力连同前馈、残差和归一化等配件封装成标准层，然后反复堆几十到上百层。层数仍受优化、显存、通信和推理延迟约束，并不是字面上的无限。 一句话 注意力是「引擎」，Transformer 是「把引擎装进一个可批量拼装的标准模块」。今天的大模型，就是这种模块摞起来的高塔。

### 2.13.2 一层里的四件套

这块「标准积木」通常由什么组成？先看最常见的四类功能。 图示：一个 Transformer 层的结构：多头注意力、前馈、各配残差与层归一化。 图 1 一个 Transformer 层：先多头注意力、后前馈网络，两处各配一组残差连接与层归一化。这样的层原样堆叠 N 次，就是一个 Transformer。 。 零件； 做什么。 多头注意力 ； 在位置之间传信息、汇总上下文（见「注意力机制」）。 前馈网络 ； 对每个位置独立做非线性特征变换；部分事实关联可在其中被定位，但知识并不只存在这里。 残差连接 ； 让输入直接绕过本层相加，是能堆到上百层的前提。 层归一化 ； 稳定每层的数值分布，防止训练发散。 。 两个主角、两个配件 多头注意力和前馈网络是「干活」的主角（一个负责跨位置传信息，一个负责逐位置加工）；残差和归一化像是「脚手架」，为深层优化提供更直接的梯度路径与受控尺度。现代模型可能把 LayerNorm 换成 RMSNorm、调整 Norm 位置或增加门控，所以“四件套”是功能地图，不是所有实现逐字相同的配方。

### 2.13.3 手算一次 Pre-Norm Transformer 块

注意力、前馈和两条残差路径怎样先后改变同一个 token 的表示？。 用二维玩具向量演示结构，不代表真实权重。输入 x=[1,2] ；忽略 ε、令归一化仿射参数 γ=1、β=0，则 Norm(x)=[−1,1] 。假设注意力汇总结果为 A=[0.4,−0.2] ：。 阶段； 计算； 结果。 注意力残差； r=x+A ； [1.4,1.8] 。 再次归一化； Norm(r) ； [−1,1] 。 前馈变换； 假设 F(Norm(r))=[0.3,0.5] ； [0.3,0.5] 。 前馈残差； y=r+F(Norm(r)) ； [1.7,2.3] 。 。 注意力先把其他位置的信息写入当前 token，前馈网络再对当前位置独立加工；两次相加都保留了进入子层前的主干。真实网络对所有 token 并行执行，并由多头注意力产生 A。 结构图必须标明 Pre-Norm 还是 Post-Norm。 本例是 x+Sublayer(Norm(x)) ；原始论文常写成 Norm(x+Sublayer(x)) 。两者张量形状相同，却有不同梯度路径，不能在已训练权重上随意互换。

### 2.13.4 残差和归一化为什么是深层训练的关键配件

注意力和前馈是主角，残差与 Norm 分别改善哪条训练链路？。 把很多非线性层直接串起来时，梯度要连续乘过每层的导数，可能快速变小或变大；同时激活尺度也会随深度漂移。残差和归一化分别改善这两类条件：。 残差连接 给梯度开了条「直通车」——让输入原样绕过本层相加，梯度可以沿这条路直接传回浅层，绕开连乘衰减。 层归一化 把每层的数值分布拉回可控范围，防止越传越大或越传越小、导致训练发散。 关键的是功能与整套配方，不是某个名称永远不可替换。 移除残差或改变 Norm 位置，会显著改变深层优化条件，常需重新设计初始化、学习率和残差缩放；但一些架构会用 RMSNorm、门控残差或专门缩放实现相近功能。不能把已验证的深层配方改一处后仍视为等价。（残差为什么关键，见“残差连接”“梯度消失”节点。）。

### 2.13.5 一个容易忽略的点：位置编码

如果注意力没有任何位置机制，模型到底怎么知道词的先后顺序？。 先意识到一件反直觉的事 不带任何位置表示的自注意力对输入排列是 等变的 ：把 token 顺序打乱，输出也只会按同样顺序重排，机制本身无法区分先后。可「小明打小红」和「小红打小明」意思天差地别，所以词序信息必须 额外注入 。 位置机制接收每个 token 的位置索引或相对距离，并输出可加入表示或注意力分数的顺序信号。加入后，相同词集合的不同排列可以产生不同关系表示；它告诉模型“谁在谁前面”，但模型是否学会正确使用长距离顺序仍要靠训练和评测。 图示：打乱词序注意力结果相同，所以要位置编码。 图 2 注意力对词序「无感」。所以 Transformer 在输入嵌入上额外叠加一层 位置编码 ，把「你排第几」告诉每个词。位置编码怎么设计，还直接影响模型能否外推到训练时没见过的更长序列——这是长上下文模型的技术难点之一。 。

### 2.13.6 三种搭法：编码器与解码器

同样一块标准积木，怎么搭出不同用途的模型？。 搭法； 代表； 擅长。 只用编码器； BERT 类； 理解 ：分类、抽取、判断（能同时看左右全文）。 只用解码器； GPT 类； 生成 ：逐词往下写，是当今大模型的主流。 编码器 + 解码器； T5 类； 转换 ：翻译、摘要等明确的「输入→输出」任务。 。 从输入输出看，编码器接收完整序列并输出每个位置的双向上下文表示；解码器接收已生成前缀并输出下一个 token 的概率分布；编码器—解码器结构还让解码器读取编码后的输入序列。表中的“擅长”是常见工程选择，不是能力的绝对边界，具体还取决于训练目标、掩码和数据。 差别主要在「能看到哪些词」 编码器让每个位置能看到 左右全部 上下文，适合理解；解码器只让每个位置看 左边 （靠因果掩码），适合一个词一个词地生成——这正是大语言模型的做法（见其深读页）。同一套积木，靠「看的范围」不同，长出了不同的物种。

### 2.13.7 模态无关：为什么它不止用于文本

Transformer 是为语言设计的，可为什么图像、音频、甚至蛋白质也都在用它？。 关键在于：Transformer 不关心输入是什么，只关心「能不能变成一串向量（token）」 。把一张图切成一个个小方块、每块当作一个「词」，同一套 Transformer 就能处理视觉（这就是 ViT）；音频、视频、蛋白质序列同理。 这正是多模态的重要技术前提 文本、图像、音频都能表示成向量序列，因此可复用 Transformer 模块并建立跨模态注意力。实际系统既可能端到端统一，也可能组合专用编码器、投影器与语言模型；“同一架构可处理”不等于所有模态必须由同一组参数完成。

### 2.13.8 为什么它改变了一切

一句话，Transformer 的历史意义到底是什么？。 它把训练时的序列位置计算变成大规模矩阵运算，显著提高 GPU/TPU 利用率；相较经典 RNN 的时间步依赖，更容易做数据、张量和流水线并行。代价是注意力的长度开销、通信、显存和推理自回归仍构成硬约束。 它打通了通往规模的重要道路 可并行训练、稳定深层堆叠和统一序列接口，使扩大参数、数据和算力更可行；缩放定律还依赖训练目标、数据质量、优化和硬件系统，不能归功于单一模块。

### 2.13.9 把整条因果链连起来

从 token 向量到深层可训练模型，四类零件怎样分工并闭环？。 注意力只管「位置间传信息」，要搭成大模型，需要一块可无限堆叠的标准积木——Transformer。 （§1） 。 每层四件套：多头注意力 + 前馈网络（两主角）+ 残差 + 层归一化（两配件）。 （§2） 。 一次数值前向显示：注意力写入跨位置内容，前馈逐位置变换，残差保留主干。 （§3） 。 残差提供短梯度路径，层归一化控制子层输入尺度，使深层堆叠更可优化。 （§4） 。 注意力本身不含完整词序，所以要额外注入位置表示。 （§5） 。 编码器/解码器/二者组合，通过可见范围与交叉注意力形成不同任务骨架。 （§6） 。 只要对象能表示为 token 序列，架构可扩展到图像、音频等模态。 （§7） 。 矩阵化并行与稳定堆叠共同提高可扩展性，但算力、数据和系统仍是约束。 （§8） 。 过关标准 如果你能说清「一层里四件套各自为什么必需」，并讲明「Transformer 相对注意力多做了什么、为什么这对大模型规模是决定性的」，你就抓住了它的内核。

### 2.13.10 常见误解

哪些说法把一个架构骨架夸成了自动获得能力的充分条件？。 误解； 更准确的理解。 Transformer 就是注意力； 注意力是核心机制；Transformer 是把它 + 前馈 + 残差 + 层归一化封装成的可堆叠层。 残差和归一化只是无关紧要的装饰； 它们承担梯度路径与尺度控制功能；具体可用 RMSNorm、门控或缩放等变体，但改动必须重新验证整套训练配方。 Transformer 自带词序感知； 注意力对词序无感，词序靠额外的 位置编码 注入。 它只能处理文本； 对模态无感，图像/音频切成 token 就能用同一套（多模态的前提）。 层数越多一定越好； 更深提高潜力也提高优化难度与推理延迟，需要平衡。 。

### 2.13.11 检查你是否真的理解

注意力已经能在位置间传信息，Transformer 在它之上多做了什么？。 一层里的四件套分别是什么？两个「主角」和两个「配件」各负责什么？。 残差连接和归一化分别改善哪类训练问题？为什么改动它们要重新验证配方？。 为什么说注意力「不知道词序」？Transformer 怎么解决？。 只用编码器、只用解码器、两者都用，分别擅长什么？根本差别在哪？。 为什么图像、音频也能用 Transformer？这和多模态有什么关系？。 用一句话说明：Transformer 为什么是「打通通往大模型规模之路」的关键？。 参考答案 把注意力连同必要配件封装成一个可反复堆叠的标准层，让信息逐层被加工得更抽象，从而能搭成深层大模型。 多头注意力负责跨位置传信息，前馈网络负责逐位置非线性变换；残差连接提供稳定的信息与梯度路径，层归一化控制激活尺度。知识由整个网络的分布式参数共同承载。 残差提供较直接的信息与梯度路径，归一化控制激活尺度；移除或换位置会改变深层优化条件。它们可有 RMSNorm、门控残差等变体，但初始化、学习率和缩放也要配套重新验证。 因为不带位置表示的注意力对排列等变，无法区分先后；Transformer 通过绝对、相对或旋转等位置表示注入顺序。 编码器擅长理解、解码器擅长生成、两者都用擅长转换；根本差别是每个位置「能看到哪些词」（左右全文 vs 只看左边）。 因为它只要求输入能切成 token 序列、对模态无感；图像切块当词就能处理，于是能用同一套架构统一处理多种模态，这是多模态的前提。 它把序列建模变成能吃满 GPU 并行的任务，使模型和数据可一起放大，缩放定律那条路才走得通。

## 2.14 状态空间模型 SSM：用可控动态系统压缩长序列（state-space-models）

### 2.14.1 状态空间来自“输入驱动的动态系统”

一段历史怎样被压成有限维状态？。 ḣ(t)=Ah(t)+Bx(t)， y(t)=Ch(t)+Dx(t)。 先读符号： t 是连续时间； x(t) 是当前输入， h(t) 是概括此前历史的有限维状态， ḣ(t) 是状态随时间的变化率， y(t) 是当前输出。矩阵 A 决定状态自身怎样演化， B 把输入写入状态， C 从状态读出输出， D 提供输入到输出的直通路径。经典控制系统里这些矩阵描述物理动态；序列模型中它们被学习，用于保存对任务有用的历史。 贯穿例子： 监测机器温度，状态每天保留 80% 旧影响并吸收当天异常：hₜ=0.8hₜ₋₁+xₜ，输入 x=[1,0,2]，h₀=0。

### 2.14.2 手算离散化后的序列递推

采样间隔改变时，为什么不能总沿用同一个 A？。 hₖ=Āhₖ₋₁+B̄xₖ， Ā=e ΔA 。 式子含义： k 是离散时间步， xₖ 是第 k 步输入， hₖ₋₁ 与 hₖ 是更新前后的状态；横线表示连续矩阵离散化后的 Ā 与 B̄ ， Δ 是采样步长。符号 e 表示自然指数函数，e 的 ΔA 次矩阵幂称为矩阵指数，它把连续演化 A 换算为一步状态转移。零阶保持等离散化方法会同时计算 Ā、B̄。若采样频率改变而不重算，模型代表的时间尺度就变了。学习时还要约束状态动力学，避免反复递推导致爆炸。 本节沿用输入 x=[1,0,2] 和初始状态 h₀=0，并把连续系统离散化成下面的标量递推。 t； xₜ； 递推； hₜ。 1； 1； 0.8×0+1； 1。 2； 0； 0.8×1； 0.8。 3； 2； 0.8×0.8+2； 2.64。 。 表中采用贯穿例子的标量参数 Ā=0.8、B̄=1：第三步把上一步状态 0.8 衰减为 0.64，再加当前输入 2，得到 2.64。这个数同时含有过去的衰减记忆和当前输入。

### 2.14.3 同一线性 SSM 也可以看成一维卷积

递归难并行，训练时如何一次处理整段？。 反复代入可得：。 yₖ=Σ i=0…k CĀ i B̄ · xₖ₋ᵢ， Kᵢ=CĀ i B̄。 符号说明： yₖ 是第 k 步输出， i 是回看距离， Σ 把从当前到最早位置的贡献相加； xₖ₋ᵢ 是 i 步前的输入， Āⁱ 表示状态转移重复 i 次。矩阵 B̄ 负责把历史输入写入状态，矩阵 C 负责从状态读出输出。于是 Kᵢ=CĀⁱB̄ 就是距离 i 对应的卷积核系数，整组 K 是由状态动力学生成的长卷积核。推理时保留 h 做 O(1) 增量更新；训练时可构造卷积核并用并行卷积/扫描处理整段。结构化参数化让长核计算可行。 二重性： 递推和卷积不是两个模型，而是同一线性系统的两种计算顺序；选择哪种取决于训练吞吐还是流式延迟。

### 2.14.4 选择性让模型按内容决定写入与遗忘

固定卷积核为何难处理“只记住红色 token”这类内容依赖任务？。 “线性时不变”是指每个位置都复用同一组 A、B、C，所以无论当前 token 是红色标记还是普通词，记忆规则都不变。选择性 SSM 让 Δ、B 或 C 由 xₜ 产生，使相同距离的输入能被不同程度保留：。 Δₜ,Bₜ,Cₜ=fθ(xₜ)， hₜ=Ā(Δₜ)hₜ₋₁+B̄ₜxₜ。 式中： xₜ 是当前输入， fθ 是参数为 θ 的小型可学习函数，它输出当前位置的步长 Δₜ 、写入参数 Bₜ 和读出参数 Cₜ ； Ā(Δₜ) 是由当前步长得到的离散状态转移， B̄ₜ 是对应离散写入参数， hₜ₋₁ 与 hₜ 是更新前后状态。这破坏了固定卷积核的简单形式，需要硬件友好的并行 scan（按递推依赖批量合并各步的扫描算法）内核。内容选择力增强，但模型仍把历史压进有限状态。

### 2.14.5 原创演示：遗忘门改变脉冲的有效记忆长度

0.5 与 0.9 的状态保留率，会让早期事件留下多久？。 图示：状态空间模型对单次脉冲的两种衰减曲线。 图 1 固定保留率下，早期输入贡献按 Āᵈ 衰减；选择性机制相当于让不同输入拥有不同时间尺度。 距离 d； 0.5ᵈ； 0.9ᵈ。 1； 0.500； 0.900。 5； 0.031； 0.590。 10； 0.001； 0.349。 50； ≈0； 0.005。 。 距离为 10 步时，保留率 0.5 的贡献只剩 0.001，而保留率 0.9 仍保留 0.349；曲线越缓，单次事件的有效记忆长度越长。

### 2.14.6 线性复杂度不等于实际必然更快

O(n) 赢了 O(n²)，为什么短序列上仍可能输？。 因素； SSM； 注意力。 渐近序列计算； O(n)； O(n²)。 推理状态； 固定维度； KV 随 n 增长。 训练内核； 依赖高效 scan/融合； 成熟矩阵与 FlashAttention。 随机访问旧位置； 经压缩状态间接访问； 可直接注意旧 KV。 。 短序列、较小批量或缺少优化内核时，常数项和硬件利用率可压过复杂度优势。必须在目标硬件、长度和 batch 上测 tokens/s、延迟与显存。

### 2.14.7 状态稳定性决定长外推是否可信

训练长度 4k 正常，推到 100k 为什么可能漂移或爆炸？。 矩阵的“谱半径”是其特征值绝对值的最大值，可粗略理解为状态反复乘这个转移矩阵时最容易放大还是衰减。若离散 Ā 的谱半径大于 1，微小状态会随步数放大；远小于 1 又会迅速遗忘。有限精度、归一化和输入依赖步长会使长程误差累积。训练区间内稳定不等于任意长度稳定。 测试； 观察。 长度外推； loss/准确率随长度曲线。 零输入滚动； 状态是否衰减、漂移或爆炸。 脉冲响应； 不同时间尺度是否可解释。 精度切换； FP32/BF16/FP16 的状态差异。 。

### 2.14.8 压缩历史会伤害精确复制与任意检索

能处理百万长度，是否等于能找回任意一个旧 token？。 固定状态可概括趋势，却可能无法同时保存大量互不相关细节。密码复制、键值关联、“needle-in-a-haystack”（把一个目标片段藏在大量干扰文本中再要求找回）和需要引用原文位置的任务，是检验随机访问的压力测试。选择性可改善写入策略，但没有让有限状态变成无限数据库。 混合架构可用 SSM 负责局部/流式压缩，稀疏注意力或外部检索负责精确回看。评测应区分“输入放得下”“吞吐可扩展”和“信息仍可取回”。 长上下文长度不是记忆证明。 必须按距离、干扰数量和检索精度报告能力。

### 2.14.9 与 RNN、卷积和注意力的关系

SSM 是旧 RNN 换名字，还是长卷积的一种？。 它们共享递归状态思想，但现代 SSM 用连续系统离散化、结构化矩阵和并行扫描解决训练效率；线性时不变 SSM 又等价于特定长卷积。选择性 SSM 引入内容依赖，跨越固定卷积核。注意力则显式保留位置表示并做内容寻址。 需求； 更匹配的机制。 固定小状态、流式； RNN/SSM。 超长平滑动力学； 结构化 SSM。 任意位置精确回看； 注意力/检索。 局部平移模式； 卷积。 。

从动态系统和计算实现两侧同时理解。 误区； 更准确的理解。 线性时间就必然更快； 内核、长度、批量和硬件决定墙钟性能。 状态保留完整历史； 它是有限维有损压缩。 递推与卷积是两种模型； 线性时不变 SSM 中是等价计算视角。 选择性解决所有检索； 它改善内容写入，未消除容量边界。 训练稳定即可无限外推； 需做长度与数值稳定压力测试。 。 层级； 依赖与延伸。 先修； RNN、线性代数、卷积、离散系统。 本页核心 ； 离散化、卷积等价、选择性扫描、稳定性。 对比； 注意力、Transformer、长上下文。 工程； 并行 scan、融合内核、流式推理。 。

## 2.15 自监督学习：让数据自己产生训练目标（self-supervised-learning）

### 2.15.1 标签不是人工写的，但目标仍然明确

把一句话右移一位，为什么就产生了监督信号？。 给定原始样本 z ，变换规则 q 从中构造模型输入 x 和自动目标 y ；参数为 θ 的模型 fθ 根据 x 预测，再由损失函数 ℓ 比较预测与 y。文本下一个 token、被遮住片段、同一图片两种增强都可自动获得 y。监督学习描述“有目标损失”，自监督描述“目标从数据自身产生”；无监督则是更宽的总称。 贯穿例子： 三张商品图 A、B、C；A 的裁剪图 A⁺ 是正样本，B、C 是候选负样本。比较模型是否把同一商品的两种视图拉近。

### 2.15.2 自回归目标把每个位置都变成训练样本

一段长度 T 的文本为何能提供 T−1 个目标？。 L AR =−Σ t=1…T log pθ(xₜ|x<ₜ)。 符号说明： L_AR 是整段文本的自回归损失； T 是序列 token 数， t 是当前预测位置， Σ 把各位置损失相加； xₜ 是第 t 个真实 token， x<ₜ 是它之前的全部 token； pθ(xₜ|x<ₜ) 是参数 θ 的模型根据前缀赋给真实下一个 token 的条件概率， log 是自然对数，前面的负号让真实 token 概率越小损失越大。 因果遮罩只允许读取此前 token。降低损失要求模型捕捉语法、主题、共现事实和代码结构，也训练出生成接口；但目标奖励“像数据分布”，不直接奖励真实、无害或服从当前用户。 输入前缀； 自动目标。 退款； 已。 退款 已； 批准。 退款 已 批准。 。

### 2.15.3 遮盖重建用双向证据恢复缺失部分

遮得太少或太多分别会发生什么？。 L mask =−Σ i∈M log pθ(xᵢ|x M )。 式中： L_mask 是所有被遮位置的总损失， M 是被遮位置集合， i∈M 表示只对其中的位置求和； xᵢ 是位置 i 原本的真实内容， x\M 是拿掉 M 中内容后仍可见的上下文； pθ 是模型据此恢复 xᵢ 的概率，负对数同样惩罚给真实内容的低概率。 BERT 根据左右文恢复被遮 token；MAE 遮住图像块后重建。遮盖少时模型可靠局部复制，任务太容易；遮盖多时证据不足，损失被不可预测细节主导。中等遮盖率往往在可预测证据与任务难度之间较平衡，但最佳比例仍取决于模态和模型。重建像素还可能把容量花在颜色纹理，而非下游语义。 遮盖率； 主要风险； 诊断。 低； 局部捷径； 扩大遮盖块/距离。 中； 通常平衡； 迁移曲线。 高； 目标不确定； 重建质量与语义探测分开看。 。

### 2.15.4 手算对比学习：把正对从负对中识别出来

温度和负样本怎样改变同一商品的匹配压力？。 ℓ=−log exp(sim(a,a⁺)/τ) / Σ j exp(sim(a,j)/τ)。 先读式子： a 是锚点样本 A 的表示， a⁺ 是同一商品增强视图 A⁺ 的表示； j 遍历正样本和候选负样本， sim 计算两表示的相似度； τ 是温度，负责缩放相似度差异； exp 与分母求和把各候选分数转成概率， ℓ 是正样本的负对数概率损失。这里的 logit 是进入指数和归一化之前的缩放相似度。 沿用三张商品图 A、B、C：A⁺ 是 A 的裁剪正样本，B、C 是候选负样本。设相似度 s(A,A⁺)=0.8、s(A,B)=0.3、s(A,C)=0.1，τ=0.2。logit 为 [4,1.5,0.5]，指数约 [54.60,4.48,1.65]，正样本概率 54.60/60.73≈ 0.899 ，损失 −log0.899≈ 0.106 。这说明在当前三个候选中，模型已经把正视图排在明显更高的位置。 较低温度放大排序差异，也放大错标正负对。批量和负样本来源改变任务难度；把同类别实例当负样本会产生 false negatives，也就是“实际上语义相近却被训练规则当成负例”。

### 2.15.5 原创图：预文本目标决定模型被迫保留什么

相同原始数据经过不同构造，为何学到不同表示？。 图示：原始数据经过自回归遮盖和对比三种自监督任务形成表示。 图 1 “自动标签”并不中立：构造规则定义模型应预测、恢复或忽略的信息。

### 2.15.6 增强策略实际定义了语义不变性

为什么商品图随机裁剪可能把正样本变成错误正对？。 若裁剪只剩品牌背景而丢掉商品，模型会被迫认为背景与商品身份等价；医学图旋转、数字翻转或音频变速也可能改变标签。反之，增强过弱时模型可利用颜色直方图、文件压缩或边框等捷径。 增强； 声明的不变性； 破坏风险。 随机裁剪； 局部视图同对象； 裁掉语义主体。 颜色抖动； 颜色不决定身份； 颜色是任务标签。 文本回译； 改写保持语义； 否定、实体或语气变化。 。

### 2.15.7 无负样本方法用不对称结构防止坍缩

若只让两种视图靠近，所有表示变成同一常数不是最优吗？。 是的，朴素一致性损失允许“表示坍缩”——所有输入都输出近乎相同向量，虽然两视图一致却不再含可区分信息。BYOL、DINO 等用停止梯度、教师动量更新、中心化/锐化或预测头制造不对称；VICReg 等显式约束方差与协方差。 L=L invariance +λL variance +μL covariance 。 式中： L 是总损失， L_invariance 拉近同一样本的两种视图， L_variance 防止每个表示维度失去变化， L_covariance 减少不同维度携带重复信息； λ 与 μ 分别控制后两项强度。“没有显式负样本”不等于没有防坍缩机制。可监控表示方差、奇异值谱（各主要表示方向还剩多少变化强度）和最近邻多样性，而非只看训练损失。

### 2.15.8 迁移评测要区分冻结表示与端到端适配

线性探测差，是否说明预训练完全失败？。 协议； 主要测什么； 局限。 线性探测； 表示是否线性可分； 低估可微调信息。 全量微调； 初始化可适配性； 混入下游容量与预算。 少样本/提示； 数据效率与接口能力； 方差大、提示敏感。 冻结检索； 距离空间质量； 依赖索引与度量。 。 所有协议必须固定数据划分和调参预算，并按来源、群体、难度与分布外样本切片。预训练 loss 只能用于过程监控，不能替代迁移证据。

### 2.15.9 规模优势把瓶颈转移到数据治理

不需要人工逐条标注，是否意味着数据免费且无风险？。 原始数据仍涉及许可、隐私、同意、去重、污染、恶意内容和群体覆盖。自动目标会把数据中的偏见与泄漏一起放大；评测集出现在预训练语料中会伪造迁移能力。需要记录来源、时间、处理链和删除能力。 自监督只省标签，不免除治理。 训练目标来自数据，不代表数据拥有合法授权，也不代表目标与产品价值一致。

### 2.15.10 常见误区与学习路线

真正的问题不是“有没有标签”，而是标签如何被构造。 误区； 更准确的理解。 自监督没有监督信号； 目标由数据变换自动构造。 预训练损失低就会下游好； 代理目标可能错位或走捷径。 增强越强越好； 增强定义不变性，可能破坏语义。 对比学习负样本越多越好； false negative 与分布同样重要。 无负样本方法无需防坍缩； 通常依靠不对称或显式方差约束。 。 层级； 依赖与延伸。 先修； 监督学习、损失函数、表示学习。 本页核心 ； 自回归、遮盖、InfoNCE、坍缩。 架构； LLM、BERT、CLIP、MAE。 治理； 预训练、训练数据治理、评测污染。 。

### 2.15.11 完整示例：同一商品对比目标的验收闭环

算出0.106的训练损失后，怎样证明表示真的可用于商品匹配？。 这里的“验收闭环”是从训练目标一直追到未见商品上的真实检索结果，解决“损失下降但模型只记住背景”的错判。输入是按商品身份拆分的训练图和测试查询图，输出是 top-k 商品检索结果、表示方差以及背景/角度/品类切片指标。 先固定商品级拆分，避免同一商品的近重复图跨训练与测试；再训练 A—A⁺ 正对，记录相似度和表示方差；随后冻结编码器，在从未见过的商品上做 top-k 检索，并按背景、角度和品类切片。最后用“换背景不换商品”和“换商品不换背景”的反事实对照，确认模型追踪主体而非摄影棚捷径。 结果怎样解释： 若平均 top-k 很高，但换背景后同一商品无法召回，说明模型利用了摄影棚捷径而不是商品身份。这个闭环只验证当前商品匹配任务；换到细粒度颜色、文字或新拍摄域时，必须重新定义增强并复测对应切片。

### 2.15.12 把因果链连起来

这个概念怎样从问题一路连接到可验证的实践？。 选择原始数据与期望不变性。 构造预测/遮盖/视图目标。 优化代理损失并防止坍缩。 冻结或微调迁移到下游。 用真实切片排查捷径。 审计来源、污染与目标错位。

### 2.15.13 误区与自测

你能否不用背术语，解释它的机制、边界与验证方法？。 自监督为什么仍有监督？。 算例中正样本概率约多少？。 遮盖率太低的主要风险？。 增强为什么不是中立预处理？。 无负样本方法如何避免常数表示？。 假设“自监督学习：让数据自己产生训练目标”在离线示例上表现正常、上线后核心结果却下降，你会怎样按输入、内部变换、输出反馈和适用边界定位问题？。 。 参考答案 输入和目标由数据自身及变换自动生成，仍有明确损失。 exp(4)/(exp4+exp1.5+exp0.5)≈0.899。 任务过易，模型利用局部复制等捷径。 它声明哪些变化不应改变语义，错误增强会注入错误不变性。 依靠停止梯度、动量教师、不对称头或方差/协方差约束。 先保存同一失败样本及环境，确认输入、权限和前置条件没有漂移；再记录关键中间状态，检查机制是否按本页描述完成变换；随后把原始输出与独立指标、人工终验对照；最后用边界样例和对照实验复测。只有定位到首次偏离预期的环节，才能判断应修改数据、机制、评测还是使用边界。

## 2.16 对比学习：用正对与负对塑造表示空间（contrastive-learning）

### 2.16.1 训练信号是一张“谁与谁相同”的关系表

没有类别名称，模型凭什么知道两张图要靠近？。 从同一原始样本产生两种视图作为正对；其他样本作为负对。编码器 f 接收一张视图并把它映射为特征向量 z ；投影头 g 再把 z 映射到专门计算对比损失的空间，让下游可使用投影前表示。构造规则事实上给出了隐式关系标签。 贯穿例子： 锚点 A 是一张鞋图，A⁺ 是其裁剪，B 是另一双鞋，C 是汽车。余弦相似度分别为0.8、0.6、0.1，温度 τ=0.2。

### 2.16.2 InfoNCE 让一个正样本与整组候选竞争

为什么它看起来像一个临时分类任务？。 ℓᵢ=−log exp(sim(zᵢ,zᵢ⁺)/τ) / Σ j∈candidates exp(sim(zᵢ,zⱼ)/τ)。 符号逐个解释： i 是当前锚点编号， zᵢ 是它的向量， zᵢ⁺ 是正视图向量； j 遍历候选集合中的正负样本， zⱼ 是候选向量； sim 是相似度函数， τ 是缩放相似度的温度； exp 和 Σ 将全部候选分数归一化成概率， ℓᵢ 是锚点 i 的正样本负对数概率损失。 把锚点当查询，候选中的正对是正确类别。分母包含正对和负对；损失拉高正对 logit，同时按当前 softmax 概率推低负对。通常先归一化向量，避免模型仅靠增大范数降低损失。

### 2.16.3 完整手算：相似鞋比汽车贡献更大梯度

相似度 [0.8,0.6,0.1] 如何变成损失？。 沿用锚点 A、正视图 A⁺、负样本鞋 B 和汽车 C，温度 τ=0.2。第一步除以温度得 logits [4,3,0.5]；第二步取指数约 [54.60,20.09,1.65]；总和76.34；正对概率 p⁺=54.60/76.34≈ 0.715 ；损失 −log0.715≈ 0.335 。 候选； 相似度； softmax概率； 训练作用。 A⁺ 正对； 0.8； 0.715； 继续拉近。 B 鞋； 0.6； 0.263； 强力推远。 C 汽车； 0.1； 0.022； 梯度很小。 。 对负候选而言，交叉熵对其 logit 的导数就是当前 softmax 概率；所以 B 的 0.263 带来比 C 的 0.022 更强推远信号。若目标是实例检索，这种困难负样本合理；若目标是鞋类语义，B 可能是假负样本。

### 2.16.4 温度控制模型关注多难的负样本

τ 变小为何既能强化区分，也会放大噪声？。 τ 缩小会放大相似度差异，使 softmax 集中在最高的几个候选；困难负样本获得更大梯度。τ 太大则概率近均匀、信号弱；τ 太小遇到错配或假负时会猛烈推开本应相近的样本。 τ； 分布； 风险。 较小； 尖锐，聚焦 hard negatives； 噪声敏感、梯度不稳。 较大； 平滑，多候选共同作用； 区分压力不足。 。 温度可固定或学习，但必须与 batch、相似度归一化和数据噪声一起调。

同一个锚点周围，哪些点被拉近、哪些被推远？。 图示：对比学习中锚点正样本困难负样本和简单负样本的移动。 图 1 损失只知道构造出的关系；B 是合理困难负样本还是错误假负样本，取决于下游语义定义。

### 2.16.6 增强定义模型应忽略哪些变化

为什么随机裁剪不是无害的数据处理？。 正对被拉近，所以两视图之间的差异被声明为“不影响语义”。裁剪训练位置与局部缺失不变，颜色抖动训练色彩不变，回译训练措辞不变。若颜色决定熟度、旋转改变医学方位、裁剪删掉主体，目标就会压掉有用信息。 领域； 可能合理； 可能破坏标签。 自然图像； 轻微裁剪/颜色； 小目标被裁掉。 医学影像； 有限噪声； 左右翻转改变侧别。 文本； 保义改写； 否定或实体被替换。 。

### 2.16.7 大 batch、队列和动量编码器解决的是负样本供给

MoCo 为什么不用把超大 batch 一次塞进显存？。 SimCLR 用大 batch 获得更多负样本；MoCo 把历史 key 放入队列，并用缓慢更新的动量编码器保持旧、新向量坐标相对一致。跨设备 all-gather 可共享负样本，但增加通信。 θ key ←mθ key +(1−m)θ query 。 式中： θ_key 是生成队列 key 的编码器参数， θ_query 是当前通过梯度训练的查询编码器参数； m 是接近 1 的动量系数。每一步让 key 编码器保留 m 比例的旧参数、吸收 1−m 比例的新 query 参数，因此坐标系变化更缓慢。 队列太旧会产生表示漂移；batch 大也会提高假负率。系统吞吐与统计目标必须联合设计，不能把“更多负样本”当单调收益。

### 2.16.8 假负样本会把同类语义撕裂

两张不同鞋图被当负对，模型到底在学什么？。 实例区分希望每张图独特，因此同类可当负；类别检索希望同类聚集，此时它是假负。缓解方法包括监督对比的多正样本、近邻挖掘、去偏损失、聚类伪标签或过滤高相似候选，但都会引入新误差。 还要警惕假正样本：同一视频相邻帧可能已经切镜，同一患者两次检查可能病情改变。关系标签必须与时间、身份和任务语义一致。 正负不是自然事实。 它们是面向某个下游任务的建模决定。

### 2.16.9 没有负样本的方法仍需防止表示坍缩

若只最小化正对距离，全部输出同一个向量不是完美答案吗？。 是。“表示坍缩”就是不同输入都输出近乎相同向量，朴素一致性损失允许这种常数解。BYOL/SimSiam 用停止梯度、教师—学生或预测头形成不对称；VICReg 显式维持各维方差并惩罚冗余协方差。 L=L invariance +λL variance +μL covariance 。 式中： L 是总损失， L_invariance 拉近正对， L_variance 防止各维失去变化， L_covariance 减少维度间冗余； λ 和 μ 是后两项权重。训练时要看每维标准差、协方差谱、有效秩与最近邻多样性。loss 正常下降不能排除部分维度或全部样本坍缩。

### 2.16.10 表示必须用目标任务和反事实切片验收

训练 loss 很低，怎样知道模型没有只认水印？。 冻结编码器做线性探测，测线性可读信息。 做 kNN/Recall@k，检查最近邻语义和少数类。 固定预算少样本微调，测数据效率。 交换背景、颜色、水印或拍摄设备，做反事实测试。 按来源、群体和分布外数据切片。 t-SNE 与 UMAP 都是把高维表示有损映射到二维或三维的可视化降维方法，适合发现可疑簇和离群点；它们会改变原空间距离，不能单独证明真实簇结构、公平性或检索质量。比较方法时必须固定骨干、数据、增强、训练预算和评测协议。

### 2.16.11 常见误区与学习路线

公式只执行关系，数据构造才定义关系。 误区； 更准确的理解。 对比学习不需要标签； 正负构造就是关系标签。 负样本越多越好； 覆盖与假负率同时增加。 温度越小越能分开； 也会放大噪声和不稳定。 增强越强越鲁棒； 错误不变性会删除任务信息。 低损失证明表示好； 需迁移、检索和反事实验收。 。 层级； 依赖与延伸。 先修； 嵌入、softmax、交叉熵。 本页核心 ； InfoNCE、温度、增强、正负采样。 变体； SimCLR、MoCo、BYOL、监督对比。 应用； CLIP、检索、自监督学习。 。

### 2.16.12 把因果链连起来

这个概念怎样从问题一路连接到可验证的实践？。 定义下游语义与不变性。 构造正对和候选负对。 编码归一化并计算相似度。 InfoNCE 聚焦困难候选。 监控假负、捷径和坍缩。 用迁移与反事实测试验收。

### 2.16.13 误区与自测

你能否不用背术语，解释它的机制、边界与验证方法？。 算例中正对概率和损失约多少？。 为什么B鞋获得比C汽车更大梯度？。 温度变小有什么双重效果？。 MoCo的动量编码器解决什么？。 只拉近正对为何会坍缩？。 假设“对比学习：用正对与负对塑造表示空间”在离线示例上表现正常、上线后核心结果却下降，你会怎样按输入、内部变换、输出反馈和适用边界定位问题？。 如何为“对比学习：用正对与负对塑造表示空间”设计一个最小对照实验，证明观察到的改善来自核心机制，而不是数据、提示、权限或评测口径同时变化？。 。 参考答案 概率约0.715，损失约0.335。 B与锚点相似度更高，是困难负样本，softmax概率更大。 聚焦困难负样本，也放大错配与假负噪声。 让队列中不同时间生成的key保持相对一致。 所有样本输出同一常数即可让正对距离为零。 先保存同一失败样本及环境，确认输入、权限和前置条件没有漂移；再记录关键中间状态，检查机制是否按本页描述完成变换；随后把原始输出与独立指标、人工终验对照；最后用边界样例和对照实验复测。只有定位到首次偏离预期的环节，才能判断应修改数据、机制、评测还是使用边界。 固定数据、模型版本、提示、权限、预算和评测，只改变一个与核心机制直接相关的因素，并在多个样本与随机种子上重复；同时保存中间状态和失败样本。若差异只在目标因素变化时稳定出现，才支持机制解释，否则应继续排查混杂变量。

## 2.17 CLIP：用图文对比把两种模态对齐到同一空间（clip）

### 2.17.1 双编码器先各自理解，再在向量空间相遇

像素矩阵和 token 序列怎样变成可比较对象？。 vᵢ=f img (Iᵢ)/‖f img (Iᵢ)‖， tⱼ=f txt (Tⱼ)/‖f txt (Tⱼ)‖。 符号说明： Iᵢ 是第 i 张图像， f_img 是图像编码器， vᵢ 是归一化后的图像向量； Tⱼ 是第 j 段文本， f_txt 是文本编码器， tⱼ 是归一化后的文本向量。双竖线 ‖·‖ 表示向量长度，除以长度会把向量变成单位长度。 两个编码器输出同维向量并做 L2 归一化，点积就等于余弦相似度。图像与文本可离线分别编码，检索时只做向量比较；代价是它们在打分前没有逐 token/区域的深度交互。 贯穿例子： batch 有两对数据：I₁=猫图配 T₁“a cat”，I₂=狗图配 T₂“a dog”。归一化后的相似度矩阵为 [[0.8,0.2],[0.3,0.7]]。

### 2.17.2 一个 batch 自动形成 N×N 个图文组合

两对真配对为什么同时产生两对负样本？。 Sᵢⱼ=vᵢᵀtⱼ/τ。 式中： Sᵢⱼ 是第 i 张图与第 j 段文本送入 softmax 前的匹配分数； vᵢ 和 tⱼ 是单位长度图像、文本向量，上标 ᵀ 表示转置，因此 vᵢᵀtⱼ 是点积； τ 是温度，用来控制候选概率分布的尖锐程度。 N 是当前 batch 的真图文对数量，所以会形成 N 行图像乘 N 列文本。 矩阵对角线是采集到的正配对，非对角线在标准 CLIP 目标中视作负对。对 τ=0.1，原相似度 [[0.8,0.2],[0.3,0.7]] 变为 logits [[8,2],[3,7]]。batch 越大，候选越多，但语义相同却未配对的“假负样本”也会增加。 ； T₁ 猫； T₂ 狗。 I₁ 猫； 0.8 正对 ； 0.2 负对。 I₂ 狗； 0.3 负对； 0.7 正对 。 。

### 2.17.3 CLIP 同时做图找文和文找图

为什么损失需要按行、按列各算一次？。 沿用上一节 logits [[8,2],[3,7]]。图到文对每一行做 softmax：I₁ 选 T₁ 的概率 e⁸/(e⁸+e²)≈ 0.9975 ；I₂ 选 T₂ 的概率 e⁷/(e³+e⁷)≈ 0.9820 。文到图则按列竞争，确保文本也能找回图像。 L=(CE image→text +CE text→image )/2。 公式含义： CE_image→text 是每张图在全部文本中选中配对文本的平均交叉熵， CE_text→image 是每段文本在全部图像中选中配对图像的平均交叉熵； L 是两方向损失的算术平均。交叉熵会对正确配对概率取负对数，所以本例两个行概率越接近 1，图到文损失越小。 只做单向目标可能让一侧检索结构较弱。温度越小，softmax 越尖锐、困难负对贡献越大；若配对噪声高，过尖也会强迫模型记住错误。 方向； 查询； 候选竞争。 图→文； 一张图； batch 内全部文本。 文→图； 一段文字； batch 内全部图像。 。

### 2.17.4 原创图：正配对沿对角线形成共享空间

训练究竟移动了哪些向量？。 图示：图像文本双编码器与二乘二相似度矩阵。 图 1 双编码器只在相似度矩阵处交汇；训练信号同时更新两侧，使真配对在共享空间靠近。

### 2.17.5 零样本分类把类别写成文本原型

没有训练新的分类头，怎样预测“猫”还是“狗”？。 把候选类写成“a photo of a cat/dog”等模板。 分别编码并归一化，多个模板可平均成类别原型。 编码待测图像，与全部文本原型计算相似度。 在预先声明的类别集合中 softmax 或取最大值。 这是闭集候选上的零样本分类，不是模型凭空发现所有可能标签。类别名称、语言、模板、温度和候选集合都会改变结果；应在验证集选择模板并冻结后再测试。

### 2.17.6 检索效率来自独立编码，精排能力也因此受限

为什么百万图库可预编码，而复杂关系查询却容易失败？。 图库向量可提前建 ANN（近似最近邻）索引：它用索引结构快速找出与查询向量最接近的一小批候选，而不逐一精确扫描全部图库。查询文本只编码一次，因此双编码器吞吐高。cross-encoder（交叉编码器）则让文本 token 与图像区域在同一模型内交互，关系判断更细，但每个候选都需联合计算。常见系统先用 CLIP 高召回，再用跨模态交叉编码器精排。 结构； 离线索引； 交互深度； 用途。 双编码器 CLIP； 可； 全局向量； 召回、零样本。 Cross-encoder； 难； token/区域交互； 小候选精排。 。

### 2.17.7 对象共现不等于关系、计数与否定理解

“狗追人”和“人追狗”为何可能得到近似向量？。 两句包含相同对象与动作词，网页配对又常是粗标题；全局对比目标只需让正确主题胜过 batch 内其他文本，不一定解析角色顺序。“没有狗”“两只狗”“狗在桌下”也可能被对象词主导。 应构造最小对照：只交换主客体、数量、方位或否定，保持其他词与图像统计一致；报告 pairwise accuracy，而非只看总体 Recall。 高相似度不是蕴含关系。 它不证明描述中每个谓词都被图像支持。

### 2.17.8 弱配对数据同时带来规模与噪声

网页替代文本为什么既有价值又危险？。 alt-text、标题和邻近文字提供海量开放词汇监督，但可能描述页面而非图像，包含广告、刻板印象、身份误标和个人信息。近重复内容还会让训练与评测泄漏。过滤过强则可能删除少数语言和文化语境。 风险； 检查。 错配/弱描述； 人工抽样、噪声鲁棒训练。 社会偏见； 人群×职业×语言切片。 重复与污染； 图像/文本近重复去重。 隐私与许可； 来源、授权、删除链路。 。

### 2.17.9 CLIP 分数不是通用图像质量或安全裁判

生成图与提示相似度高，为什么仍可能是一张坏图？。 相似度可被大字、水印、典型背景和对抗纹理提高，却忽略解剖错误、事实矛盾、审美、版权和安全。用 CLIP 作生成奖励会诱发 reward hacking；做过滤器会产生群体差异与规避空间。 生成评估至少分开测提示对齐、视觉质量、多样性、关系/文字准确、安全与人类偏好，并用独立模型和人工样本校验。高影响判断不得只靠一个嵌入分数。

### 2.17.10 常见误区与学习路线

把 CLIP 看成跨模态检索度量，而不是视觉事实验证器。 误区； 更准确的理解。 共享空间表示真正理解全部语义； 优化的是配对相对排序。 非对角线都是真负样本； 可能存在语义同类或多描述。 零样本完全无需设计； 模板与类别集合影响原型。 相似度高表示描述完全正确； 对象共现可掩盖关系错误。 CLIP 分数等于图像质量； 需多维独立评估。 。 层级； 依赖与延伸。 先修； 嵌入、softmax、对比学习。 本页核心 ； 双编码器、对称损失、文本原型。 系统； 向量数据库、重排、图像生成。 评测； 组合泛化、公平、数据治理。 。

### 2.17.11 把因果链连起来

这个概念怎样从问题一路连接到可验证的实践？。 收集并治理图文配对。 双编码器产生归一化向量。 构造批内相似度矩阵。 双向交叉熵对齐空间。 文本原型或 ANN 完成迁移。 用最小对照与群体切片限定用途。

### 2.17.12 误区与自测

你能否不用背术语，解释它的机制、边界与验证方法？。 例子中 I₁ 选 T₁ 的概率约多少？。 为什么损失要双向计算？。 零样本分类的类别从哪里来？。 双编码器为何适合大规模检索？。 CLIP 高分为何不证明描述完整正确？。 假设“CLIP：用图文对比把两种模态对齐到同一空间”在离线示例上表现正常、上线后核心结果却下降，你会怎样按输入、内部变换、输出反馈和适用边界定位问题？。 如何为“CLIP：用图文对比把两种模态对齐到同一空间”设计一个最小对照实验，证明观察到的改善来自核心机制，而不是数据、提示、权限或评测口径同时变化？。 。 参考答案 τ=0.1时 logits 为8和2，概率约0.9975。 同时训练图找文与文找图的检索结构。 来自用户预先写出的文本类别原型及模板。 候选图文可独立预编码并建立向量索引。 全局相似度可能由对象共现主导，忽略关系、数量和否定。 先保存同一失败样本及环境，确认输入、权限和前置条件没有漂移；再记录关键中间状态，检查机制是否按本页描述完成变换；随后把原始输出与独立指标、人工终验对照；最后用边界样例和对照实验复测。只有定位到首次偏离预期的环节，才能判断应修改数据、机制、评测还是使用边界。 固定数据、模型版本、提示、权限、预算和评测，只改变一个与核心机制直接相关的因素，并在多个样本与随机种子上重复；同时保存中间状态和失败样本。若差异只在目标因素变化时稳定出现，才支持机制解释，否则应继续排查混杂变量。
