# 无监督学习理解原理页审查记录

审查日期：2026-07-26  
页面：`data/deepdive/unsupervised-learning.js`  
官方学习路径：`1 · 无监督学习`  
状态：已修复本轮发现的问题；尚未进行 L4 独立人工认证

## 记录目的

本记录用于积累后续统一优化门禁规范的真实缺陷样本。记录重点是读者为何在案例入口失去上下文、自动门禁为何漏检，以及什么部分能够自动检查、什么部分仍需人工判断。

## 发现与修复

### 1. 案例章节从答案开始，没有重新建立题干

- 用户影响：第 3 节直接计算 A 到 B、B 到 C 的欧氏距离。虽然第 1 节曾短暂列出 A、B、C、D，但第 3 节没有重新说明人物、特征、单位、比较目的和“距离越小表示越相似”的暂定规则。读者看到的是一道突然开始解答的题，而不是一个可独立阅读的例题。
- 漏检原因：原门禁只确认页面存在“数值例子”、公式和结果，没有检查案例是否在同一章节内具备可恢复的题干，也没有区分“前文曾出现某些数值”和“当前工作步骤所需条件已经重新激活”。
- 修复：第 3 节新增任务场景和完整数据表；先定义聚类语境中的相似性判据，再定义二维欧氏距离及全部符号，随后分别展示特征差、平方贡献、距离结果和业务解释。z-score 公式补充索引、均值、标准差的含义，并给出标准化前后的距离对照。

### 2. PCA 公式和整节术语没有为新手建立入口

- 用户影响：第 5 节用“投影方差最大的线性子空间、线性重建误差、局部邻域、高维连续云、岛屿”等专业词汇互相解释，并直接给出 `max Tr(WᵀΣW)`。读者既不知道降维要解决什么问题，也不知道 `W`、`Σ`、`Tr`、`I` 和约束分别承担什么角色。
- 漏检原因：门禁确认页面包含 PCA、t-SNE、UMAP、公式和边界提醒，便认为章节部件完整；它没有验证术语能否由日常语言进入，也没有检查公式中的全部符号是否在公式出现前获得角色。
- 修复：先用“多个用户特征压成少数坐标”和投影影子的类比解释降维，再从二维压到一维引出方向 `w`、一维坐标和近似重建；随后才把一条方向推广成矩阵 `W`。正式公式后增加逐符号表，并分别用普通语言解释方差、协方差、迹、正交约束和最大化目标。t-SNE/UMAP 改用“先找近邻、再尽量在二维保持靠近”的过程解释，并以对照表说明三种方法可读与不可读的结论。

### 3. “轮廓系数”首次出现即参与结论

- 用户影响：原第 8 节的引导句直接询问“轮廓系数高为什么仍无用”，正文随后把轮廓系数、惯性、重建误差和似然并列。读者既不知道轮廓系数在比较哪两个距离，也不知道取值范围和高低分别意味着什么。
- 漏检原因：原术语门禁只在同一节命中至少四个预登记术语时触发；单个关键新概念可以完全绕过检查。已有 `termReviews` 还只绑定一条任意正文证据，无法证明每个术语同时获得“是什么”和“有什么用”的解释。
- 修复：第 8 节先定义内部指标的角色，再定义同簇平均距离 `a`、最近其他簇平均距离 `b` 和轮廓系数 `s`；增加公式、`a=2,b=8` 与 `a=5,b=4` 两个数值例子、取值范围及可解释边界。

### 4. 密度估计只有公式，没有说明任务用途

- 用户影响：原第 6 节从 `pθ(xᵢ)` 和最大似然开始，随后直接出现生成、缺失值、异常评分、典型集合和密度比。新手不知道密度估计的输入、输出、用途，也无法理解“低密度”为什么值得关注。
- 漏检原因：公式符号合同只能证明 `θ`、`p`、`x`、`i` 有局部解释，不能证明所在章节已经建立任务级的“问题—输入—输出—用途—边界”。
- 修复：新增“分布地图”直觉，明确密度估计学习数据在哪些区域集中；分别说明异常筛查、生成样本和缺失值补全的使用方式与风险，再从任务语言引出概率密度、似然、对数似然和训练公式。

### 5. 同页各任务没有沿用统一教学标准

- 用户影响：降维部分具有日常语言入口、直觉类比、公式解码和方法边界，密度估计与内部指标却只有术语和结论。页面局部质量很高掩盖了其余章节的认知断层。
- 漏检原因：原门禁按全页图表、公式、案例和总字数计分，没有检查每个核心任务是否分别回答“是什么、有什么用、怎样工作、怎样解释、边界是什么”。
- 修复：第 1 节先给聚类、降维、密度估计建立任务地图；第 6 节按任务教学链重写；第 8 节明确内部指标是评估工具而不是另一项学习任务，并补齐计算和外部验证边界。

## 候选门禁改进

| 缺陷模式 | 候选自动检查 | 误报与人工边界 |
|---|---|---|
| 手算案例缺少局部题干 | 标记为“手算、逐步演算、数值例子”的章节，要求在首次代入前出现输入对象、数值或数据表、目标问题以及计算规则 | 简短案例可以继承紧邻上一段，但跨章节继承是否造成工作记忆负担仍需人工判断 |
| 例题直接给结果 | 检查核心结果前是否存在“定义/规则—代入—中间量—结果”证据位置 | 自然语言可能表达同一结构，不能仅靠关键词宣称教学充分 |
| 结论没有数值证据 | 当正文声称某处理“改变、恢复、降低或提高”某量时，提示检查处理前后对照 | 有些机制结论可由严格推导支持，不一定需要重复数值实验 |
| 一段话用多个未解释术语互相定义 | 提取高密度领域术语段落，并检查术语首次出现附近是否有普通语言释义、例子或符号表 | “专业词汇”依赖目标读者，自动化只能发出复核提示，不能仅凭词频阻断 |
| 单个关键概念突然出现 | 对已迁移页建立关键概念首次出现索引；每个概念分别绑定定义证据和用途证据，不再要求先达到术语密度阈值 | 自动化可验证证据存在，仍不能证明解释对目标读者已经充分 |
| 同页核心任务解释深度不一致 | 为核心任务审查“定义、用途、机制、例子、边界”五项映射，缺项进入人工复核 | 哪些章节属于核心任务需结合学习目标与官方顺序人工确认 |
| 核心公式中的符号突然出现 | 公式元数据登记核心符号；检查每个符号在公式前是否已有定义或紧邻符号表 | 公式前定义与公式后紧邻定义哪种更适合读者，需要 L4 判断；本项目优先先定义后使用 |

## 验收边界

自动门禁可以验证案例部件是否存在，却不能证明题干足够自然、计算步骤适合目标读者或例子真正降低了认知负担。上述判断仍属于 L4 人工审校范围。

## 门禁落地

本页已迁移到 `quality.contractVersion: 2`：

- 第 3 节登记案例局部题干合同，绑定 `setup`、`rule`、`steps`、`interpretation` 四段正文证据；
- 六个核心公式登记唯一 ID、所属章节、符号含义和正文证据；
- 门禁会验证证据确实位于同一章节、登记符号确实出现在公式中；
- 回归夹具证明“直接从 A 到 B 的结果开始”和“PCA 公式含 W 但正文没有 W 的定义”均会被 L3 硬阻断；
- 关键概念首次出现合同要求每个概念分别登记含义、用途、定义证据和用途证据；单个“轮廓系数”也能触发复核，不再依赖四词密度阈值；
- 十个核心正文节逐节登记六问合同：是什么、解决什么问题、输入输出、工作机制、结果解释和适用边界；任何一节缺项都会使整页失败，不能由第 5 节或全页总分补偿；
- 因果链、自测和参考路线分别标记为 `synthesis`、`assessment`、`reference`，使用各自门禁，不为满足模板强塞输入输出；
- 自动门禁只能确认这些证据存在，解释是否真正适合新手仍保留为 L4 判断。
