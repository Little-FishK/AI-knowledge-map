# 官方技术资料：知识矩阵重建记录

审核日期：2026-09-24
审核机制：`official-technical-importance-v2`（OpenAI、Anthropic、Google / DeepMind 均已完成全量审核）

## 收录门槛

每份候选资料依次回答：

1. 是否补上知识地图已有主题的必要资料缺口？
2. 是否仍适用于当前产品，或具有不可替代的基础、历史价值？
3. 它增加的是通用知识，还是品牌事实？
4. 若只是品牌事实，是否影响理解、使用、选型或比较？
5. 同一“品牌 × 主题”下，是否已有更完整、更新的官方原件？

通过项必须同时记录 `knowledgeDelta` 与 `brandEvidenceDelta`。二者允许一主一次，但不能都只是“厂商有这个功能”。资料数量不作为收录目标。

## 删除结果

此前 OpenAI 四批结论因没有把重要性作为硬门槛而全部作废。当前已完成 OpenAI 929 份、Anthropic 845 份与 Google / DeepMind 257 份候选的全量重审；只有先通过知识对应、重要性、边际增量和时效判断的资料才进入建卡环节。OpenAI 的 10 分制价值复核已完成四批共 240 份；当前官方技术资料共保留 873 条。主要不收录类型：

- 快速开始、价格页、产品总览和通用模型列表；
- 同一品牌同一主题下较旧或信息更少的重复页；
- 已迁移、已弃用或进入维护模式的资料；
- 只证明“该厂商也提供此功能”，但不影响理解或选型的条目；
- 尚未形成稳定来源簇的“其他厂商官方资料”混合分类。

`vendor-docs-other` 二级来源已撤销。今后新品牌只有在形成持续、代表性的技术贡献簇时才新增二级来源；单份厂商资料不得放回混合兜底分类。

2026-09-24 用户决策：撤销 Qwen、Moonshot AI 与 Zhipu AI 三个二级来源，并删除其原有 10 条官方技术资料卡。

## 全面性的定义

全面不再等于各品牌资料数量相同，而是：通用知识没有关键缺口；核心品牌的重要差异没有缺口；专业品牌的代表性贡献没有缺口。品牌重复资料只作为证据或比较项，不重复创建概念内容。
