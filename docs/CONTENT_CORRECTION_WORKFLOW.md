# 内容纠错与更新规则

对应原计划第18项。维护规则及本地阅读视图的中英反馈入口已接入，浏览器验证中文神经网络页和英文监督学习页的说明、页面ID、语言及问题模板正确。入口指向公开GitHub Issues，提示需要账号，提交前可检查；本次没有代用户提交问题。尚未部署，独立静态产物未扩展此入口，真实反馈闭环仍待验证。

记录反馈时保存：页面ID和语言、完整URL、版本hash、章节或原句、问题类型、复现说明、来源链接（如有）、受影响相关页面。无需收集姓名、邮箱等无关信息。

| 类型 | 处理流程 | 关闭条件 |
|---|---|---|
| 事实错误 | 用原始来源核实成立条件；定位相关中英页面；由控制器修订并独立审核 | 当前版本问题消失、来源可追溯、受影响版本已更新或明确待更新 |
| 看不懂 | 记录读者前置知识与卡点；区分术语跳步、例子不足、界面入口问题 | 内容修订后以复述/应用任务复测；只改写不能直接关闭教学问题 |
| 内容过时 | 核对产品、版本、时间、地区；保留历史语境或更新当前说明 | 事实与时间边界明确，旧译文失效可见 |
| 链接失效 | 检查重定向与访问限制，找官方替代来源 | 替代链接与原教学目的匹配；不以任意可访问首页替代具体证据 |
| 图表错误 | 复算数值与几何关系，核对正文和替代文字 | 独立图文复验通过；需要改图时走明确范围授权 |

流程：新建 → 待核实 → 已确认或无法复现 → 受控修订 → 独立复验 → 必要的人工确认 → 关闭。关联问题、版本变化、未完成英文同步都保留，不能因反馈数清零而删除历史。

事实可能误导学习时先标为阻断；排版和措辞建议独立排队。高变动软件资料每月复核一次，基础概念每季度及关联来源变化后复核；反馈触发核验不等周期。此为维护约定，未创建定时自动化。
