完整解决需要在控制器内完成以下事务：

1. 只读准备：锁定页面、候选摘要、旧基准摘要及独立审查记录，拒绝活动租约；核验独立审查确实对应当前候选，生成供人工检查的差异和维护计划。
2. 隔离验证：仅在临时夹具中把基准摘要指向候选，保持基准页面ID、维度和分数门槛不变，重新执行结构、L2、L3验证。报告其他真实缺陷，不把换摘要视作通过。
3. 人工确认：展示确切候选和计划；若原页面流程要求人工终审，维护动作不能替代该确认。
4. 原子应用：由控制器同时提交候选正文、运行时、审核关联和基准摘要，执行正式验证；任何失败恢复全部目标。不能先改变全站基准再等待页面发布。
5. 可追溯回执：记录前后摘要、独立审查绑定、门禁结果及确认依据。旧英文与静态产物重新计算资格，不自动沿用旧批准。
