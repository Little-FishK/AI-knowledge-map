# 英文翻译审核轮次

新批量任务使用 `translation-rounds-v1`，不再按每 60 个文本单元切分审核请求。

1. 一次完整审核：同时检查逐项译文准确性和全文一致性，集中返回全部具体缺陷。没有缺陷时直接进入资源与浏览器验收。
2. 一次集中返修：只能修改控制器提供的缺陷单元，并覆盖全部获准返修单元。
3. 一次定向复审：检查实际改动、原缺陷、受影响章节、重复原文及页头。全文作为引用上下文保留。未改动单元以内容哈希和原审核哈希继承覆盖记录，不伪造新的审核证据。复审仍有问题时进入裁定，不无限自动返修。

模型仍须明确返回 completed、findings、summary；控制器绑定版本和范围，校验引用、缺陷类型及独立审核身份。预算、上下文容量、资源与浏览器验收保持有效；一次请求不等于保证一次通过。

已有批次通过精确 `STAGE2_ROUND_REVIEW_CAMPAIGN` 授权迁移。旧部分审核归档保留，不能充当完整审核。未决请求必须单独处理，丢失响应的预留费用不归零。新建批次默认采用该流程。
