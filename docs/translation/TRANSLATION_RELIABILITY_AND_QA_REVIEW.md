# 翻译流程可靠性修复与成熟方案调研

2026-09-13。范围：控制器代码、合成测试、通过 Stage 2 MCP 进行的只读候选复核。未重新调用 DeepSeek，未部署网站。

## 已实现

- 错误记录包含时间、阶段、分类、具体报错、定位到 unitKey 的合同缺陷。敏感环境变量值及常见密钥格式从错误消息中移除。
- API 返回后、JSON 解析和合同校验前保存最终响应及计费字段到控制器私有存储；不保存 reasoning_content。历史丢失的响应不能由此补回。
- 取消合同版本变化时清零重试次数。合同失败最多两次；后续受限重试收到具体合同缺陷。未恢复历史已耗尽次数的队列。
- 审核请求只有一种 checkedUnits 传输结构，仍由控制器转换成原审核结构并严格校验。保留逐单元精确引用、说明最少 20 字符、整页说明最少 40 字符和审核/返修身份隔离。未自动填充引用或扩写审核证据。
- 数字检查增加受限的万/亿数量等价转换，包括十万、100万、英文 million/billion、a billion 和 megapixel。不是通用自然语言数字解析器；日期、版本、百分比、实际数值和已识别单位的变化仍被拦截。
- 宪法式 AI 的已知 SVG 底部英文图注改为两行，不改译文、候选哈希或正式中文源。未知尺寸或超长图注继续交由浏览器检查拦截。

## 验证与边界

- 合成测试覆盖数字正反例、审核缺陷反馈与两次停止、私有最终响应保留、思考内容排除、错误脱敏、图注全文保留、独立审核和发布权限。
- MCP 真实候选复核：curse-of-dimensionality、kernel-methods 均无机械缺陷，状态为 awaiting-independent-review。这不代表语义审核通过。
- constitutional-ai 在修复后的真实 Edge 桌面 1440×1000、手机 390×844 检查及导航/语言切换验收通过；未发布。
- 聚类、正则化、声音克隆仍需模型重新生成合格审核报告。输出合同改进经模拟测试，真实模型成功率尚未重新测量。
- campaign 的旧 held 状态仍保留；本次诊断不写回生产审核记录或启动付费续跑。

## 外部成熟方案

### MQM：优先借鉴错误分类

[MQM Council 错误分类](https://www.themqm.org/mqm-pillars/typology/)将错误分为术语、准确性、语言规范、风格、区域规范、受众适宜性、设计与标记等维度；准确性下包括遗漏、添加、误译等。它是评价框架，不是自动翻译引擎。

已接入项目子集 `mqm-subset-v1`：新 DeepSeek 审核缺陷必须提供误译、遗漏、添加、一致性或术语分类，以及 minor/major/critical 严重程度。审核控制器验证分类与规则的一致性，净化返修包保留这些定位信息。旧证据保持兼容，未标注严重程度显示 unassessed，不补造证据，不重置审核。所有已确认缺陷仍然阻断，不以平均分或轻微等级放行。

质量状态新增独立的 source、mechanical、semantic、presentation 层；合同和运行错误单独呈现为 systemError。浏览器进程故障属于 system；明确的越界/资源检查失败属于 presentation，不混入语义质量计数。新分类已通过合成回归测试，尚未进行新的付费模型审核校准。

### Weblate：借鉴机械 QA 和审核状态分离

[质量检查](https://docs.weblate.org/en/latest/user/checks.html)覆盖占位符、标记、术语等技术检查；[工作流文档](https://docs.weblate.org/en/latest/workflows.html)说明机器翻译、人工编辑和审核批准后进入仓库等流程。

项目建议：现阶段借鉴其检查分层和状态管理即可。若以后需要多人翻译界面，可适配导出副本供 Weblate 编辑；导入仍经过 Stage 2 控制器。不能让外部平台直接写正式深度理解页或批准记录。

### Phrase：参考商业 QA / Auto LQA 的职责划分

[Phrase QA](https://support.phrase.com/hc/en-us/articles/5709703799324-Quality-Assurance-QA-TMS)说明机械检查及任务结果保存；[Auto LQA](https://support.phrase.com/hc/en-us/articles/14313477218588-Auto-LQA-TMS)提供错误标注和评估，明确不会自动修改译文。

项目建议：借鉴“发现缺陷—验证缺陷—独立返修—复验”的分工及工作流级记录。商业服务可作为未来备选，但本轮没有购买、接入或比较报价。

### COMET / XCOMET：可试验辅助评估

[官方仓库](https://github.com/Unbabel/COMET)提供参考译文评分和无参考译文质量估计模型；XCOMET 可输出错误跨度和质量分。框架代码与具体模型权重分别有许可说明，选模型时需分别核对。

项目建议：先离线在中英技术样本上测量误报和漏报，再决定是否做第二评估信号。它不能直接取代整页上下文审核、源码结构保护或浏览器排版验证。本轮未安装模型、下载权重或接入生产。

## 推荐路径（尚未执行）

### 2026-09-13 用户批准的追加返修

用户明确同意维度灾难和核方法各追加一次限定返修。控制器以授权标识、当前译文 revision 和精确缺陷 unitKey 保存一次性授权；历史 repairCount 保留，从 2 增加到 3 后授权消耗，不允许再次使用或更换标识重复追加。修订后必须独立复验。默认其他页面仍维持两轮上限。相关合成测试覆盖越界拒绝、幂等授权、使用一次后拒绝以及修订后回到独立审核。

先复用现有翻译及控制器，采用 MQM 错误分类和机械/语义/展示三层检查。准备包含准确译文、漏译、数值变化、否定变化、术语问题及 SVG 长文本的中英标注集；比较现有审核与辅助评估的误报、漏报、耗时和费用。验证后再决定引入 Weblate 界面或 COMET 服务，不因单次高分自动发布。
