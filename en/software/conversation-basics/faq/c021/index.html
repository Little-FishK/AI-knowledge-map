How do I stop a task, revoke permission or restore the previous state?

简体中文

C021 · C Controlling changes · Autonomous decisions and action permissions

Key answerFull explanationReferences

Key answer

Stopping, revoking and restoring are separate actions requiring separate checks. Stopping halts work; revocation removes future permission; restoration needs versions, backups or the system's recovery features.

Full explanation

Research supports correction and disengagement controls. Amershi et al.'s human-AI interaction guidelines underwent multiple evaluations, including 49 design practitioners applying them to 20 AI products. Guidelines 8, 9 and 17 concern dismissal, correction and global controls. CHI 2019, Table 1

Proceed in order:

1. Use Stop/Cancel and identify the task. Check scheduled runs, background jobs and other executors too.

2. Revoke corresponding authorization; disable connections or permissions in the product/external service when lasting prevention is required.

3. Inspect operation records, distinguishing success, not started and unknown outcomes before choosing recovery. Confirm the target version to avoid overwriting later valid edits by others.

Cancellation has timing limits. MCP specifies optional cancellation; receivers may ignore notifications when a request is already complete or cannot be canceled. Check external state after stopping such tools. Cancellation specification

Stop this task and revoke permission for further edits and sends. Use tool records to list changes and uncertain outcomes. Inspect only; do not start restoration yet. Identify recoverable versions and later changes they could overwrite.

Recovery depends on actual features. OneDrive history can make an earlier version current while retaining the previous current version. Microsoft documentation Sent messages require the sending system's recall feature; reverting a local draft does not change what recipients received.

Reopen files or external systems to check states/versions. Confirm stopping, revocation and restoration individually from actual records rather than one AI assurance.

References

1. Amershi et al. (2019), Guidelines for Human-AI Interaction, CHI, Table 1 and user evaluation

2. Model Context Protocol (2025-06-18), Cancellation, Behavior Requirements and Timing Considerations

3. Microsoft, Restore a previous version of a file stored in OneDrive, official help
