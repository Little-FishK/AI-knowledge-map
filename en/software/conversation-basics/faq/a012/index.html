If I do not know a technical name, can AI identify it from uses, features, examples and counterexamples?

简体中文

A012 · A Expressing intent · Aligning words and meanings

Key answerFull explanationReferences

Key answer

You can search for a name through uses, features and examples, but initially treat AI's terms as candidates. Describing something to find its name is an established language-processing task called a reverse dictionary.

Full explanation

Tsinghua's WantWords accepts meaning descriptions and returns semantically matching words, supporting Chinese, English and cross-language queries. It demonstrates feasibility, but is a specialized reverse dictionary, not evidence that any chat model accurately identifies every concept. Paper

A practical chat process is to describe what you see and want to accomplish, request a few candidates and their differences, then answer a question that distinguishes them. CLAM validated detecting ambiguity, asking a clarification and using the answer, mainly for factual question answering rather than unlimited beginner consultations. Study

I do not know this feature's name. It separates a person from the background without changing the person. Suggest possible feature names and their differences. If background removal and other features fit, first ask the question that best distinguishes them.

Use counterexamples to exclude likely confusions: “I do not want a different background; I want an image of the person on a transparent background.” You need not guess a technical term first. A wrong term can steer subsequent discussion toward another task.

References

1. Qi et al. (2020), WantWords: An Open-source Online Reverse Dictionary System, EMNLP System Demonstrations

2. Kuhn, Gal and Farquhar (2022/2023), CLAM: Selective Clarification for Ambiguous Questions with Generative Language Models
