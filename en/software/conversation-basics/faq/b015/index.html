What information should I provide again when continuing in a new conversation?

简体中文

B015 · B Providing context · Context and memory

Key answerFull explanationReferences

Key answer

A new conversation needs enough current state to continue: goal, authoritative artifact, constraints and starting point. Do not copy the entire history unnecessarily, but “continue last time” is insufficient.

Full explanation

Automatic inheritance depends on the product. Claude's history search has project-scope restrictions and separate project memories; OpenAI distinguishes ChatGPT and local Codex memory. Confirm that important conventions and latest files are available in the new conversation; an old chat's existence does not establish inclusion. Claude scope, OpenAI memory

Reprovide especially:

· Goals and acceptance criteria: audience, deliverable and mandatory requirements.

· Current artifacts and material: latest version, accessible files/links, key terms and necessary original text.

· Confirmed decisions: choices, reasons and superseded approaches/rules.

· Progress and remaining work: actual completion and verification, gaps and next action.

For tasks with action permissions or resource limits, include still-valid authorization, budgets and stopping conditions. Add unconfirmed ideas, old drafts or failed attempts only when they prevent repeating mistakes.
