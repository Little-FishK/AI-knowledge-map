  • DeepSeek-OCR official repository

    Publisher: DeepSeek · Collection: DeepSeek official repository · Format: Official code repository · Authority tier: A1 · Review status: current

    The official OCR model repository, focused on "contexts optical compression": compressing document images into fewer vision tokens before handing them to a language model. It represents a route for long documents different from plain text chunking and is primary material for understanding the relationship between multimodality and context cost.

    Evidence use: Supports statements such as "whether visual compression can reduce token usage for long documents"; the trade-off between compression ratio and accuracy should be judged from the repository's experimental data.

  • Context Caching

    Publisher: DeepSeek · Collection: DeepSeek API official docs · Guides · Format: Official technical documentation · Authority tier: A1 · Review status: current

    Introduces on-disk context caching, enabled by default for all users: cached input tokens are billed at a lower price, with no change to how the API is called. It turns prompt caching from an optional optimization into default behavior, and is key to understanding how the pricing structure relates to the caching mechanism.
