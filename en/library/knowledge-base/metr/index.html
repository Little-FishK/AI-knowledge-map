Knowledge Bases and Evaluation Organizations · METR. Pre-deployment evaluations and task time-horizon curves. This source has 8 entries admitted under this category's review policy; each links directly to the original.

Authority tiers in this category: A2–B. Admission policy: All core resources are included. Each secondary source is admitted according to its own database, methodology, versions and leaderboard structure; there is no cross-organization scoring scheme.

  • Measuring AI Ability to Complete Long Software Tasks

    Publisher: METR · Collection: METR Time Horizons · Format: Evaluation methodology and research report · Authority tier: A2 · Review status: living

    Uses the time human experts need to complete a task as a difficulty scale to study how reliably models complete long software tasks.

    Evidence use: Supports the definition, methodology and historical trend of the task time-horizon metric.

    Limitations: Tasks are mainly software, machine learning and cybersecurity. Trend extrapolation is not a capability promise.

    Related concepts: AI Agent · Model Evaluation and Benchmarks

    Link last checked: 2026-09-24

  • Task-Completion Time Horizons of Frontier AI Models

    Publisher: METR · Collection: METR Time Horizons · Format: Continuously updated evaluation results · Authority tier: A2 · Review status: living

    Continuously publishes frontier model results on the task time-horizon curve, with explanations and FAQs.

    Evidence use: Supports 50% time-horizon results for a specified date, model and evaluation suite.

    Limitations: Time horizon refers to the estimated time for a human to complete a task, not model run time. Intervals become less stable as a suite nears saturation.

    Related concepts: AI Agent · Model Evaluation and Benchmarks

    Link last checked: 2026-09-24
