Knowledge Bases and Evaluation Organizations · Stanford CRFM / HELM. Foundation model transparency and evaluation. This source has 12 entries admitted under this category's review policy; each links directly to the original.

Authority tiers in this category: A2–B. Admission policy: All core resources are included. Each secondary source is admitted according to its own database, methodology, versions and leaderboard structure; there is no cross-organization scoring scheme.

  • HELM：Holistic Evaluation of Language Models

    Publisher: Stanford CRFM · Collection: HELM · Format: Reproducible comprehensive evaluation platform · Authority tier: A2 · Review status: living

    Evaluates foundation model capabilities in language, multimodal, medical, image and other areas with uniform scenarios, metrics and reproducible configurations.

    Evidence use: Supports the methods, scenarios, metrics and model results of each HELM sub-leaderboard.

    Limitations: Sub-leaderboards use different definitions. Some evaluations use model judges.

  • 2025 Foundation Model Transparency Index

    Publisher: Stanford CRFM / HAI · Collection: Foundation Model Transparency Index · Format: Foundation Model Transparency Index · Authority tier: A2 · Review status: living

    Uses a set of transparency indicators to assess what major foundation model developers disclose about upstream resources, the model and downstream use.

    Evidence use: Supports comparing developers' transparency performance and the indicator framework.

    Limitations: Scores measure disclosure, not model quality or safety. Comparisons are valid only within the same version of the index.

    Related concepts: AI Governance and Regulation · Model Evaluation and Benchmarks
