阅读说明

AI 生成镜头后，通常还要调整片段长度、镜头顺序、画面构图、颜色和声音。本章先选定专业视频编辑平台，再完成 Agent 接入，让你通过自然语言操作已有工程，并根据预览继续修改。

1. 选定两个编辑平台

本章选择 DaVinci Resolve Studio（达芬奇） 和 Adobe Premiere Pro，依据是专业后期能力、可继续编辑的工程，以及有资料可核对的 Agent 接入方式。两者选一个学习即可。

平台选择理由Agent 接入路线建议怎样选
DaVinci Resolve Studio在同一工程中完成剪辑、调色、Fusion 合成与 Fairlight 声音后期21.1 已加入官方 AI 助手集成；也可使用下文的第三方 MCP新建后期流程、重视画面与声音统一处理时，优先从它开始
Adobe Premiere Pro时间线精剪、文字与图形制作，以及 Adobe 素材协作内置 AI Assistant（beta）；外部 Agent 可通过第三方 PPMCP 接入已在使用 Photoshop、After Effects 或 Premiere 工程时，优先沿用它

平台具备某项编辑功能，与 Agent 能调用这项功能，需要分别确认。学习时先接通查询、一次小修改和工程保存，再扩大任务范围。

2. DaVinci Resolve Studio：连接外部 Agent

官方接入与本章采用的步骤

Blackmagic 已在 Resolve 21.1 官方更新说明中确认 AI 助手集成，列出的任务包括分析工程、整理素材、调整设置、剪出精选片段和批量渲染。使用对应版本时，可先查 官方支持中心中的 21.1 手册与新版功能介绍，采用随软件提供的接入方式。

下面展开的是 第三方 samuelgursky/davinci-resolve-mcp 路线，便于按作者安装文档逐项完成环境准备、客户端配置和连接检查。它与官方集成是两套方案，选择其中一套连接即可。项目说明

1. 准备软件与脚本环境

按作者要求准备 Resolve Studio 18.5 或以上、Git，以及 64 位 Python 3.10 或以上；下面的命令使用 Python 3.12。媒体分析还需 ffmpeg，并确保命令能从 PATH 找到；转录等功能的额外依赖按任务补齐。启动 Resolve，打开用于练习的工程。在 Preferences → System → General → External scripting using 中选择 Local，保存设置。安装与版本要求

本节按 Studio 编写。免费版的脚本接口与桥接条件随版本变化，不直接套用本节步骤。

2. 下载项目并生成客户端配置

在选定的工具目录打开 PowerShell，依次执行：

git clone https://github.com/samuelgursky/davinci-resolve-mcp.git
Set-Location davinci-resolve-mcp
py -3.12 install.py --clients manual

安装器会建立运行环境并输出手动接入配置。将它生成的启动命令、参数与环境变量加入你的 Agent 客户端；路径使用安装器给出的实际值。已有其他 MCP 配置时，合并服务器条目。其他安装方式与故障诊断见同一份 作者安装文档。

3. 连接并检查当前工程

客户端需要支持启动本地 stdio MCP 服务。保存配置并重启客户端，启用 Resolve 工具，同时保持 Resolve 和工程打开。先让 Agent 读取当前工程名称、时间线、轨道和片段，核对返回信息与软件界面是否一致。

4. 从明确支持的编辑操作开始

可以先练习素材整理、片段属性调整、标记、渲染设置等任务。涉及剪切、移动或替换片段时，让 Agent 先检查当前接口是否支持相应操作，再执行。时间线操作边界区分支持、部分支持和受限操作；软件界面能完成的任务，接口未必提供相同控制。

软件与接入教程：Blackmagic 官方培训、MCP 安装指南、时间线能力说明。

3. Adobe Premiere Pro：内置助手与外部 Agent

路线 A：内置 AI Assistant

如果当前版本与账户已提供助手，在 Premiere 中打开工程，通过 Window → Assistant 进入对话。Adobe 的 官方说明仍将其标为 beta；列出的任务包括素材分箱与重命名、转录、标记，以及初步片段组合。

这条路线适合先用自然语言整理素材和搭建粗剪。需要精确修改片段、构图或音量时，检查助手当时支持的动作，也可选择下面的外部接入路线。

路线 B：外部 Agent + PPMCP

本章选用第三方项目 CaYatur/PremiereProMCP（PPMCP）。它通过 UXP 插件与本地桥接程序连接 Premiere，再把编辑工具提供给 Agent。下面按作者主要测试的 Windows 环境编写。

1. 准备 Premiere 与插件加载工具

使用 Premiere 26.0 或以上，安装 Adobe UXP Developer Tool。在 Premiere 的 Settings → Plugins 中启用 Enable developer mode，重启 Premiere。Adobe 通用 UXP 教程支持的最低版本与这个项目的最低版本不同，本节采用项目要求的 26.0。项目版本要求、Adobe 插件加载说明

2. 安装 PPMCP

从 作者 Releases 下载 PPMCP-Setup-x.x.x.zip，完整解压，保留 Setup.bat 与 payload 的相对位置，再运行 Setup.bat。安装后打开作者生成的连接说明：

  • %APPDATA%/PPMCP/HOW-TO-USE.txt：使用步骤与本机实际路径。
  • %APPDATA%/PPMCP/HOW-TO-CONNECT.txt：程序、服务器与插件入口。
  • %APPDATA%/PPMCP/mcp-config-snippet.json：供客户端合并使用的配置片段。

以上为作者提供的发布包安装方式，本章没有在本机执行安装。完整安装指南

3. 启动桥接并加载插件

运行安装器建立的 PPMCP Bridge 快捷方式。打开 Premiere 与 UXP Developer Tool，在后者选择 Add Plugin，使用 HOW-TO-CONNECT.txt 中的插件 manifest 路径，再点击 Load。在 Premiere 中打开 PPMCP 面板，确认状态为 Active；面板关闭后，可从 Window → UXP Plugins 找回。作者连接步骤、Adobe 面板入口说明

4. 配置 Agent 客户端

将生成的 MCP 配置片段合并到客户端，保存后重启。PPMCP 使用本地 stdio：客户端启动指定的 Node 程序，并以服务器入口文件作为参数。它不能填进只接受远程 MCP URL 的连接框。不同客户端配置格式有差异，按 作者的客户端配置章节填写；使用安装器生成的真实路径。

5. 核对能够执行的操作

作者记录的实机验证包含读取工程与序列、部分片段剪辑、位置与缩放、音量增益，以及工程保存和序列截图。完整工具表还包含未逐项实测的功能，不能仅凭工具数量判断可靠性。工具与验证状态

可编辑 MOGRT 文字需要作者另列的 CEP Text Bridge；PNG 文字覆盖层与可编辑字幕不同。新增轨道等操作也可能受 UXP 接口限制，先检查当前版本的支持状态。

软件与接入教程：Premiere 官方帮助、内置助手说明、PPMCP 安装指南、工具能力与限制。

4. 常见问题与结果检查

现象优先检查
Agent 只有建议，软件没有变化是否启用了实际编辑工具，是否出现调用记录，回读的工程是否正确
Resolve 服务启动但读不到工程Studio 版本、本地脚本设置、Resolve 是否运行，以及工程是否打开
Premiere 插件没有连接开发者模式、UXP 插件是否 Load、PPMCP Bridge 是否运行、面板是否 Active
MCP 工具为空客户端是否支持本地 stdio、启动路径是否有效、配置是否按客户端格式合并
某个菜单功能无法通过 Agent 执行查看当前接口与工具的支持范围；保留错误信息，转到软件中完成该步骤
保存成功但没有测试视频工程保存与视频导出分别检查，核对渲染状态和实际输出文件
