1. skill 和 Harness

skill

skill（技能）是一份按约定格式组织、可以按任务加载的操作说明，也可以附带资料和程序。 它的价值在于让软件能够识别、加载和复用一套工作方法。Agent Skills 官方说明

与 AGENTS.md 有什么区别

两者的内容可以相同，区别在于放在哪里、何时加载：

  • AGENTS.md 提供项目或目录中的工作说明，例如项目结构、修改规则和测试方法，由支持它的软件按目录范围加载。AGENTS.md 官方说明
  • skill 把一类任务单独组织起来，提供名称和用途描述。软件先让模型知道有哪些技能，任务需要时再加载具体步骤。技能加载机制

按照 Agent Skills 规范，先建一个文件夹，在里面创建 SKILL.md。文件开头填写 name 和 description，后面写操作步骤。名称要与文件夹一致。下面是一份最小示例：

return-support/
└── SKILL.md

SKILL.md 的内容：

---
name: return-support
description: 核对商店退货条件并生成客服回复。处理退货申请咨询时使用。
---

# 处理退货咨询

1. 取得现行退货规则、订单签收时间和商品使用情况。
2. 缺少影响判断的信息时，先询问，不猜测。
3. 按规则说明能否申请，以及后续审核流程。
4. 区分“可以申请”与“保证退款”，不补充未提供的承诺。

这个目录已经构成一份符合格式的 skill 资源。需要附带规则、示例或程序时，再加入 references/、scripts/ 等目录，并在说明中写清楚读取或运行哪个文件。写了 AGENTS.md 不会自动变成 skill；只有 SKILL.md、没有辅助程序，也可以是 skill。 Agent Skills 格式规范

skill 文件不会自己运行。支持技能的软件要先发现它，将名称和描述提供给模型，再在选中时把完整说明放进上下文。选择技能有两条路径：模型根据任务自动选择，或用户显式指定。官方接入说明

例如，在 Claude Code 中，将上面的目录放到项目的 .claude/skills/ 下，就形成 .claude/skills/return-support/SKILL.md。之后可以在消息开头输入 /return-support，再附上顾客问题和材料，显式加载这项技能。Claude Code：技能目录与调用

skill 出现在列表中，说明软件发现了它；显式调用或读取记录可以帮助确认加载；执行是否正确，要检查实际步骤和结果。

skill 的文字说明不能保证模型百分之百遵守。必须执行的限制，要落实到程序和工具中。例如，要求“只读”时就不给写入权限；要求登记必须有订单号，就让登记接口拒绝缺失订单号的请求。skill 交代怎么做，运行程序检查哪些操作可以发生。

skill 的基本交付物是整个文件夹。把说明引用的资料和程序一起放进去，保留相对路径，就可以复制目录或通过代码仓库分享。

需要上传到 Claude 网页版时，把目录压缩成 ZIP，包内结构如下：

return-support.zip
└── return-support/
    ├── SKILL.md
    └── references/   如果使用了附带资料，就一起打包

Windows PowerShell 可以在技能文件夹的上一级运行：

Compress-Archive -LiteralPath .\return-support -DestinationPath .\return-support.zip

然后在 Claude 的 Customize → Skills 中选择添加技能、上传 ZIP 并启用。Claude Code 则可以直接使用技能目录，无需先压缩。Claude：打包要求、上传与启用

Harness

Harness 是让 Agent 实际运行的程序，负责组织模型调用、工具执行、上下文和运行控制。 也是一个模型和工具反复交互的流程。模型提出“查询订单”，Harness 就把请求交给查询工具，再将结果送回模型。Anthropic 对 Harness 的核心描述就是调用模型并转交工具请求的循环。Anthropic：运行结构

Harness 和工作流可以是一个东西，只是前者强调模型运行的程序，后者强调任务的步骤、分支和顺序。

一个 Harness 的核心是模型与工具之间的执行循环。为了处理完整任务，还会组合以下能力：

部分具体负责什么
模型接入连接模型服务，发送输入，接收回复或工具调用请求。
上下文管理整理指令、对话、skill 和工具结果；内容过长时摘要或转存。
工具调度将工具名称和参数交给对应程序，把返回值或错误送回模型。
执行控制检查操作权限，处理人工批准、停止请求和运行次数限制。
状态与记录保存已完成步骤、工具结果和待办事项，配合持久化存储恢复任务。

文件读写、skill 加载、任务拆解和子 Agent 都可以在此基础上加入。Deep Agents 就提供了多项现成能力。模型服务、文件系统和数据库可以由其他系统提供，Harness 负责把它们组织起来。Deep Agents：组成与能力
