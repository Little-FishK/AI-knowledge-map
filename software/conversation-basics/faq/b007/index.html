上传成功是否等于全文已被读取？怎样发现遗漏页、截断或解析失败？

B007 · B 提供条件 · 材料是否被实际读取

回答要点完整解答引用文献

回答要点

上传成功表示文件已被接收；全文是否被正确解析、是否都进入本次处理范围，需要另外检查。 有些工具按问题检索片段，有些只提取文字，也有些同时处理页面图像。

完整解答

OpenAI Responses API 的文件输入文档给出了具体差别：支持视觉的模型处理 PDF 时会收到提取文字和页面图像；非 PDF 文档主要提取文字，不提取其中的嵌入图像与图表；其表格输入流程最多解析每个工作表的前 1,000 行，再生成摘要和表头信息。这里说的是该接口的输入流程，不能套用为所有聊天产品的文件上限。文件处理说明

可以从三处查遗漏：

· 结构是否齐全：文件实际页数、目录、附件和工作表，是否与解析结果对应；扫描页有没有变成空白文字。

· 重点内容是否读到：抽查开头、中间、结尾，以及决定结论的表格、脚注和附录，让 AI 指出具体内容与位置。

· 任务是否覆盖完整：逐条审查、查找所有例外或统计全部记录时，要求按章节、页段或数据范围记录覆盖情况，不能只凭检索到几段就宣布完成。

这份文件共48页，请核对可读取范围，检查第1、24、48页及附录表格是否有内容。随后按章节审查，列出已处理范围与缺页、空白解析或截断情况；不要把检索到的片段写成全文检查。

答不出抽查题，可能是解析遗漏，也可能是内容已提供但没有被正确利用。*Lost in the Middle* 在多文档问答和键值检索实验中发现，仅改变相关信息的位置就会影响表现。因此，应先检查提取结果，再决定重新上传、分段处理还是补给关键页面。研究原文
